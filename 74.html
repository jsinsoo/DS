2. 수업을 여는 멘트

숫자만 가득한 표를 보면 변화와 차이를 한눈에 파악하기 어렵습니다. 하지만 그래프로 바꾸면 증가하는 흐름, 가장 큰 값, 관계와 분포가 눈에 들어옵니다. Matplotlib은 데이터를 그림으로 번역하는 도구입니다. 인문 철학적으로 시각화는 “무엇을 보이게 할 것인가”의 선택이기도 합니다. 오늘 우리는 데이터를 잘 보이게 하되, 왜곡하지 않고 정직하게 보여 주는 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① Matplotlib

Matplotlib은 파이썬에서 그래프를 그리는 대표적인 시각화 라이브러리이다. 데이터 분석 결과를 선, 막대, 점, 구간 분포 등 다양한 형태로 표현할 수 있다.

② pyplot

pyplot은 Matplotlib에서 그래프를 쉽게 그리기 위한 모듈이다. 보통 import matplotlib.pyplot as plt로 불러온다.

③ Figure와 Axes

Figure는 그래프가 그려지는 전체 도화지이고, Axes는 실제 그래프가 표시되는 좌표 영역이다. 기초 수업에서는 pyplot 방식으로 쉽게 시작할 수 있다.

④ 선그래프

선그래프는 시간에 따른 변화와 추세를 표현하는 데 적합하다. 월별 매출, 일별 기온, 연도별 변화에 자주 사용된다.

⑤ 막대그래프

막대그래프는 범주별 값의 크기를 비교할 때 사용한다. 학급별 평균, 메뉴별 투표 수, 지역별 이용자 수에 적합하다.

⑥ 산점도

산점도는 두 수치형 변수 사이의 관계를 점으로 나타낸다. 공부 시간과 점수, 수면 시간과 집중도처럼 두 변수의 관계를 볼 수 있다.

⑦ 히스토그램

히스토그램은 수치 데이터가 어떤 구간에 얼마나 많이 분포하는지 보여 준다. 점수 분포, 키 분포, 센서값 분포에 활용된다.

⑧ 그래프 요소

제목, 축 이름, 범례, 눈금, 축 범위는 그래프 해석에 중요한 요소이다. 좋은 그래프는 보는 사람이 의미를 쉽게 이해할 수 있도록 돕는다.

⑨ 한글 표시

Matplotlib에서 한글이 깨질 수 있으므로 수업 환경에 맞는 한글 폰트를 설정해야 한다. 웹 배포용 예제에서는 영어 라벨을 쓰면 오류와 경고를 줄일 수 있다.

⑩ 시각화 윤리

그래프는 사람의 판단에 영향을 준다. 축을 과도하게 조정하거나 일부 데이터만 선택하면 오해를 만들 수 있으므로 정직한 표현이 중요하다.

4. 각각의 개념과 관련된 파이썬 코드

① pyplot 불러오기

import matplotlib.pyplot as plt

print("Matplotlib is ready")

Matplotlib의 pyplot 모듈을 plt라는 이름으로 불러온다.

② 선그래프

import matplotlib.pyplot as plt

months = [1, 2, 3, 4]
sales = [100, 120, 150, 130]

plt.plot(months, sales, marker="o")
plt.title("Monthly Sales")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.show()

월별 판매량의 변화 추세를 선으로 나타낸다.

③ 막대그래프

import matplotlib.pyplot as plt

classes = ["A", "B", "C"]
scores = [82, 88, 79]

plt.bar(classes, scores)
plt.title("Average Score by Class")
plt.xlabel("Class")
plt.ylabel("Score")
plt.show()

학급별 평균 점수를 막대로 비교한다.

④ 산점도

import matplotlib.pyplot as plt

study = [1, 2, 3, 4, 5]
score = [55, 65, 72, 83, 90]

plt.scatter(study, score)
plt.title("Study Time and Score")
plt.xlabel("Study Time")
plt.ylabel("Score")
plt.show()

공부 시간과 점수의 관계를 점으로 확인한다.

⑤ 히스토그램

import matplotlib.pyplot as plt

scores = [60, 70, 75, 80, 85, 90, 95, 95]

plt.hist(scores, bins=5)
plt.title("Score Distribution")
plt.xlabel("Score")
plt.ylabel("Count")
plt.show()

점수들이 어떤 구간에 많이 분포하는지 확인한다.

⑥ 범례가 있는 그래프

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
a = [10, 20, 25, 30]
b = [8, 18, 22, 28]

plt.plot(x, a, label="A")
plt.plot(x, b, label="B")
plt.title("A and B Comparison")
plt.xlabel("Time")
plt.ylabel("Value")
plt.legend()
plt.show()

여러 선이 있을 때 범례로 각 선의 의미를 설명한다.

상세 설명: 월별 독서량 변화 추세를 선그래프로 확인한다.

import matplotlib.pyplot as plt

menus = ["Rice", "Curry", "Pasta", "Soup"]

상세 설명: 메뉴별 투표 수처럼 범주별 크기 비교에는 막대그래프가 적합하다.

예제 3. 수면 시간과 집중도 산점도

import matplotlib.pyplot as plt

sleep = [5, 6, 7, 8, 9]
focus = [55, 65, 75, 82, 80]

plt.scatter(sleep, focus)
plt.title("Sleep and Focus")

plt.ylabel("Focus Score")
plt.show()

상세 설명: 두 수치형 변수의 관계를 산점도로 확인한다.

예제 4. 시험 점수 분포 히스토그램

import matplotlib.pyplot as plt

scores = [55, 60, 65, 70, 70, 75, 80, 85, 90, 95]

plt.hist(scores, bins=5)
plt.title("Score Distribution")
plt.xlabel("Score")
plt.ylabel("Count")
plt.show()

상세 설명: 점수 분포를 구간별 빈도로 확인한다.

예제 5. 두 반의 성장 비교

import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4]
class_a = [70, 75, 80, 85]
class_b = [72, 74, 78, 83]

plt.plot(weeks, class_a, marker="o", label="Class A")
plt.plot(weeks, class_b, marker="o", label="Class B")
plt.title("Weekly Score Growth")
plt.xlabel("Week")
plt.ylabel("Score")
plt.legend()
plt.ylim(0, 100)
plt.show()

상세 설명: 두 반의 점수 변화 추세를 비교한다. y축을 0~100으로 두어 과장된 해석을 줄인다.
