3. 각각의 개념에 대한 상세 설명

1) 데이터 과학

데이터 과학은 현실 문제를 데이터로 표현하고, 수집·정제·분석·모델링·해석하여 의사결정을 돕는 융합 분야이다. 컴퓨터과학의 계산 능력, 수학·통계의 추론 능력, 과학의 탐구 태도, 인문학의 해석 능력이 함께 필요하다.

2) 문제 정의

데이터 분석은 질문에서 시작한다. “성적을 분석하자”보다 “학습 시간이 성취도와 어떤 관계가 있는가?”처럼 측정 가능한 질문으로 바꾸는 과정이 중요하다.

3) 데이터 수집

관찰, 설문, 센서, 공공데이터, 웹 로그 등에서 데이터를 모은다. 수집 단계에서는 표본의 대표성, 개인정보 보호, 측정 오류를 함께 고려한다.

4) 전처리

결측값, 이상값, 중복값, 단위 불일치를 정리하는 과정이다. 분석 결과의 신뢰성은 화려한 모델보다 올바른 전처리에 크게 좌우된다.

5) 탐색적 데이터 분석

평균, 중앙값, 분포, 상관관계, 그래프를 통해 데이터의 구조를 먼저 살펴보는 과정이다. 모델을 만들기 전 데이터를 이해하는 과학적 관찰 단계이다.

6) 모델링

데이터 속 규칙을 수식이나 알고리즘으로 표현하는 과정이다. 회귀, 분류, 군집화 등이 대표적이며 예측뿐 아니라 설명 가능성도 중요하다.

7) 해석과 의사결정

결과 숫자를 현실의 의미로 번역하는 과정이다. 높은 정확도만으로 충분하지 않고, 왜 그런 결과가 나왔는지 설명해야 한다.

8) 데이터 윤리

데이터는 사람의 행동과 삶을 반영하므로 편향, 차별, 프라이버시 침해가 발생할 수 있다. 데이터 과학자는 기술적 능력과 사회적 책임을 함께 가져야 한다.

4. 각각의 개념과 관련된 파이썬 코드

데이터 과학 흐름 전체 예시

import pandas as pd

# 1. 데이터 수집: 학생 학습 데이터를 표 형태로 생성
df = pd.DataFrame({
    'student': ['A', 'B', 'C', 'D', 'E'],
    'study_hour': [2, 4, 1, 5, 3],
    'score': [70, 85, 60, 95, 78]
})

# 2. 탐색: 평균 학습 시간과 평균 점수 확인
print('평균 학습 시간:', df['study_hour'].mean())
print('평균 점수:', df['score'].mean())

# 3. 간단한 해석: 학습 시간이 3시간 이상인 학생 추출
high_study = df[df['study_hour'] >= 3]
print(high_study)

# 4. 의사결정: 보충 지도가 필요한 학생 찾기
need_help = df[df['score'] < 75]
print('보충 지도 대상:', need_help['student'].tolist())
핵심: 데이터 과학은 데이터를 만들고 끝나는 것이 아니라, 질문을 세우고 분석한 뒤 의미 있는 행동으로 연결하는 과정이다.

개념별 미니 코드

# 문제 정의: 분석 질문을 변수로 표현
question = '학습 시간은 점수와 관련이 있는가?'
print(question)

# 전처리: 결측값을 평균으로 대체
scores = pd.Series([80, None, 90, 70])

print(scores.tolist())

# 탐색: 상관계수 확인
