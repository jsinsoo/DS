2. 수업을 여는 멘트

학교에는 매일 수많은 데이터가 생깁니다. 도서관을 얼마나 이용했는지, 어떤 급식을 좋아했는지, 동아리에 얼마나 참여했는지, 상담 신청이 어느 달에 늘었는지 같은 기록입니다. 하지만 이 데이터는 단순한 숫자가 아니라 학생들의 생활과 감정, 필요를 담고 있습니다. 인문 철학적으로 학교 생활 데이터 분석은 “학생을 평가하기 위한 데이터인가, 학생을 더 잘 돕기 위한 데이터인가?”라는 질문을 던집니다. 오늘 우리는 학교 데이터를 더 나은 학교를 만드는 근거로 활용하는 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 학교 생활 데이터

학교 생활 데이터는 출석, 지각, 급식 만족도, 도서관 이용, 동아리 활동, 학습 시간, 상담 신청, 시설 이용처럼 학교 안에서 발생하는 여러 활동 기록이다.

② 문제 정의

학교 생활 데이터 분석은 “학생들이 도서관을 언제 많이 이용할까?”, “급식 만족도는 어떤 메뉴에서 높을까?”처럼 구체적인 질문을 정하는 것에서 시작한다.

③ 출석 데이터

출석 데이터는 결석, 지각, 조퇴 같은 학교 생활 패턴을 보여 준다. 학생 개인을 낙인찍기보다 지원이 필요한 상황을 찾는 데 활용해야 한다.

④ 급식 만족도 데이터

급식 만족도 데이터는 메뉴별 선호도와 개선 의견을 분석하는 데 사용된다. 평균뿐 아니라 응답자 수와 의견의 다양성을 함께 봐야 한다.

⑤ 도서관 이용 데이터

도서관 방문 횟수, 대출 권수, 이용 시간대는 독서 문화와 학습 공간 활용을 이해하는 데 도움이 된다.

⑥ 학습 시간 데이터

학습 시간 데이터는 성적, 집중도, 수면 시간 등과 함께 분석될 수 있다. 그러나 학습 시간이 많다고 항상 성과가 높다고 단정할 수는 없다.

⑦ 동아리 활동 데이터

동아리 참여 시간, 활동 분야, 만족도는 학생 자율 활동과 진로 탐색을 이해하는 데 활용될 수 있다.

⑧ 데이터 전처리

학교 생활 데이터에는 기록 누락, 중복 입력, 잘못된 값이 있을 수 있다. 결측값과 이상값을 확인해야 정확한 분석이 가능하다.

⑨ 시각화와 해석

막대그래프는 반별·메뉴별 비교, 선그래프는 월별 변화, 산점도는 학습 시간과 성적 같은 두 변수의 관계를 표현하는 데 유용하다.

⑩ 개인정보와 윤리

학교 생활 데이터는 학생 개인의 생활과 관련되므로 익명화, 최소 수집, 목적 제한, 접근 권한 관리가 중요하다. 분석 결과는 낙인이 아니라 지원과 개선을 위해 사용되어야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 학교 생활 DataFrame 만들기

import pandas as pd

df = pd.DataFrame({
    "class": ["A", "A", "B", "B"],
    "library_visits": [5, 8, 3, 6],
    "study_hour": [12, 15, 10, 14],
    "satisfaction": [4, 5, 3, 4]
})

print(df)

반, 도서관 방문 횟수, 학습 시간, 만족도 데이터를 표 형태로 만든다.

② 요약 통계 확인

print(df[["library_visits", "study_hour", "satisfaction"]].describe())

학교 생활 데이터의 평균, 최솟값, 최댓값 등을 확인한다.

③ 반별 평균 만족도

print(df.groupby("class")["satisfaction"].mean())

반별 평균 만족도를 계산한다.

④ 도서관 이용이 많은 학생 찾기

active = df[df["library_visits"] >= 6]
print(active)

도서관 방문 횟수가 6회 이상인 데이터를 선택한다.

⑤ 학습 시간과 만족도 산점도

import matplotlib.pyplot as plt

plt.scatter(df["study_hour"], df["satisfaction"])
plt.title("Study Hour and Satisfaction")
plt.xlabel("Study Hour")
plt.ylabel("Satisfaction")
plt.show()

학습 시간과 만족도의 관계를 산점도로 살펴본다.

⑥ 반별 도서관 이용 막대그래프

summary = df.groupby("class")["library_visits"].mean()

summary.plot(kind="bar")
plt.title("Library Visits by Class")
plt.xlabel("Class")
plt.ylabel("Average Visits")
plt.show()

반별 평균 도서관 이용 횟수를 막대그래프로 비교한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 학교 생활 데이터를 통해 학생들의 생활과 학교 환경을 더 깊이 이해하는 방법을 배웠습니다. 컴퓨터과학은 데이터를 정리하고 분석하는 도구를 제공하고, 수학은 평균과 비교, 관계 분석을 설명하며, 과학은 관찰과 근거에 기반한 개선을 가능하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “데이터는 학생을 통제하기 위한 도구인가, 학생을 돕기 위한 언어인가?” 좋은 데이터 과학자는 학교 생활 데이터를 숫자로만 보지 않고, 그 뒤에 있는 학생의 삶과 존엄을 함께 존중하는 사람입니다.
