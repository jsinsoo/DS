2. 수업을 여는 멘트

날씨 앱에서 빨갛게 표시된 지역을 보면 우리는 즉시 “덥다” 또는 “위험하다”고 느낍니다. 지도 위 색 하나가 수많은 숫자보다 더 강한 인상을 줄 때가 있습니다. 인문 철학적으로 히트맵과 지도 시각화는 “공간과 색으로 세상을 해석하는 방식”입니다. 하지만 색이 강하다고 반드시 더 중요하다는 뜻은 아니며, 넓게 보이는 지역이 항상 더 큰 문제를 가진 것도 아닙니다. 오늘 우리는 색과 지도를 읽는 힘, 그리고 정직하게 표현하는 책임을 함께 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 히트맵

히트맵은 값의 크기를 색상이나 색의 진하기로 표현하는 시각화이다. 숫자가 많은 표에서 큰 값과 작은 값의 패턴을 빠르게 찾는 데 유용하다.

② 색상표

색상표는 값의 크기를 어떤 색으로 표현할지 정한 체계이다. 낮은 값에서 높은 값으로 색이 점점 변하는 연속형 색상표, 양수와 음수를 구분하는 발산형 색상표 등이 있다.

③ 범례

범례는 색이 어떤 값을 의미하는지 알려 주는 설명이다. 히트맵과 지도 시각화에서는 범례가 없으면 색의 의미를 정확히 해석하기 어렵다.

④ 상관행렬 히트맵

상관행렬은 여러 변수 사이의 상관계수를 표로 나타낸 것이다. 히트맵으로 표현하면 어떤 변수들이 강하게 관련되어 있는지 쉽게 파악할 수 있다.

⑤ 피벗 테이블 히트맵

피벗 테이블은 두 범주를 행과 열로 놓고 값을 요약한 표이다. 예를 들어 요일과 시간대별 이용자 수를 히트맵으로 나타내면 사람이 몰리는 시간대를 쉽게 볼 수 있다.

⑥ 지도 시각화

지도 시각화는 위치나 지역과 관련된 데이터를 지도 위에 표현하는 방법이다. 지역별 인구, 미세먼지, 교통량, 감염률, 시설 분포 등을 나타낼 수 있다.

⑦ 위도와 경도

위도와 경도는 지구상의 위치를 숫자로 나타내는 좌표이다. 지도 위에 점을 찍거나 위치 기반 데이터를 분석할 때 사용한다.

⑧ 단계구분도

단계구분도는 행정구역별 값을 색의 단계로 나타내는 지도이다. 지역별 비율이나 밀도를 표현하는 데 유용하지만, 지역 면적 차이 때문에 해석이 왜곡될 수 있다.

⑨ 시각화 윤리

히트맵과 지도는 색과 공간 때문에 강한 인상을 준다. 색 기준을 숨기거나, 특정 지역만 강조하거나, 절대값과 비율을 혼동하면 잘못된 판단을 유도할 수 있다.

4. 각각의 개념과 관련된 파이썬 코드

① 기본 히트맵

import matplotlib.pyplot as plt

data = [
    [10, 20, 30],
    [25, 35, 45],
    [40, 50, 60]
]

plt.imshow(data)
plt.title("Basic Heatmap")
plt.colorbar(label="Value")
plt.show()

2차원 숫자 데이터를 색으로 표현한다. colorbar는 색이 어떤 값을 의미하는지 알려 준다.

② 상관행렬 히트맵

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "study": [1, 2, 3, 4, 5],
    "score": [55, 65, 72, 83, 90],
    "sleep": [5, 6, 7, 8, 9]
})

corr = df.corr(numeric_only=True)

plt.imshow(corr)
plt.xticks(range(len(corr.columns)), corr.columns)
plt.yticks(range(len(corr.columns)), corr.columns)
plt.title("Correlation Heatmap")
plt.colorbar(label="Correlation")
plt.show()

변수 사이의 상관계수를 색으로 표현한다.

③ 피벗 테이블 만들기

import pandas as pd

df = pd.DataFrame({
    "day": ["Mon", "Mon", "Tue", "Tue"],
    "time": ["Morning", "Afternoon", "Morning", "Afternoon"],
    "users": [30, 50, 40, 60]
})

pivot = df.pivot_table(index="day", columns="time", values="users")
print(pivot)

요일과 시간대별 이용자 수를 표로 재구성한다.

④ 피벗 테이블 히트맵

import matplotlib.pyplot as plt

plt.imshow(pivot)

plt.yticks(range(len(pivot.index)), pivot.index)

plt.show()

요일과 시간대별 이용자 수를 색으로 표현하여 붐비는 패턴을 확인한다.

⑤ 위도·경도 산점도형 지도 시각화

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "city": ["Jeonju", "Iksan", "Gunsan"],
    "lat": [35.8242, 35.9483, 35.9677],
    "lon": [127.1480, 126.9576, 126.7369],
    "value": [70, 45, 60]
})

plt.scatter(df["lon"], df["lat"], s=df["value"] * 5)
plt.title("Location Based Visualization")
plt.xlabel("Longitude")
plt.ylabel("Latitude")
plt.show()

실제 지도 배경은 없지만, 위도와 경도를 이용해 위치 기반 점 시각화의 원리를 이해할 수 있다.

예제 5. 지도 시각화 해석 주의 예제

import pandas as pd

df = pd.DataFrame({
    "region": ["A", "B"],
    "cases": [100, 80],
    "population": [10000, 1000]
})

df["rate"] = df["cases"] / df["population"] * 100
print(df)

상세 설명: 단순 발생 수만 보면 A가 커 보이지만, 인구 대비 비율을 보면 B가 더 심각할 수 있다. 지도 시각화에서는 절대값과 비율을 구별해야 한다.

문항 9. 히트맵에서 값이 높은 부분을 빠르게 찾을 수 있는 이유는?
정답: 1번
상세풀이: 색으로 표현하면 큰 값과 작은 값의 패턴을 시각적으로 쉽게 볼 수 있다.
