2. 수업을 여는 멘트

학생 1명의 점수를 계산하는 것은 쉽습니다. 하지만 학생 1000명, 센서 1만 개, 이미지 픽셀 수백만 개를 하나씩 계산한다면 어떨까요? 데이터 과학은 많은 수를 빠르게 다루어야 합니다. NumPy는 수많은 값을 하나의 배열로 보고 한 번에 계산하게 해 주는 도구입니다. 인문 철학적으로 NumPy는 흩어진 수많은 값을 하나의 구조로 묶어 질서 있게 사고하는 방법입니다. 오늘 우리는 많은 숫자를 효율적으로 다루는 데이터 과학의 계산 언어를 배웁니다.

3. 각각의 개념에 대한 상세 설명

① NumPy

NumPy는 Numerical Python의 줄임말로, 파이썬에서 빠른 수치 계산과 배열 처리를 위해 사용하는 핵심 라이브러리이다.

② ndarray

ndarray는 NumPy의 핵심 자료구조로, 같은 자료형의 값을 n차원 배열 형태로 저장한다.

③ 배열 생성

np.array()를 이용해 리스트를 NumPy 배열로 바꿀 수 있다. 배열이 되면 원소별 연산을 쉽게 수행할 수 있다.

④ 벡터화 연산

벡터화 연산은 반복문 없이 배열 전체에 한 번에 연산을 적용하는 방식이다. 예를 들어 arr + 10은 배열의 모든 원소에 10을 더한다.

⑤ 인덱싱

인덱싱은 배열의 특정 위치 값을 선택하는 방법이다. NumPy 배열도 파이썬처럼 0번부터 시작한다.

⑥ 슬라이싱

슬라이싱은 배열의 일부 구간을 선택하는 방법이다. arr[1:4]는 인덱스 1부터 3까지 선택한다.

⑦ 배열 통계

np.mean(), np.sum(), np.max(), np.min(), np.std() 등을 이용해 배열의 평균, 합계, 최댓값, 최솟값, 표준편차를 계산할 수 있다.

⑧ 다차원 배열

NumPy는 1차원 배열뿐 아니라 행렬과 같은 2차원 배열도 다룰 수 있다. 데이터 표, 이미지, 센서 데이터 처리에 유용하다.

⑨ 난수 생성

np.random은 무작위 수를 생성하는 기능을 제공한다. 시뮬레이션, 표본 추출, 실험 데이터 생성에 활용된다.

⑩ 데이터 과학에서의 역할

NumPy는 Pandas, Matplotlib, scikit-learn 등 많은 데이터 과학 도구의 기반이 되며, 대량의 수치 데이터를 효율적으로 계산하게 해 준다.

4. 각각의 개념과 관련된 파이썬 코드

① NumPy 불러오기와 배열 생성

import numpy as np

arr = np.array([10, 20, 30])
print(arr)

리스트를 NumPy 배열로 변환한다.

② 벡터화 연산

import numpy as np

arr = np.array([10, 20, 30])
result = arr + 5

print(result)

배열의 모든 원소에 5를 더한다.

③ 인덱싱과 슬라이싱

import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print(arr[0])
print(arr[1:4])

첫 번째 원소와 일부 구간을 선택한다.

④ 배열 통계

import numpy as np

scores = np.array([70, 80, 90, 100])

print("mean:", np.mean(scores))
print("sum:", np.sum(scores))
print("std:", np.std(scores))

평균, 합계, 표준편차를 계산한다.

⑤ 2차원 배열

import numpy as np

matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])

print(matrix)
print(matrix.shape)

2행 3열 배열을 만들고 형태를 확인한다.

⑥ 난수 생성

import numpy as np

dice = np.random.randint(1, 7, 10)
print(dice)

주사위 눈처럼 1부터 6까지의 정수 10개를 무작위로 생성한다.

5. 실생활 관련 코드 예제 5개

예제 1. 시험 점수 평균과 표준편차

import numpy as np

scores = np.array([85, 90, 78, 92, 88])

print("mean:", np.mean(scores))
print("std:", np.std(scores))

상세 설명: 학생 점수 배열의 평균과 표준편차를 계산해 성적의 중심과 흩어짐을 확인한다.

예제 2. 모든 가격에 할인 적용

import numpy as np

prices = np.array([10000, 15000, 20000])
discounted = prices * 0.9

print(discounted)

상세 설명: 벡터화 연산으로 모든 상품 가격에 10% 할인을 한 번에 적용한다.

예제 3. 하루 걸음 수 분석

import numpy as np

steps = np.array([3500, 8200, 12000, 6500, 9000])

print("max:", np.max(steps))
print("min:", np.min(steps))
print("average:", np.mean(steps))

상세 설명: 걸음 수 데이터에서 최댓값, 최솟값, 평균을 계산한다.

예제 4. 온도 섭씨를 화씨로 변환

import numpy as np

celsius = np.array([0, 10, 20, 30])
fahrenheit = celsius * 9 / 5 + 32

print(fahrenheit)

상세 설명: 배열 전체에 같은 변환식을 적용해 섭씨를 화씨로 변환한다.

예제 5. 주사위 실험 시뮬레이션

import numpy as np

rolls = np.random.randint(1, 7, 100)
count_six = np.sum(rolls == 6)

print("six count:", count_six)

상세 설명: 주사위를 100번 던지는 실험을 난수로 시뮬레이션하고 6이 나온 횟수를 센다.

9. 수업을 마무리 하는 멘트

오늘 우리는 NumPy를 이용해 수치 데이터를 배열로 다루고, 벡터화 연산으로 빠르게 계산하는 방법을 배웠습니다. 컴퓨터과학은 효율적인 배열 구조와 연산을 제공하고, 수학은 벡터와 행렬, 평균과 표준편차의 의미를 설명하며, 과학은 많은 관찰값을 계산 가능한 자료로 바꾸게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “많은 숫자를 빠르게 계산할 때, 우리는 그 숫자가 나타내는 현실도 함께 이해하고 있는가?” 좋은 데이터 과학자는 빠른 계산뿐 아니라 계산의 의미까지 함께 해석하는 사람입니다.
