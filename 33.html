2. 수업을 여는 멘트

우리가 친구 명단을 엑셀 표로 저장할 때와, 날씨 앱이 서버에서 정보를 받아올 때 데이터의 모양은 다릅니다. CSV는 줄과 칸으로 정리된 노트 같고, JSON은 이름표가 붙은 상자들이 서로 들어 있는 구조 같습니다. 인문 철학적으로 데이터 형식은 기억을 담는 그릇입니다. 같은 사실도 어떤 그릇에 담느냐에 따라 찾기 쉽고, 해석하기 쉽고, 공유하기 쉬운 정도가 달라집니다. 오늘은 데이터가 어떤 형식으로 저장될 때 가장 잘 이해되고 활용되는지 배웁니다.

3. 각각의 개념에 대한 상세 설명

① CSV

CSV는 Comma-Separated Values의 약자로, 쉼표 등 구분자를 이용해 행과 열 형태의 데이터를 저장하는 텍스트 파일이다. 성적표, 출석부, 판매 기록처럼 표 구조가 분명한 데이터에 적합하다.

② 구분자

구분자는 값과 값을 나누는 기호이다. 일반적으로 쉼표를 쓰지만 탭, 세미콜론을 쓰는 경우도 있다. 데이터 안에 쉼표가 포함되면 따옴표 처리가 필요할 수 있다.

③ 인코딩

인코딩은 문자를 컴퓨터가 저장하는 방식이다. 한글 CSV 파일은 utf-8, utf-8-sig, cp949 등 인코딩 차이 때문에 깨질 수 있다. 파일을 읽고 쓸 때 인코딩을 확인해야 한다.

④ JSON

JSON은 JavaScript Object Notation의 약자로, key-value 구조를 이용해 데이터를 표현한다. 웹 API 응답, 설정 파일, 중첩된 데이터 저장에 자주 사용된다.

⑤ 객체와 배열

JSON 객체는 중괄호로 표현되는 key-value 묶음이며, 파이썬 딕셔너리와 유사하다. JSON 배열은 대괄호로 표현되는 값의 목록이며, 파이썬 리스트와 유사하다.

⑥ 중첩 구조

JSON은 객체 안에 배열, 배열 안에 객체를 넣을 수 있다. 예를 들어 학생 한 명의 이름, 점수 목록, 동아리 정보 등을 하나의 구조로 표현할 수 있다.

⑦ DataFrame

Pandas의 DataFrame은 표 형태 데이터를 다루는 핵심 구조이다. CSV는 DataFrame과 잘 연결되며, JSON도 정규화하면 DataFrame으로 변환할 수 있다.

⑧ 직렬화

직렬화는 파이썬 객체를 파일에 저장하거나 네트워크로 전송할 수 있는 문자열 형태로 바꾸는 과정이다. json.dump는 파이썬 객체를 JSON 파일로 저장하는 직렬화 기능이다.

⑨ 형식 선택

행과 열이 단순하고 분석 중심이면 CSV가 편리하다. 데이터가 계층적이고 웹 API와 주고받아야 한다면 JSON이 적합하다. 데이터 형식 선택은 데이터 구조와 활용 목적에 따라 달라진다.

4. 각각의 개념과 관련된 파이썬 코드

① CSV 저장

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "점수": [95, 82, 88]
})

df.to_csv("score.csv", index=False, encoding="utf-8-sig")
print("CSV 저장 완료")

DataFrame을 CSV 파일로 저장한다. index=False는 불필요한 인덱스 열 저장을 막는다.

② CSV 읽기

import pandas as pd

df = pd.read_csv("score.csv", encoding="utf-8-sig")
print(df)

CSV 파일을 다시 DataFrame으로 읽는다.

③ JSON 저장

import json

student = {
    "이름": "가은",
    "점수": [95, 90, 88],
    "동아리": "데이터분석반"
}

with open("student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, ensure_ascii=False, indent=2)

print("JSON 저장 완료")

딕셔너리와 리스트를 포함한 파이썬 객체를 JSON 파일로 저장한다.

④ JSON 읽기

import json

with open("student.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data["이름"])
print(data["점수"])

JSON 파일을 읽어 딕셔너리처럼 key로 값을 꺼낸다.

⑤ JSON을 DataFrame으로 변환

import pandas as pd

data = [
    {"이름": "가은", "점수": 95},
    {"이름": "나래", "점수": 82}
]

df = pd.DataFrame(data)
print(df)

리스트 안에 딕셔너리가 들어 있는 JSON형 데이터를 표 형태로 바꾼다.

5. 실생활 관련 코드 예제 5개

예제 1. 학생 성적 CSV 저장

import pandas as pd

df = pd.DataFrame({
    "학번": [101, 102, 103],
    "이름": ["가은", "나래", "다온"],
    "평균": [92.5, 84.0, 88.5]
})
df.to_csv("students.csv", index=False, encoding="utf-8-sig")
print(df)

상세 설명: 행과 열이 분명한 학생 성적 데이터는 CSV로 저장하기 좋다.

예제 2. 앱 설정 JSON 저장

import json

settings = {"theme": "light", "font_size": 16, "alarm": True}

with open("settings.json", "w", encoding="utf-8") as f:
    json.dump(settings, f, ensure_ascii=False, indent=2)

print("설정 저장 완료")

상세 설명: 앱 설정처럼 key-value 구조가 분명한 데이터는 JSON으로 저장하기 적합하다.

예제 3. 날씨 API 응답 흉내 내기

weather = {
    "city": "Jeonju",
    "temperature": 23,
    "dust": {"pm10": 35, "grade": "보통"}
}

print(weather["city"])
print(weather["dust"]["grade"])

상세 설명: JSON의 중첩 구조에서 필요한 값을 꺼내는 예이다.

예제 4. CSV 자료형 확인

import pandas as pd

df = pd.DataFrame({"상품": ["사과", "바나나"], "가격": ["1200", "900"]})
df["가격"] = df["가격"].astype(int)

print(df.dtypes)
print(df["가격"].mean())

상세 설명: 숫자가 문자열로 저장되면 계산이 어려우므로 정수형으로 변환한다.

예제 5. JSON 목록을 표로 바꾸기

import pandas as pd

books = [
    {"제목": "데이터 과학", "분야": "정보"},
    {"제목": "통계 기초", "분야": "수학"}
]

df = pd.DataFrame(books)
print(df)

상세 설명: JSON 형식의 목록을 DataFrame으로 바꾸면 정렬, 필터링, 저장이 쉬워진다.
