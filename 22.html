2. 수업을 여는 멘트

우리가 오늘 아침 확인한 날씨, 미세먼지, 버스 도착 시간, 학교 주변 교통량은 단순한 숫자가 아닙니다. 그 숫자들은 공공기관이 시민의 삶을 더 안전하고 편리하게 만들기 위해 모은 기록입니다. 철학적으로 보면 공공데이터는 “공동체가 함께 남긴 기억”입니다. 데이터를 읽는다는 것은 사회가 남긴 흔적을 해석하는 일이고, 좋은 데이터 과학자는 그 흔적을 이용해 더 공정하고 지혜로운 선택을 돕는 사람입니다.

3. 각각의 개념에 대한 상세 설명

① 공공데이터

공공데이터는 중앙정부, 지방자치단체, 공공기관 등이 업무 수행 과정에서 생성하거나 관리하는 데이터이다. 예를 들어 기상 정보, 교통 정보, 인구 통계, 학교 현황, 대기오염 정보 등이 있다. 공공데이터는 시민, 기업, 연구자, 학생이 활용하여 새로운 서비스와 정책 아이디어를 만들 수 있다는 점에서 사회적 가치가 크다.

② 공공데이터 포털

공공데이터 포털은 여러 공공기관의 데이터를 한곳에서 검색하고 다운로드하거나 API로 호출할 수 있도록 제공하는 플랫폼이다. 학생들은 포털에서 데이터의 제목뿐 아니라 제공기관, 갱신 주기, 파일 형식, 활용 조건, 설명 자료를 함께 확인해야 한다.

③ CSV 데이터

CSV는 쉼표로 구분된 표 형식 데이터이다. 엑셀처럼 행과 열로 이루어진 데이터를 저장할 때 자주 쓰이며, 파이썬의 Pandas로 쉽게 읽고 분석할 수 있다. 다만 인코딩 문제, 결측값, 열 이름 불일치 등을 주의해야 한다.

④ 오픈 API

오픈 API는 사용자가 정해진 주소와 매개변수를 이용하여 실시간 또는 최신 데이터를 요청할 수 있게 해 주는 방식이다. 버스 도착 정보, 날씨 정보, 미세먼지 정보처럼 자주 바뀌는 데이터에 적합하다. API를 사용할 때는 인증키, 요청 제한, 응답 형식(JSON/XML)을 확인해야 한다.

⑤ 메타데이터

메타데이터는 데이터에 대한 데이터이다. 데이터의 제공기관, 생성일, 갱신일, 단위, 열의 의미, 수집 방법 등을 설명한다. 메타데이터를 확인하지 않으면 숫자의 의미를 잘못 해석할 수 있다.

⑥ 데이터 품질

공공데이터라고 해서 항상 완벽한 것은 아니다. 결측값, 중복값, 오래된 데이터, 단위 불일치, 오탈자 등이 있을 수 있다. 데이터 과학자는 데이터를 그대로 믿기보다 품질을 점검하고 분석 목적에 맞게 정제해야 한다.

⑦ 라이선스와 출처 표기

공공데이터는 개방되어 있지만 아무렇게나 사용할 수 있는 것은 아니다. 활용 조건, 저작권, 출처 표기, 상업적 이용 가능 여부를 확인해야 한다. 좋은 데이터 활용은 기술적 능력뿐 아니라 책임 있는 태도에서 시작된다.

⑧ 개인정보 보호

공공데이터에 개인을 식별할 수 있는 정보가 포함되어서는 안 된다. 이름, 전화번호, 주소뿐 아니라 여러 데이터를 결합했을 때 특정 개인을 추정할 수 있는 정보도 조심해야 한다. 데이터 활용의 목적이 공익적이어도 개인의 권리를 침해해서는 안 된다.

4. 각각의 개념과 관련된 파이썬 코드

① CSV 공공데이터 읽기

import pandas as pd

df = pd.read_csv("public_data.csv", encoding="utf-8")
print(df.head())

CSV 파일을 Pandas DataFrame으로 읽어 처음 5행을 확인한다. 실제 공공데이터 파일은 인코딩이 cp949인 경우도 있으므로 오류가 나면 encoding="cp949"를 시도할 수 있다.

② 열 이름과 기본 정보 확인

print(df.columns)
print(df.info())

열 이름과 데이터 형식을 확인한다. 분석 전에 어떤 항목이 있고 숫자형·문자형이 어떻게 저장되어 있는지 파악하는 단계이다.

③ 결측값 확인

missing = df.isna().sum()
print(missing)

각 열에 비어 있는 값이 몇 개 있는지 확인한다. 결측값이 많으면 평균, 합계, 비율 계산이 왜곡될 수 있다.

④ 지역별 데이터 집계

result = df.groupby("지역")["이용자수"].sum()
print(result)

지역별 이용자 수를 합산한다. 공공시설 이용 현황, 교통량, 관광객 수 등을 지역 단위로 비교할 때 사용할 수 있다.

⑤ JSON 형태 API 응답 이해

sample = {
    "city": "Jeonju",
    "temperature": 23,
    "pm10": 35
}

print(sample["city"])
print(sample["pm10"])

API 응답은 JSON 구조로 제공되는 경우가 많다. 딕셔너리의 key를 이용해 원하는 값을 꺼내는 연습이다.

5. 실생활 관련 코드 예제 5개

예제 1. 지역별 도서관 이용자 수 분석

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "익산", "군산", "전주", "익산"],
    "도서관": ["A", "B", "C", "D", "E"],
    "이용자수": [1200, 850, 930, 1500, 760]
})

result = df.groupby("지역")["이용자수"].sum()
print(result)

상세 설명: 지역별 공공도서관 이용자 수를 합산한다. 공공시설을 어디에 확충해야 하는지 판단할 때 근거 자료가 될 수 있다.

예제 2. 미세먼지 등급 분류

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "서울", "부산", "대전"],
    "PM10": [28, 82, 45, 110]
})

def grade(pm10):
    if pm10 <= 30:
        return "좋음"
    elif pm10 <= 80:
        return "보통"
    elif pm10 <= 150:
        return "나쁨"
    return "매우 나쁨"

df["등급"] = df["PM10"].apply(grade)
print(df)

상세 설명: 미세먼지 수치를 기준에 따라 등급으로 바꾼다. 숫자를 사람이 이해하기 쉬운 정보로 변환하는 과정이다.

예제 3. 버스 도착 정보 구조 이해

bus = [
    {"노선": "101", "정류장": "전북과학고", "도착분": 3},
    {"노선": "165", "정류장": "전북과학고", "도착분": 8},
    {"노선": "970", "정류장": "전북과학고", "도착분": 15}
]

soon = [b for b in bus if b["도착분"] <= 10]
print(soon)

상세 설명: API에서 받은 버스 도착 정보를 리스트와 딕셔너리 구조로 가정하고, 10분 이내 도착 버스만 필터링한다.

예제 4. 공공데이터 결측값 점검

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "익산", "군산", None],
    "강수량": [12.5, None, 5.0, 9.2]
})

print(df.isna().sum())

상세 설명: 공공데이터에 비어 있는 값이 있는지 확인한다. 결측값을 점검해야 잘못된 평균이나 통계를 줄일 수 있다.

예제 5. 공공데이터 출처 문구 만들기

상세 설명: 데이터 분석 결과를 발표할 때 출처를 명확히 밝히는 습관을 기른다. 출처 표기는 데이터 윤리의 기본이다.
