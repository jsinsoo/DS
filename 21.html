핵심 개념

데이터는 형태, 의미, 생성 방식, 수집 목적에 따라 구분되며, 데이터의 종류를 이해하면 적절한 수집·분석·해석 방법을 선택할 수 있다.

핵심 질문

같은 현상도 왜 서로 다른 종류의 데이터로 표현될 수 있을까?

데이터의 종류를 잘못 이해하면 어떤 분석 오류가 생길까?

지식 목표

정형·반정형·비정형 데이터, 양적·질적 데이터, 1차·2차 데이터, 시계열·범주형 데이터의 뜻을 설명한다.

기능 목표

주어진 데이터 사례를 분류하고, 파이썬으로 데이터 형식과 기본 특징을 확인한다.

태도 목표

데이터가 사회적 맥락 속에서 만들어진다는 점을 이해하고, 책임 있는 수집 태도를 가진다.

평가 방법

진단평가 OX, 형성평가 5지선다형, 실생활 코드 분석 과제, 수업 참여 관찰을 종합한다.

단계활동교사·학생 활동
도입생활 속 데이터 찾기날씨, 성적, 사진, 댓글, 위치 기록을 제시하고 데이터 종류를 예상한다.
전개 1개념 탐구형태·의미·출처·시간 기준으로 데이터를 분류한다.
전개 2파이썬 실습DataFrame, JSON, 텍스트, 이미지 파일명을 예로 들어 데이터 구조를 확인한다.
정리개념 연결데이터 종류와 분석 방법의 관계를 토의한다.
평가자동 채점OX와 5지선다형을 풀고 TXT 결과 파일을 저장한다.

🔍 각각의 개념에 대한 상세 설명

1. 정형 데이터

행과 열처럼 일정한 구조를 가진 데이터입니다. 성적표, 출석부, 매출표처럼 표 형태로 저장하기 쉽고, 통계 분석이나 데이터베이스 처리에 적합합니다.

표DBCSV

2. 반정형 데이터

완전한 표 구조는 아니지만 태그나 키-값 구조처럼 일정한 규칙이 있는 데이터입니다. JSON, XML, HTML 문서가 대표적입니다.

JSONXML키-값

3. 비정형 데이터

정해진 행·열 구조가 없는 데이터입니다. 사진, 음성, 동영상, 자유 서술형 글, SNS 댓글 등이 포함됩니다. 인공지능 분석에서 매우 중요합니다.

이미지음성텍스트

4. 양적 데이터

숫자로 측정할 수 있는 데이터입니다. 키, 몸무게, 온도, 시간, 점수처럼 계산과 비교가 가능합니다.

수치형평균분산

5. 질적 데이터

분류나 특성을 나타내는 데이터입니다. 혈액형, 선호 과목, 만족도 등은 숫자가 붙어도 본질적으로 범주를 뜻할 수 있습니다.

범주형분류

6. 1차 데이터

연구자나 분석자가 목적에 맞게 직접 수집한 데이터입니다. 직접 설문, 실험 측정, 센서 수집 자료가 예입니다.

직접 수집설문

7. 2차 데이터

이미 다른 목적을 위해 수집되어 공개되거나 보관된 데이터입니다. 공공데이터, 논문 자료, 기존 통계 자료가 예입니다.

공공데이터기존 자료

8. 시계열 데이터

시간 순서에 따라 기록된 데이터입니다. 기온 변화, 주가, 심박수, 미세먼지 농도처럼 시간 흐름 분석이 중요합니다.

시간추세

✅ 진단평가 OX 예제 10개

OX 1. 정형 데이터는 보통 행과 열의 구조를 가진다.
정답: O
성적표나 매출표처럼 표 구조를 가지므로 O입니다.
OX 2. 비정형 데이터는 항상 숫자로만 이루어진다.
정답: X
이미지, 음성, 동영상, 자유 텍스트처럼 숫자가 아닌 경우가 많습니다.
OX 3. JSON은 반정형 데이터의 예로 볼 수 있다.
정답: O
키-값 구조라는 규칙이 있으므로 반정형 데이터입니다.
OX 4. 양적 데이터는 계산과 비교가 가능한 수치 데이터이다.
정답: O
온도, 점수, 길이처럼 평균이나 합계를 구할 수 있습니다.
OX 5. 질적 데이터는 반드시 평균을 구해야 의미가 있다.
정답: X
질적 데이터는 범주나 특성을 나타내므로 빈도나 비율이 더 적절할 수 있습니다.
OX 6. 직접 설문조사로 얻은 자료는 1차 데이터가 될 수 있다.
정답: O
분석 목적에 맞게 직접 수집한 자료이므로 1차 데이터입니다.
OX 7. 공공기관이 이미 공개한 통계자료는 2차 데이터로 활용될 수 있다.
정답: O
기존에 수집된 자료를 활용하므로 2차 데이터입니다.
OX 8. 시계열 데이터는 시간 순서가 중요하지 않다.
정답: X
시계열 데이터는 시간 흐름과 순서가 핵심입니다.
OX 9. SNS 댓글은 비정형 텍스트 데이터의 예이다.
정답: O
자유롭게 작성된 문장이므로 비정형 데이터입니다.
OX 10. 데이터의 종류를 알면 분석 방법을 선택하는 데 도움이 된다.
정답: O
데이터 특성에 따라 통계, 시각화, 모델링 방법이 달라집니다.

📝 형성평가 5지선다형 10개

문항 1. 다음 중 정형 데이터에 가장 가까운 것은?
정답: 1번
성적표는 행과 열이 있는 표 형태입니다.
문항 2. 반정형 데이터의 대표 예는?
정답: 1번
JSON은 키-값 구조를 가진 반정형 데이터입니다.
문항 3. 비정형 데이터에 해당하지 않는 것은?
정답: 1번
출석부 표는 정형 데이터입니다.
문항 4. 양적 데이터의 예로 가장 적절한 것은?
정답: 1번
기온은 숫자로 측정하고 평균을 구할 수 있습니다.
문항 5. 질적 데이터 분석에 자주 쓰이는 방법은?
정답: 1번
질적 데이터는 범주별 빈도와 비율을 살펴보기 좋습니다.
문항 6. 1차 데이터에 대한 설명으로 옳은 것은?
정답: 1번
직접 설문, 실험, 센서 측정 등이 1차 데이터입니다.
문항 7. 2차 데이터의 예로 가장 적절한 것은?
정답: 1번
이미 기관이 수집해 공개한 자료를 활용하면 2차 데이터입니다.
문항 8. 시계열 데이터에서 가장 중요한 요소는?
정답: 1번
시계열 데이터는 시간 순서에 따른 변화 분석이 핵심입니다.
문항 9. 데이터 종류를 구분해야 하는 이유는?
정답: 1번
데이터 종류에 따라 전처리, 시각화, 모델링 방법이 달라집니다.
문항 10. 다음 중 질적 데이터에 가까운 것은?
정답: 1번
선호 과목은 범주를 나타내므로 질적 데이터입니다.

🌏 실생활 관련 코드예제 5개

예제 1. 급식 만족도 데이터 분류

import pandas as pd

df = pd.DataFrame({"메뉴": ["비빔밥", "카레", "국수"], "만족도": [5, 4, 3]})
print("정형 데이터")
print(df.describe())

메뉴는 질적 데이터, 만족도는 수치로 계산 가능한 양적 데이터입니다.

예제 2. 날씨 센서 데이터

temps = [18.2, 19.0, 21.3, 20.1]
print("평균 기온:", sum(temps) / len(temps))

센서가 직접 측정한 값이므로 1차 데이터이며, 숫자형 양적 데이터입니다.

예제 3. 공공데이터 활용 여부 표시

source = "공공데이터포털"
kind = "2차 데이터"
print(source, "자료는", kind, "로 볼 수 있습니다.")

이미 기관이 수집해 공개한 자료는 보통 2차 데이터로 활용합니다.

예제 4. SNS 댓글 길이 분석

comments = ["좋아요", "설명이 친절해요", "다시 보고 싶어요"]
lengths = [len(c) for c in comments]
print(lengths)

SNS 댓글은 비정형 텍스트 데이터이지만 길이처럼 수치 특징으로 변환할 수 있습니다.

예제 5. 시간 순서 미세먼지 데이터

dust = [("09:00", 35), ("10:00", 42), ("11:00", 39)]
for time, value in dust:
    print(time, value)

시간에 따라 기록된 미세먼지 수치는 시계열 데이터입니다.
