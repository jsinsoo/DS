3. 각각의 개념에 대한 상세 설명

데이터
관찰, 측정, 조사, 센서, 설문, 거래 기록 등으로 얻은 원자료입니다. 예: 18, 21, 23이라는 온도 값, 학생별 수면 시간, 웹사이트 클릭 수.
정보
데이터를 목적에 맞게 정리하고 해석하여 의미를 만든 것입니다. 예: “오늘 평균 기온은 20.7도이므로 어제보다 따뜻하다.”
맥락
데이터가 만들어진 상황입니다. 같은 90점도 쉬운 시험인지 어려운 시험인지, 평균이 얼마인지에 따라 의미가 달라집니다.
데이터 유형
수치형, 범주형, 문자형, 날짜·시간형, 이미지·음성 같은 비정형 데이터가 있습니다. 유형에 따라 분석 방법이 달라집니다.
데이터 품질
정확성, 완전성, 일관성, 최신성, 관련성이 중요합니다. 결측치나 오류가 많으면 그럴듯한 그래프도 잘못된 정보를 줄 수 있습니다.
데이터 처리 과정
수집 → 저장 → 정제 → 분석 → 시각화 → 해석 → 의사결정의 흐름을 거칩니다.
메타데이터
데이터를 설명하는 데이터입니다. 예: 측정 날짜, 단위, 출처, 수집 방법. 데이터의 신뢰도를 판단하는 단서가 됩니다.
데이터 윤리
개인정보 보호, 편향 방지, 해석의 공정성, 출처 표시, 책임 있는 사용을 포함합니다.

4. 각각의 개념과 관련된 Python 코드

① 데이터와 정보: 평균 온도 구하기

temperatures = [18, 21, 23, 20, 22]
avg = sum(temperatures) / len(temperatures)
print(f"평균 기온 정보: {avg:.1f}도")
숫자 목록은 데이터이고, 평균을 계산해 “평균 기온”이라는 의미로 표현하면 정보가 됩니다.

② 맥락: 평균과 비교하기

score = 90
class_avg = 82
if score > class_avg:
    print("평균보다 높은 성취")
else:
    print("추가 학습 필요")
90이라는 점수는 맥락 없이 보면 단순 데이터입니다. 학급 평균과 비교하면 성취 수준이라는 정보가 됩니다.

③ 데이터 유형 확인

data = ["전주", 18.5, 70, True]
for item in data:
    print(item, type(item))
문자, 실수, 정수, 논리형처럼 데이터 유형을 확인하면 적절한 처리 방법을 선택할 수 있습니다.

④ 데이터 품질: 결측치 처리

sleep_hours = [7, None, 6, 8, None, 5]
cleaned = [x for x in sleep_hours if x is not None]
print("평균 수면 시간:", sum(cleaned) / len(cleaned))
비어 있는 값(None)을 그대로 계산하면 오류가 납니다. 정제 과정은 신뢰할 수 있는 정보를 만들기 위한 필수 단계입니다.

⑤ 메타데이터와 출처 표시

record = {
    "value": 23.4,
    "unit": "℃",
    "source": "학교 운동장 온도 센서",
    "date": "2026-05-19"
}
print(f"{record['date']} {record['source']}: {record['value']}{record['unit']}")
값뿐 아니라 단위, 출처, 날짜를 함께 저장하면 데이터의 의미와 신뢰도를 판단하기 쉬워집니다.

5. 실생활 관련 코드예제 5개 상세설명 포함

예제 1. 스마트폰 사용 시간 분석

apps = {"학습": 50, "메신저": 80, "영상": 120, "게임": 40}
total = sum(apps.values())
for app, minutes in apps.items():
    print(app, f"{minutes/total*100:.1f}%")
앱별 사용 시간 데이터에서 전체 대비 비율 정보를 만듭니다. 디지털 습관을 스스로 성찰할 수 있습니다.

예제 2. 급식 만족도 평균

ratings = [5, 4, 3, 5, 4, 2, 5]
print("급식 만족도 평균:", round(sum(ratings) / len(ratings), 2))
개별 평가 점수는 데이터이고, 평균 만족도는 학교 의사결정에 활용 가능한 정보입니다.

예제 3. 미세먼지 상태 분류

pm10 = 82
if pm10 <= 30:
    state = "좋음"
elif pm10 <= 80:
    state = "보통"
else:
    state = "나쁨"
print("미세먼지 상태:", state)
측정값을 기준에 따라 분류하면 행동 지침으로 바꿀 수 있습니다. 단, 기준의 출처와 최신성도 확인해야 합니다.

예제 4. 독서 기록에서 최다 분야 찾기

books = ["과학", "문학", "과학", "역사", "과학", "철학", "문학"]
counts = {}
for b in books:
    counts[b] = counts.get(b, 0) + 1
print("가장 많이 읽은 분야:", max(counts, key=counts.get))
반복 기록을 세어 개인의 관심 분야라는 정보를 얻습니다. 데이터는 자기 이해의 도구가 될 수 있습니다.

예제 5. 통학 시간 이상값 찾기

times = [25, 27, 26, 90, 24, 28]
avg = sum(times) / len(times)
for t in times:
    if t > avg * 2:
        print("이상하게 긴 통학 시간:", t, "분")
평소와 크게 다른 값은 오류일 수도 있고 특별한 사건일 수도 있습니다. 이상값은 삭제하기 전에 원인을 확인해야 합니다.

6. 진단평가 OX 예제 10개 — 상세풀이 포함

1. 데이터는 관찰하거나 측정하여 얻은 원자료이다.
정답 O — 데이터는 온도, 점수, 문자 기록처럼 관찰·측정·기록된 값이다.
2. 정보는 언제나 데이터보다 양이 많아야 한다.
정답 X — 정보는 양이 아니라 의미와 목적이 중요하다. 적은 데이터도 잘 해석되면 정보가 된다.
3. 같은 데이터도 맥락에 따라 다르게 해석될 수 있다.
정답 O — 90점은 시험 난이도, 평균, 평가 기준에 따라 의미가 달라진다.
4. 데이터 품질이 낮아도 시각화만 예쁘면 신뢰할 수 있다.
정답 X — 오류와 결측이 많은 데이터는 예쁜 그래프라도 잘못된 판단을 만들 수 있다.
5. 메타데이터는 데이터의 출처, 단위, 수집 시각 등을 설명한다.
정답 O — 메타데이터는 데이터를 해석하는 설명 정보이다.
6. 수치형 데이터만 데이터 과학에서 사용할 수 있다.
정답 X — 문자, 이미지, 음성, 날짜, 위치 등 다양한 데이터가 사용된다.
7. 데이터 정제는 분석 전에 오류나 결측값을 다루는 과정이다.
정답 O — 정제는 신뢰할 수 있는 분석을 위한 준비 단계이다.
8. 정보는 의사결정에 도움을 주는 의미 있는 해석이다.
정답 O — 데이터를 목적에 맞게 해석하면 정보가 된다.
9. 개인정보가 포함된 데이터는 윤리와 무관하게 자유롭게 분석해도 된다.
정답 X — 개인정보 보호와 동의, 목적 제한이 필요하다.
10. 데이터 과학에서는 질문을 세우는 과정도 중요하다.
정답 O — 좋은 질문이 있어야 필요한 데이터와 분석 방법을 정할 수 있다.
