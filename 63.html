1. 개념기반 목표지향 수업지도안

핵심 개념
지도학습은 정답 레이블을 이용해 예측 규칙을 학습하고, 비지도학습은 정답 없이 데이터의 숨은 구조와 유사성을 찾는다.
일반화된 이해
학습 방법은 데이터에 정답이 있는지, 예측이 목적인지, 구조 탐색이 목적인지에 따라 달라진다.
핵심 질문
컴퓨터에게 정답을 알려 주고 배우게 할 것인가, 아니면 스스로 비슷한 것끼리 찾아보게 할 것인가?

2. 수업을 여는 멘트

선생님이 문제와 정답을 함께 보여 주며 가르치는 경우가 있습니다. 이것은 지도학습과 닮았습니다. 반대로 정답을 주지 않고 여러 자료를 펼쳐 놓은 뒤 “비슷한 것끼리 묶어 보자”라고 하면, 이것은 비지도학습과 닮았습니다. 인문 철학적으로 지도학습과 비지도학습은 “배움에는 정답이 먼저 필요한가, 아니면 관찰을 통해 구조를 발견할 수 있는가?”라는 질문을 던집니다. 오늘 우리는 컴퓨터가 정답을 보고 배우는 방식과, 정답 없이 패턴을 찾아가는 방식을 비교해 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 지도학습

지도학습은 입력 데이터와 정답 레이블이 함께 주어진 상태에서 모델을 학습시키는 방법이다. 모델은 특징과 레이블 사이의 관계를 배워 새로운 데이터의 정답을 예측한다.

② 비지도학습

비지도학습은 정답 레이블 없이 데이터의 숨은 구조, 유사성, 군집, 패턴을 찾는 방법이다. 모델이 찾아낸 결과의 의미는 사람이 맥락 속에서 해석해야 한다.

③ 특징

특징은 모델이 판단에 사용하는 입력 변수이다. 예를 들어 학생 데이터에서는 공부 시간, 수면 시간, 과제 제출 횟수 등이 특징이 될 수 있다.

④ 레이블

레이블은 지도학습에서 모델이 맞히려는 정답 값이다. 합격/불합격, 스팸/정상, 실제 점수, 실제 가격 등이 레이블이 될 수 있다.

⑤ 분류

분류는 데이터를 정해진 범주 중 하나로 예측하는 지도학습 문제이다. 이메일 스팸 분류, 이미지 고양이/강아지 분류, 질병 양성/음성 판단이 예이다.

⑥ 회귀

회귀는 연속적인 숫자 값을 예측하는 지도학습 문제이다. 집값, 온도, 시험 점수, 매출액처럼 수치형 결과를 예측한다.

⑦ 군집화

군집화는 정답 없이 비슷한 데이터끼리 묶는 비지도학습 방법이다. 고객 세분화, 문서 묶기, 이미지 패턴 탐색 등에 활용된다.

⑧ 차원 축소

차원 축소는 많은 특징을 더 적은 수의 특징으로 줄여 데이터 구조를 쉽게 파악하도록 돕는 비지도학습 방법이다. 시각화나 노이즈 감소에 활용될 수 있다.

⑨ 해석과 윤리

지도학습은 레이블의 편향을 배울 수 있고, 비지도학습은 사람이 군집에 부여한 의미가 편견을 만들 수 있다. 따라서 데이터의 출처와 해석 기준을 투명하게 확인해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 지도학습 데이터 구조

import pandas as pd

df = pd.DataFrame({
    "study_hour": [1, 2, 3, 4],
    "sleep_hour": [6, 7, 7, 8],
    "pass": ["No", "No", "Yes", "Yes"]
})

X = df[["study_hour", "sleep_hour"]]
y = df["pass"]

print(X)
print(y)

study_hour와 sleep_hour는 특징이고, pass는 정답 레이블이다.

② 간단한 분류 규칙

study_hour = 4

if study_hour >= 3:
    result = "Pass"
else:
    result = "Fail"

print(result)

공부 시간이 3시간 이상이면 합격으로 분류하는 단순 규칙 예제이다.

③ 간단한 회귀 예측

study_hour = 5

predicted_score = 50 + study_hour * 8
print("Predicted score:", predicted_score)

공부 시간을 이용해 점수라는 숫자 값을 예측한다. 이는 회귀 문제의 기초 예이다.

④ 비지도학습: 유사도 기반 묶기

students = {
    "A": 2,
    "B": 3,
    "C": 9,
    "D": 10
}

low_group = []
high_group = []

for name, hour in students.items():
    if hour < 5:
        low_group.append(name)
    else:
        high_group.append(name)

print("Low study group:", low_group)
print("High study group:", high_group)

정답 레이블 없이 공부 시간이 비슷한 학생끼리 묶는 군집화 아이디어를 보여 준다.

⑤ 군집 중심과 거리 개념

point = 7
center_a = 3
center_b = 9

distance_a = abs(point - center_a)
distance_b = abs(point - center_b)

if distance_a < distance_b:
    print("Group A")
else:
    print("Group B")

새로운 값이 어느 군집 중심에 더 가까운지 거리로 판단한다.

5. 실생활 관련 코드 예제 5개

예제 1. 스팸 메일 지도학습 예시

message = "free prize now"

if "free" in message or "prize" in message:
    print("Spam")
else:
    print("Normal")

상세 설명: 스팸/정상이라는 정답 범주를 예측하는 분류 문제이다. 실제 모델은 많은 메일 데이터로 학습한다.

예제 2. 공부 시간 기반 점수 회귀

study_hour = 6
score = 45 + study_hour * 7

print("Predicted score:", score)

상세 설명: 점수라는 숫자를 예측하므로 회귀 문제이다.

예제 3. 고객 구매 패턴 군집화

customers = {
    "C1": 2,
    "C2": 3,
    "C3": 12,
    "C4": 15
}

small_buyers = [k for k, v in customers.items() if v < 5]
big_buyers = [k for k, v in customers.items() if v >= 5]

print("Small buyers:", small_buyers)
print("Big buyers:", big_buyers)

상세 설명: 정답 없이 구매 횟수가 비슷한 고객을 묶는 비지도학습 아이디어이다.

예제 4. 뉴스 기사 관심 분야 묶기

articles = {
    "A": "AI data model",
    "B": "machine learning data",
    "C": "soccer player goal",
    "D": "baseball team win"
}

tech = []
sports = []

for title, text in articles.items():
    if "data" in text or "model" in text:
        tech.append(title)
    else:
        sports.append(title)

print("Tech-like:", tech)
print("Sports-like:", sports)

상세 설명: 문서의 단어 특징을 기준으로 비슷한 기사끼리 묶는 군집화의 기초 아이디어를 보여 준다.

예제 5. 지도학습과 비지도학습 선택

has_label = True
goal = "predict"

if has_label and goal == "predict":
    print("Use supervised learning")
else:
    print("Use unsupervised learning")

상세 설명: 정답 레이블이 있고 예측이 목적이면 지도학습이 적합하다. 숨은 구조를 찾고 싶다면 비지도학습을 고려한다.

OX 10. 지도학습과 비지도학습은 데이터의 목적과 정답 레이블 유무에 따라 선택한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 머신러닝이 정답을 보고 배우는 지도학습과, 정답 없이 구조를 찾는 비지도학습으로 나뉠 수 있음을 배웠습니다. 컴퓨터과학은 학습 알고리즘을 구현하고, 수학은 거리·함수·확률로 패턴을 설명하며, 과학은 예측과 군집이 실제 세계에서 타당한지 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “누가 정답을 정하고, 누가 비슷함의 기준을 정하는가?” 좋은 데이터 과학자는 모델을 선택할 때 기술적 성능뿐 아니라 데이터의 목적, 레이블의 의미, 해석의 책임까지 함께 생각하는 사람입니다.
