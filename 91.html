2. 수업을 여는 멘트

환경 문제는 멀리 있는 이야기가 아닙니다. 우리가 사용하는 전기, 버리는 쓰레기, 숨 쉬는 공기, 이동하는 방식이 모두 데이터로 기록될 수 있습니다. 데이터는 눈에 보이지 않던 환경 변화를 보이게 만들고, 막연한 걱정을 구체적인 행동으로 바꾸는 근거가 됩니다. 인문 철학적으로 환경 데이터 분석은 “우리는 미래 세대에게 어떤 지구를 남길 것인가?”라는 질문과 연결됩니다. 오늘 우리는 환경 문제를 데이터로 읽고, 더 지속 가능한 선택을 제안하는 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 환경 데이터

환경 데이터는 기온, 강수량, 미세먼지, 탄소 배출량, 전력 사용량, 쓰레기 배출량, 재활용률, 생물 다양성처럼 환경 상태와 인간 활동의 영향을 수치로 기록한 데이터이다.

② 기후 변화 데이터

기후 변화 데이터는 장기간의 기온, 해수면, 강수 패턴, 온실가스 농도 변화를 포함한다. 단기간의 날씨와 장기간의 기후를 구별해 해석해야 한다.

③ 탄소 배출량

탄소 배출량은 에너지 사용, 산업 활동, 교통, 소비 활동 등에서 발생하는 온실가스 배출을 나타내는 지표이다. 기후 변화 대응 정책의 중요한 근거가 된다.

④ 대기질 데이터

미세먼지, 초미세먼지, 오존, 이산화질소 같은 대기질 데이터는 호흡 건강과 도시 환경을 이해하는 데 활용된다.

⑤ 에너지 사용 데이터

전력, 가스, 연료 사용량 데이터는 에너지 소비 패턴을 파악하고 절약 방안을 찾는 데 도움이 된다.

⑥ 쓰레기와 재활용 데이터

쓰레기 배출량, 재활용률, 음식물 쓰레기량 데이터는 자원 순환과 폐기물 감축 정책을 설계하는 데 사용될 수 있다.

⑦ 생태 데이터

생물종 개체 수, 서식지 변화, 수질, 토양 상태 같은 데이터는 생태계 건강성을 판단하는 데 활용된다.

⑧ 데이터 기반 해결 과정

환경 문제 해결은 문제 정의, 데이터 수집, 전처리, 분석, 시각화, 원인 가설 검토, 해결책 제안, 효과 평가의 흐름으로 진행될 수 있다.

⑨ 환경 시각화

선그래프는 시간 변화, 막대그래프는 지역 비교, 산점도는 두 변수 관계, 지도 시각화는 공간적 차이를 보여 주는 데 유용하다.

⑩ 환경 정의와 윤리

환경 피해는 모든 사람에게 동일하게 나타나지 않는다. 취약 계층, 지역 격차, 미래 세대의 권리를 고려하는 환경 정의 관점이 중요하다.

    "month": ["Mar", "Apr", "May", "Jun"],

    "waste": [45, 42, 40, 38],
    "pm10": [55, 48, 42, 35]
})

오늘 우리는 환경 문제를 데이터로 읽고 해결책으로 연결하는 방법을 배웠습니다. 컴퓨터과학은 환경 데이터를 수집하고 분석하는 도구를 제공하고, 수학은 변화량과 평균, 상관관계를 설명하며, 과학은 기후와 대기, 생태 현상을 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “데이터가 경고하는 미래 앞에서 우리는 어떤 책임 있는 선택을 할 것인가?” 좋은 데이터 과학자는 환경 지표를 계산하는 사람을 넘어, 그 데이터를 바탕으로 사람과 자연이 함께 살아갈 길을 제안하는 사람입니다.
