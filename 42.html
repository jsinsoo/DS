2. 수업을 여는 멘트

“우리 반 평균 점수는 80점입니다.” 이 한 문장은 많은 것을 말해 주는 것 같지만, 동시에 많은 것을 숨기기도 합니다. 대부분이 80점 근처인지, 몇 명의 매우 높은 점수가 평균을 끌어올린 것인지, 절반의 학생은 어느 정도 수준인지 알 수 없습니다. 인문 철학적으로 평균과 중앙값은 “공동체를 하나의 숫자로 말할 수 있는가?”라는 질문과 연결됩니다. 오늘 우리는 대표값을 계산하는 방법뿐 아니라, 그 숫자가 누구의 현실을 잘 보여 주고 누구의 현실을 가릴 수 있는지도 함께 생각해 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 대표값

대표값은 데이터 전체의 중심적 경향을 하나의 값으로 요약한 것이다. 평균, 중앙값, 최빈값이 대표적인 대표값이다. 대표값은 편리하지만 데이터의 모든 차이를 보여 주지는 않는다.

② 평균

평균은 모든 값을 더한 뒤 값의 개수로 나눈 값이다. 모든 데이터를 반영한다는 장점이 있지만, 매우 큰 값이나 작은 값이 있으면 그 영향을 크게 받는다.

③ 중앙값

중앙값은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값이다. 자료의 개수가 홀수이면 가운데 값, 짝수이면 가운데 두 값의 평균을 사용한다.

④ 이상값의 영향

이상값은 평균을 크게 움직일 수 있다. 예를 들어 대부분의 값이 1000원 근처인데 하나의 값이 100000원이라면 평균은 실제 대부분의 값보다 훨씬 커질 수 있다.

⑤ 치우친 분포

치우친 분포는 값들이 한쪽으로 몰리고 일부 값이 반대쪽으로 길게 퍼진 분포이다. 소득, 집값, 조회수, 기부금처럼 일부 큰 값이 있는 데이터에서 자주 나타난다.

⑥ 평균이 적절한 경우

데이터가 비교적 대칭적이고 이상값이 적을 때 평균은 전체 중심을 잘 나타낼 수 있다. 예를 들어 비슷한 범위의 시험 점수나 반복 측정값에서는 평균이 유용하다.

⑦ 중앙값이 적절한 경우

이상값이 있거나 분포가 한쪽으로 치우친 경우 중앙값이 대표적인 현실을 더 안정적으로 보여 줄 수 있다. 소득이나 부동산 가격을 설명할 때 중앙값을 함께 사용하는 이유이다.

⑧ 평균과 중앙값 비교

평균과 중앙값이 크게 다르면 데이터가 치우쳐 있거나 이상값이 있을 가능성이 있다. 두 값을 함께 보면 데이터의 중심과 분포 특성을 더 잘 이해할 수 있다.

⑨ 대표값의 윤리

대표값은 정책, 평가, 비교에 사용될 수 있다. 그러나 한 숫자로 집단을 설명할 때 소수의 상황이나 분포의 차이를 가릴 수 있으므로 공정한 해석이 필요하다.

4. 각각의 개념과 관련된 파이썬 코드

① 직접 평균 구하기

scores = [70, 80, 90]

mean_score = sum(scores) / len(scores)
print(mean_score)

모든 점수의 합을 개수로 나누어 평균을 구한다.

② Pandas로 평균과 중앙값 구하기

import pandas as pd

df = pd.DataFrame({"점수": [70, 80, 90, 100, 100]})

print("평균:", df["점수"].mean())
print("중앙값:", df["점수"].median())

Pandas의 mean()과 median()을 사용해 평균과 중앙값을 구한다.

③ 이상값이 평균에 미치는 영향

import pandas as pd

df = pd.DataFrame({"가격": [1000, 1100, 1200, 1300, 100000]})

print("평균:", df["가격"].mean())
print("중앙값:", df["가격"].median())

100000이라는 큰 값 때문에 평균이 중앙값보다 훨씬 커진다.

④ 자료 정렬 후 중앙값 이해

values = [100, 30, 50, 40, 60]

sorted_values = sorted(values)
middle = sorted_values[len(sorted_values) // 2]

print(sorted_values)
print("중앙값:", middle)

중앙값을 찾기 위해 자료를 먼저 정렬한다.

⑤ 평균과 중앙값을 함께 요약

import pandas as pd

df = pd.DataFrame({"조회수": [12, 15, 18, 20, 300]})

summary = df["조회수"].agg(["mean", "median", "min", "max"])
print(summary)

평균, 중앙값, 최솟값, 최댓값을 함께 보아 데이터의 특성을 해석한다.

5. 실생활 관련 코드 예제 5개

예제 1. 시험 점수 평균과 중앙값

import pandas as pd

df = pd.DataFrame({"score": [65, 70, 75, 80, 85]})

print("mean:", df["score"].mean())
print("median:", df["score"].median())

상세 설명: 점수가 비교적 고르게 분포하면 평균과 중앙값이 비슷하게 나타날 수 있다.

예제 2. 용돈 데이터의 이상값 영향

import pandas as pd

df = pd.DataFrame({"allowance": [10000, 12000, 15000, 13000, 100000]})

print("mean:", df["allowance"].mean())
print("median:", df["allowance"].median())

상세 설명: 한 명의 용돈이 매우 크면 평균이 크게 올라간다. 이때 중앙값이 일반적인 수준을 더 잘 보여 줄 수 있다.

예제 3. 집값 대표값 비교

import pandas as pd

df = pd.DataFrame({"price": [200, 210, 220, 230, 1000]})

print(df["price"].agg(["mean", "median"]))

상세 설명: 부동산 가격처럼 고가의 이상값이 있는 자료에서는 평균과 중앙값을 함께 확인해야 한다.

예제 4. 운동 시간 대표값

import pandas as pd

df = pd.DataFrame({"exercise_min": [20, 25, 30, 35, 40]})

print("평균 운동 시간:", df["exercise_min"].mean())
print("중앙 운동 시간:", df["exercise_min"].median())

상세 설명: 운동 시간이 균형 있게 분포하면 평균이 집단의 중심을 잘 나타낼 수 있다.

예제 5. 조회수 데이터 해석

import pandas as pd

df = pd.DataFrame({"views": [30, 35, 40, 45, 1000]})

mean_value = df["views"].mean()
median_value = df["views"].median()

print("mean:", mean_value)
print("median:", median_value)
print("difference:", mean_value - median_value)

상세 설명: 조회수처럼 일부 콘텐츠가 폭발적으로 높은 데이터에서는 평균과 중앙값의 차이가 클 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 평균과 중앙값이라는 두 대표값을 배웠습니다. 컴퓨터과학은 데이터를 빠르게 계산하게 해 주고, 수학은 대표값의 정의와 성질을 설명하며, 과학은 자료의 분포와 측정 조건을 함께 보게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “하나의 숫자로 집단을 말할 때, 우리는 누구의 현실을 놓치고 있는가?” 좋은 데이터 과학자는 평균을 계산할 줄 아는 사람을 넘어, 언제 평균이 충분하지 않은지 알고 중앙값과 분포를 함께 설명할 수 있는 사람입니다.
