2. 수업을 여는 멘트

여러분의 스마트폰은 지금도 빛의 세기, 움직임, 위치, 소리, 네트워크 상태를 감지하고 있습니다. 교실의 온도계, 미세먼지 측정기, 버스 위치 시스템, 스마트워치의 심박수 기록도 모두 현실 세계를 데이터로 바꾸는 장치입니다. 인문 철학적으로 보면 센서는 “세계가 우리에게 남기는 순간의 흔적”을 읽는 도구입니다. 하지만 모든 흔적을 모아도 되는 것은 아닙니다. 오늘 우리는 센서가 어떻게 데이터를 만들고, 실시간 데이터가 어떻게 판단을 돕는지 배우면서 측정의 책임도 함께 생각해 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 센서

센서는 온도, 습도, 빛, 소리, 움직임, 위치, 압력, 먼지 농도처럼 현실 세계의 물리적 상태를 측정하여 전기 신호나 디지털 데이터로 바꾸는 장치이다. 센서가 없다면 컴퓨터는 현실 세계의 변화를 직접 알 수 없다.

② IoT

IoT는 사물인터넷을 뜻하며, 센서가 부착된 사물들이 네트워크를 통해 데이터를 주고받는 환경이다. 스마트홈, 스마트팜, 스마트시티, 공장 자동화, 헬스케어 기기 등이 IoT의 대표 사례이다.

③ 실시간 데이터

실시간 데이터는 생성된 직후 빠르게 수집·처리·활용되는 데이터이다. 버스 위치, 주식 가격, 날씨 관측값, 심박수, 교통량처럼 시간에 따라 계속 변하는 데이터가 여기에 해당한다.

④ 시계열 데이터

시계열 데이터는 시간 순서가 중요한 데이터이다. 같은 온도 값이라도 언제 측정되었는지가 중요하다. 시계열 데이터에서는 추세, 주기성, 급격한 변화, 이상값을 살펴볼 수 있다.

⑤ 샘플링 주기

샘플링 주기는 센서가 데이터를 측정하는 시간 간격이다. 1초마다 측정하면 세밀한 변화를 볼 수 있지만 데이터 양이 많아지고, 1시간마다 측정하면 저장 공간은 줄지만 빠른 변화를 놓칠 수 있다.

⑥ 노이즈와 이상값

노이즈는 센서 오차나 환경 영향으로 생기는 작은 흔들림이고, 이상값은 일반적인 범위를 벗어난 값이다. 모든 이상값이 오류는 아니며, 실제 위험 신호일 수도 있으므로 맥락을 보고 판단해야 한다.

⑦ 실시간 모니터링

실시간 모니터링은 센서 데이터를 계속 확인하여 현재 상태를 파악하고 필요한 경우 경고를 발생시키는 과정이다. 예를 들어 미세먼지가 기준치를 넘으면 알림을 보내거나, 온실 온도가 너무 높으면 환기 장치를 작동시킬 수 있다.

⑧ 센서 데이터 윤리

센서 데이터는 위치, 건강, 행동 패턴처럼 민감한 정보를 포함할 수 있다. 편리한 서비스와 감시의 경계가 모호해질 수 있으므로 수집 목적, 동의, 보관 기간, 익명화, 접근 권한을 신중하게 다루어야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 센서 예시 데이터 만들기

import pandas as pd

df = pd.DataFrame({
    "시간": ["09:00", "09:10", "09:20"],
    "온도": [22.1, 22.5, 23.0],
    "습도": [45, 44, 43]
})

print(df)

센서에서 수집된 시간, 온도, 습도 데이터를 표 형태로 만든다.

② 시간순 정렬

df = df.sort_values("시간")
print(df)

실시간 데이터는 시간 순서가 중요하므로 측정 시각을 기준으로 정렬한다.

③ 평균 온도 계산

mean_temp = df["온도"].mean()
print("평균 온도:", mean_temp)

일정 시간 동안의 센서 측정값을 요약한다.

④ 임계값 경고

df["경고"] = df["온도"].apply(lambda x: "주의" if x >= 23 else "정상")
print(df)

온도가 기준값 이상이면 경고를 표시한다. 실시간 모니터링의 기본 원리이다.

⑤ 이동평균으로 노이즈 줄이기

df["온도_이동평균"] = df["온도"].rolling(window=2).mean()
print(df)

이동평균은 갑작스러운 작은 흔들림을 완화하여 전체 흐름을 보기 쉽게 한다.

5. 실생활 관련 코드 예제 5개

예제 1. 교실 온도 센서 경고 시스템

import pandas as pd

df = pd.DataFrame({
    "시간": ["1교시", "2교시", "3교시", "4교시"],
    "온도": [22.4, 24.1, 27.3, 28.2]
})

df["상태"] = df["온도"].apply(lambda t: "환기 필요" if t >= 27 else "쾌적")
print(df)

상세 설명: 교실 온도가 기준 이상이면 환기 필요 상태를 표시한다. 센서 데이터가 생활 환경 개선에 활용되는 예이다.

예제 2. 미세먼지 실시간 등급 표시

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "익산", "군산", "남원"],
    "PM10": [25, 58, 95, 160]
})

def grade(pm):
    if pm <= 30:
        return "좋음"
    elif pm <= 80:
        return "보통"
    elif pm <= 150:
        return "나쁨"
    return "매우 나쁨"

df["등급"] = df["PM10"].apply(grade)
print(df)

상세 설명: 미세먼지 센서값을 사람이 이해하기 쉬운 등급으로 바꾼다. 숫자 데이터가 의사결정 정보로 변환된다.

예제 3. 스마트팜 습도 관리

import pandas as pd

df = pd.DataFrame({
    "시간": ["08:00", "10:00", "12:00", "14:00"],
    "토양습도": [42, 38, 31, 28]
})

df["물주기"] = df["토양습도"].apply(lambda h: "필요" if h < 35 else "대기")
print(df)

상세 설명: 토양 습도가 기준보다 낮으면 물주기가 필요하다고 표시한다. 농업에서 실시간 센서 데이터가 자동화에 활용될 수 있다.

예제 4. 심박수 이상값 탐지

import pandas as pd

df = pd.DataFrame({
    "시간": ["09:00", "09:01", "09:02", "09:03"],
    "심박수": [78, 82, 145, 80]
})

df["이상여부"] = df["심박수"].apply(lambda x: "이상값 확인" if x > 130 else "정상")
print(df)

상세 설명: 스마트워치 심박수 데이터에서 기준보다 높은 값을 탐지한다. 단, 실제 건강 판단은 전문가의 검토가 필요하다.

예제 5. 소음 데이터 이동평균

import pandas as pd

df = pd.DataFrame({
    "분": [1, 2, 3, 4, 5],
    "소음": [55, 80, 58, 60, 62]
})

df["이동평균"] = df["소음"].rolling(window=3).mean()
print(df)

상세 설명: 순간적으로 튄 소음값을 이동평균으로 완화한다. 실시간 데이터에서 노이즈와 추세를 구별하는 데 도움이 된다.

9. 수업을 마무리 하는 멘트

오늘 우리는 센서가 현실 세계를 데이터로 바꾸는 과정을 배웠습니다. 컴퓨터과학은 센서 데이터를 저장하고 처리하는 방법을 제공하고, 수학은 시간에 따른 변화와 평균, 임계값, 이상값을 해석하게 하며, 과학은 측정의 정확도와 오차를 점검하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “측정 가능한 모든 것을 측정하는 사회는 과연 더 좋은 사회인가?” 좋은 데이터 과학자는 실시간 데이터를 빠르게 다루는 사람일 뿐 아니라, 무엇을 왜 측정해야 하는지 성찰하는 사람입니다.
