2. 수업을 여는 멘트

우리는 매일 선택합니다. 어떤 메뉴를 개선할지, 어떤 정책을 먼저 실행할지, 어떤 프로그램에 예산을 배분할지 결정해야 합니다. 감과 경험도 중요하지만, 데이터는 선택의 이유를 더 분명하게 만들어 줍니다. 그러나 숫자가 있다고 해서 결정이 자동으로 옳아지는 것은 아닙니다. 인문 철학적으로 데이터 기반 의사결정은 “무엇을 기준으로 좋은 선택이라고 말할 수 있는가?”라는 질문과 연결됩니다. 오늘 우리는 데이터를 근거로 삼되, 인간의 책임과 윤리를 함께 고려하는 의사결정 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 데이터 기반 의사결정

데이터 기반 의사결정은 직관, 경험, 권위에만 의존하지 않고 데이터를 수집·분석하여 근거 있는 결정을 내리는 과정이다. 학교, 기업, 공공기관, 환경 정책, 의료, 교통 등 다양한 분야에서 활용된다.

② 문제 정의

의사결정은 “무엇을 결정해야 하는가?”를 분명히 하는 것에서 시작한다. 문제 정의가 모호하면 데이터 수집과 분석 방향도 흔들린다.

③ 데이터 수집

의사결정에 필요한 데이터를 모으는 단계이다. 설문, 센서, 공공데이터, 업무 기록, 실험 결과 등을 활용할 수 있으며 출처와 신뢰도를 확인해야 한다.

④ 지표 설정

지표는 판단의 기준이다. 비용, 시간, 만족도, 효율, 정확도, 위험도, 공정성, 지속 가능성 같은 지표를 상황에 맞게 정한다.

⑤ 데이터 분석

수집한 데이터를 평균, 합계, 비율, 변화량, 상관관계, 그룹 비교 등으로 분석한다. 분석 결과는 대안을 비교하는 근거가 된다.

⑥ 대안 비교

여러 선택지를 지표에 따라 비교한다. 어떤 대안이 비용은 낮지만 효과도 낮을 수 있고, 어떤 대안은 효과는 크지만 위험이 클 수 있다.

⑦ 시각화

그래프는 대안의 차이와 변화 추세를 한눈에 보여 준다. 막대그래프는 대안 비교, 선그래프는 시간 변화, 산점도는 변수 관계를 표현하는 데 유용하다.

⑧ 실행과 평가

결정을 실행한 뒤 결과 데이터를 다시 수집해 목표가 달성되었는지 평가한다. 데이터 기반 의사결정은 한 번의 선택이 아니라 반복적 개선 과정이다.

⑨ 편향과 한계

데이터가 특정 집단을 과소대표하거나 잘못 측정되면 의사결정도 불공정해질 수 있다. 데이터의 출처, 수집 방식, 표본, 해석의 한계를 점검해야 한다.

⑩ 책임 있는 의사결정

데이터는 결정을 돕는 도구이지만 최종 책임은 인간에게 있다. 공정성, 개인정보 보호, 설명 가능성, 사회적 영향을 함께 고려해야 한다.

5. 실생활 관련 코드 예제 5개

예제 1. 급식 메뉴 개선 의사결정

import pandas as pd

df = pd.DataFrame({
    "menu": ["Rice", "Curry", "Pasta"],
    "satisfaction": [70, 90, 85],
    "cost": [50, 65, 70]
})

df["score"] = df["satisfaction"] - df["cost"] * 0.5
print(df.sort_values("score", ascending=False))

상세 설명: 만족도와 비용을 함께 고려해 메뉴 개선 우선순위를 정한다.

예제 2. 동아리 예산 배분 비교

import pandas as pd

df = pd.DataFrame({
    "club": ["Science", "Music", "Sports"],
    "students": [45, 30, 50],
    "need": [80, 70, 75]
})

df["priority"] = df["students"] * 0.4 + df["need"] * 0.6
print(df.sort_values("priority", ascending=False))

상세 설명: 참여 학생 수와 필요도를 함께 고려해 예산 배분 우선순위를 비교한다.

예제 3. 에너지 절약 정책 선택

import pandas as pd

df = pd.DataFrame({
    "policy": ["LED", "AC control", "Solar"],
    "saving": [30, 25, 45],
    "cost": [10, 5, 40]
})

df["efficiency"] = df["saving"] / df["cost"]
print(df.sort_values("efficiency", ascending=False))

상세 설명: 비용 대비 절감 효과를 계산해 효율적인 정책을 찾는다.

오늘 우리는 데이터를 근거로 문제를 정의하고, 지표를 설정하고, 대안을 비교하며, 실행 후 다시 평가하는 의사결정 과정을 배웠습니다. 컴퓨터과학은 데이터를 처리하고 자동화하는 도구를 제공하고, 수학은 점수화와 비교, 변화량 계산의 논리를 설명하며, 과학은 선택의 효과를 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “좋은 결정은 효율만 높은 결정인가, 아니면 공정하고 책임 있는 결정인가?” 좋은 데이터 과학자는 숫자를 계산하는 사람을 넘어, 데이터와 인간의 가치를 함께 고려해 더 나은 선택을 이끄는 사람입니다.
