핵심 개념
데이터 탐색은 분석 전에 데이터의 구조, 품질, 분포, 관계를 살펴보며 의미 있는 질문을 만들어 가는 과정이다.

데이터는 우리에게 어떤 이야기를 하고 있으며, 우리는 그 이야기를 성급하게 오해하고 있지는 않은가?

2. 수업을 여는 멘트

데이터 분석은 정답을 바로 계산하는 일이 아닙니다. 처음 만난 데이터를 천천히 살펴보며 “무엇이 기록되어 있는가?”, “어떤 값이 비어 있는가?”, “어떤 값이 유난히 튀는가?”, “어떤 변수들이 함께 움직이는가?”를 묻는 일에서 시작됩니다. 인문 철학적으로 데이터 탐색은 낯선 세계를 관찰하는 태도와 닮았습니다. 우리는 오늘 숫자와 표와 그래프를 통해 데이터가 들려주는 첫 목소리를 들어 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 데이터 탐색

데이터 탐색은 본격적인 분석이나 모델링 전에 데이터의 구조와 특징을 살펴보는 과정이다. 어떤 열이 있는지, 자료형은 무엇인지, 값이 비어 있는지, 분포와 관계가 어떤지를 확인한다.

② 탐색적 데이터 분석

탐색적 데이터 분석은 데이터를 다양한 관점에서 살펴보며 패턴, 이상값, 관계, 가설을 발견하는 분석 접근이다. 정해진 답을 찾기보다 좋은 질문을 만드는 과정에 가깝다.

③ 데이터 구조 확인

데이터 구조 확인은 행과 열의 수, 열 이름, 자료형, 결측값 여부를 확인하는 것이다. Pandas에서는 head(), info(), shape 등을 사용한다.

④ 요약 통계

요약 통계는 평균, 중앙값, 표준편차, 최솟값, 최댓값, 사분위수처럼 데이터를 짧게 설명하는 값이다. describe()를 이용하면 수치형 데이터의 기본 통계를 빠르게 볼 수 있다.

⑤ 분포

분포는 데이터 값들이 어떤 범위에 얼마나 모여 있는지를 나타낸다. 분포를 보면 데이터가 한쪽으로 치우쳤는지, 여러 봉우리가 있는지, 이상값이 있는지 파악할 수 있다.

⑥ 이상값

이상값은 일반적인 값의 범위에서 크게 벗어난 값이다. 탐색 단계에서 이상값을 발견하면 오류인지 중요한 사건인지 확인해야 한다.

⑦ 결측값

결측값은 비어 있는 값이다. 결측값이 많으면 분석 결과가 왜곡될 수 있으므로 어느 열에 얼마나 있는지 확인해야 한다.

⑧ 상관관계

상관관계는 두 변수가 함께 변하는 정도를 의미한다. 키와 몸무게, 공부 시간과 점수처럼 함께 증가하거나 감소하는 경향을 볼 수 있다. 그러나 상관관계는 인과관계를 의미하지 않는다.

⑨ 시각화

시각화는 데이터를 그래프로 표현하여 패턴을 눈으로 확인하는 방법이다. 히스토그램은 분포, 박스플롯은 이상값과 사분위수, 산점도는 두 변수의 관계를 살펴보는 데 유용하다.

4. 각각의 개념과 관련된 파이썬 코드

① 데이터 기본 구조 확인

import pandas as pd

df = pd.DataFrame({
    "공부시간": [1, 2, 3, 4, 5],
    "점수": [55, 60, 70, 80, 90],
    "수면시간": [6, 7, 6, 8, 7]
})

print(df.head())
print(df.shape)

데이터 앞부분과 행·열 크기를 확인한다.

② 자료형과 결측값 확인

print(df.info())
print(df.isna().sum())

열별 자료형과 결측값 개수를 확인한다.

③ 요약 통계 확인

print(df.describe())

평균, 표준편차, 최솟값, 사분위수, 최댓값을 확인한다.

④ 상관관계 확인

corr = df.corr(numeric_only=True)
print(corr)

수치형 변수들 사이의 상관관계를 계산한다.

⑤ 히스토그램 그리기

import matplotlib.pyplot as plt

df["점수"].plot(kind="hist", bins=5)
plt.title("Score Distribution")
plt.xlabel("Score")
plt.ylabel("Frequency")
plt.show()

점수 분포를 히스토그램으로 확인한다. 한글 깨짐을 피하기 위해 그래프 제목은 영어로 작성했다.

5. 실생활 관련 코드 예제 5개

예제 1. 공부 시간과 점수 탐색

import pandas as pd

df = pd.DataFrame({
    "study_hour": [1, 2, 3, 4, 5],
    "score": [55, 60, 70, 80, 90]
})

print(df.describe())
print(df.corr(numeric_only=True))

상세 설명: 공부 시간과 점수의 요약 통계와 상관관계를 확인한다. 상관관계가 높아도 반드시 인과관계를 뜻하지는 않는다.

예제 2. 급식 만족도 빈도 탐색

import pandas as pd

df = pd.DataFrame({
    "menu": ["rice", "curry", "rice", "pasta", "curry", "rice"]
})

print(df["menu"].value_counts())

상세 설명: 어떤 메뉴가 많이 선택되었는지 빈도를 확인한다. 범주형 데이터 탐색에 적합하다.

예제 3. 운동 걸음수 분포 확인

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({"steps": [5200, 7600, 8000, 9100, 10000, 12000]})

df["steps"].plot(kind="hist", bins=4)
plt.title("Steps Distribution")
plt.xlabel("Steps")
plt.ylabel("Frequency")
plt.show()

상세 설명: 걸음수 값들이 어느 구간에 몰려 있는지 히스토그램으로 확인한다.

예제 4. 쇼핑 데이터 이상값 후보 확인

import pandas as pd

df = pd.DataFrame({"price": [1000, 1200, 1500, 1300, 100000]})

print(df.describe())
print(df[df["price"] > 10000])

상세 설명: 가격 데이터에서 매우 큰 값을 이상값 후보로 찾는다. 실제 고가 상품인지 입력 오류인지 확인해야 한다.

예제 5. 수면 시간과 집중도 산점도

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({

plt.title("Sleep and Focus")

상세 설명: 수면 시간과 집중도 점수의 관계를 산점도로 확인한다. 점들이 어떤 방향으로 분포하는지 살펴본다.

7. 형성평가 5지선다형 10문항

문항 1. 데이터 탐색의 주된 목적은?
정답: 1번
상세풀이: 데이터 탐색은 본격 분석 전에 데이터의 상태와 패턴을 이해하는 과정이다.
문항 2. 요약 통계에 해당하지 않는 것은?
정답: 1번
상세풀이: 글꼴 종류는 통계량이 아니며, 평균·중앙값·최댓값·최솟값은 요약 통계이다.
문항 3. 분포를 확인하는 데 적절한 그래프는?
정답: 1번
상세풀이: 히스토그램은 값들이 어느 구간에 얼마나 모여 있는지 보여 준다.
문항 4. 두 수치형 변수의 관계를 보는 데 적절한 그래프는?
정답: 1번
상세풀이: 산점도는 두 변수 사이의 관계나 패턴을 살펴보는 데 적합하다.
문항 5. 상관관계에 대한 설명으로 옳은 것은?
정답: 1번
상세풀이: 상관관계는 두 변수가 함께 변하는 정도를 뜻하지만 인과를 보장하지 않는다.
문항 6. Pandas에서 데이터 앞부분을 확인하는 함수는?
정답: 1번
상세풀이: head()는 DataFrame의 앞부분 몇 행을 보여 준다.
문항 7. Pandas에서 열별 자료형을 확인하는 데 유용한 것은?
정답: 1번
상세풀이: info()는 열 이름, 결측이 아닌 값의 개수, 자료형 등을 보여 준다.
문항 8. 결측값 확인 코드로 적절한 것은?
정답: 1번
상세풀이: isna().sum()은 열별 결측값 개수를 확인한다.
문항 9. 박스플롯으로 주로 확인할 수 있는 것은?
정답: 1번
상세풀이: 박스플롯은 분포의 중심, 퍼짐, 이상값 후보를 확인하는 데 유용하다.
문항 10. 데이터 탐색에서 바람직한 태도는?
정답: 1번
상세풀이: 탐색 결과는 데이터가 만들어진 맥락과 함께 해석해야 한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 데이터를 분석하기 전에 먼저 관찰하는 법을 배웠습니다. 컴퓨터과학은 데이터를 불러오고 요약하고 시각화하는 도구를 제공하며, 수학은 평균·분포·상관관계로 패턴을 설명하게 하고, 과학은 관찰에서 가설을 세우고 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “우리는 데이터가 말하는 것과 우리가 보고 싶은 것을 혼동하고 있지는 않은가?” 좋은 데이터 과학자는 정답을 서두르는 사람이 아니라, 데이터를 정직하게 바라보고 좋은 질문을 만들어 내는 사람입니다.
