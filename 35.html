2. 수업을 여는 멘트

데이터를 열어 보면 값이 비어 있는 칸도 있고, 유난히 큰 값이나 작은 값도 있습니다. 처음에는 이것이 귀찮은 오류처럼 보이지만, 사실 그 안에는 중요한 이야기가 숨어 있을 수 있습니다. 응답하지 않은 이유가 질문의 민감성 때문일 수도 있고, 갑자기 튄 센서값이 실제 위험 신호일 수도 있습니다. 인문 철학적으로 결측치와 이상치는 “침묵과 예외를 어떻게 해석할 것인가”의 문제입니다. 오늘 우리는 비어 있는 값과 튀는 값을 다루는 기술을 배우며, 데이터가 말하지 못한 것까지 성찰하는 태도를 기릅니다.

3. 각각의 개념에 대한 상세 설명

① 결측치

결측치는 데이터 값이 비어 있거나 누락된 상태이다. 설문 미응답, 센서 고장, 파일 변환 오류, 입력 실수 등으로 발생한다. 결측치가 많으면 평균이나 비율 분석이 왜곡될 수 있다.

② 결측 원인

결측치는 단순 실수일 수도 있지만, 응답자가 민감한 질문을 피했거나 특정 조건에서만 측정이 실패했기 때문에 생길 수도 있다. 원인을 확인하지 않고 처리하면 편향이 생길 수 있다.

③ 결측치 삭제

결측치가 있는 행이나 열을 삭제하는 방법이다. 간단하지만 데이터 수가 줄어들고 특정 집단이 과도하게 제외될 수 있다.

④ 결측치 대체

결측치를 평균, 중앙값, 최빈값, 이전 값, 예측값 등으로 채우는 방법이다. 대체값은 편리하지만 실제 관측값은 아니므로 결과 해석에 주의해야 한다.

⑤ 평균과 중앙값

평균은 모든 값을 더해 개수로 나눈 값이고, 중앙값은 값을 크기순으로 정렬했을 때 가운데 위치한 값이다. 이상치가 있으면 평균보다 중앙값이 더 안정적일 수 있다.

⑥ 이상치

이상치는 일반적인 데이터 범위에서 크게 벗어난 값이다. 입력 오류, 측정 오류, 특수한 사건, 실제 극단 사례 등 다양한 원인이 있다.

⑦ IQR 이상치 탐지

IQR은 3사분위수(Q3)와 1사분위수(Q1)의 차이이다. 일반적으로 Q1 - 1.5×IQR보다 작거나 Q3 + 1.5×IQR보다 큰 값을 이상치 후보로 본다.

⑧ z-score 이상치 탐지

z-score는 어떤 값이 평균에서 표준편차 몇 개만큼 떨어져 있는지를 나타낸다. 절댓값이 3보다 크면 이상치 후보로 보는 경우가 많다.

⑨ 윤리적 처리

결측치와 이상치를 처리하는 기준은 분석 결과를 바꾼다. 특히 사람과 관련된 데이터에서는 특정 집단의 데이터가 사라지지 않는지, 극단 사례가 부당하게 배제되지 않는지 확인해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 결측치 확인

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "점수": [90, None, 70]
})

print(df.isna().sum())

각 열에 결측치가 몇 개 있는지 확인한다.

② 결측치 평균 대체

df["점수"] = df["점수"].fillna(df["점수"].mean())
print(df)

비어 있는 점수를 평균으로 채운다. 단, 평균이 적절한지는 데이터 상황에 따라 판단해야 한다.

③ 결측치 행 삭제

clean = df.dropna()
print(clean)

결측치가 포함된 행을 삭제한다. 데이터 수가 줄어드는 점을 주의해야 한다.

④ IQR로 이상치 찾기

import pandas as pd

df = pd.DataFrame({"키": [160, 165, 170, 172, 999]})

q1 = df["키"].quantile(0.25)
q3 = df["키"].quantile(0.75)
iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

outliers = df[(df["키"] < lower) | (df["키"] > upper)]
print(outliers)

사분위수와 IQR을 이용해 일반 범위를 벗어난 값을 찾는다.

⑤ z-score로 이상치 후보 찾기

import pandas as pd

df = pd.DataFrame({"점수": [70, 75, 80, 85, 150]})

mean = df["점수"].mean()
std = df["점수"].std()

df["z점수"] = (df["점수"] - mean) / std
print(df)

평균과 표준편차를 이용해 각 값이 평균에서 얼마나 떨어져 있는지 계산한다.

5. 실생활 관련 코드 예제 5개

예제 1. 설문 만족도 결측치 중앙값 대체

import pandas as pd

df = pd.DataFrame({
    "학생": ["A", "B", "C", "D", "E"],
    "만족도": [5, None, 4, 1, 5]
})

df["만족도_대체"] = df["만족도"].fillna(df["만족도"].median())
print(df)

상세 설명: 만족도 결측치를 중앙값으로 대체한다. 중앙값은 극단값의 영향을 평균보다 덜 받는다.

예제 2. 출석 데이터 결측 행 확인

import pandas as pd

df = pd.DataFrame({
    "날짜": ["월", "화", "수"],
    "출석상태": ["출석", None, "지각"]
})

missing_rows = df[df["출석상태"].isna()]
print(missing_rows)

상세 설명: 출석 상태가 입력되지 않은 행을 찾아 확인한다. 삭제하기 전 입력 누락인지 확인해야 한다.

예제 3. 운동 걸음수 이상치 탐지

import pandas as pd

df = pd.DataFrame({"걸음수": [7200, 8500, 9100, 7800, 999999]})

q1 = df["걸음수"].quantile(0.25)
q3 = df["걸음수"].quantile(0.75)
iqr = q3 - q1

outliers = df[(df["걸음수"] < q1 - 1.5 * iqr) | (df["걸음수"] > q3 + 1.5 * iqr)]
print(outliers)

상세 설명: 비정상적으로 큰 걸음수를 이상치 후보로 탐지한다. 기기 오류인지 실제 기록인지 확인해야 한다.

예제 4. 가격 데이터 평균과 중앙값 비교

import pandas as pd

df = pd.DataFrame({"가격": [1000, 1200, 1300, 1500, 100000]})

print("평균:", df["가격"].mean())
print("중앙값:", df["가격"].median())

상세 설명: 매우 큰 가격 하나가 평균을 크게 올린다. 이상치가 있을 때 중앙값도 함께 보는 것이 좋다.

예제 5. 센서 온도 이상값 표시

import pandas as pd

df = pd.DataFrame({
    "시간": ["09:00", "10:00", "11:00", "12:00"],
    "온도": [22.5, 23.0, 88.0, 23.4]
})

df["상태"] = df["온도"].apply(lambda t: "확인 필요" if t > 50 else "정상")
print(df)

상세 설명: 교실 온도로 보기 어려운 88도를 확인 필요로 표시한다. 자동 삭제보다 확인 표시가 먼저 필요하다.

OX 3. 이상치는 일반적인 데이터 범위에서 크게 벗어난 값을 말한다.
정답: O
상세풀이: 이상치는 오류일 수도 있고 실제로 중요한 사건일 수도 있다.
OX 4. 이상치는 무조건 삭제하는 것이 가장 좋은 처리 방법이다.
정답: X
상세풀이: 이상치의 원인을 확인한 뒤 삭제, 수정, 유지 여부를 결정해야 한다.
OX 5. 평균은 극단값의 영향을 많이 받을 수 있다.
정답: O
상세풀이: 매우 큰 값이나 작은 값이 있으면 평균이 크게 흔들릴 수 있다.
OX 6. 중앙값은 이상치가 있을 때 평균보다 안정적인 대표값이 될 수 있다.
정답: O
상세풀이: 중앙값은 순서상 가운데 값이므로 극단값의 영향을 덜 받는다.
OX 7. IQR은 사분위수를 이용해 이상치를 탐지하는 방법과 관련 있다.
정답: O
상세풀이: IQR은 Q3-Q1이며, 일반적으로 Q1-1.5IQR보다 작거나 Q3+1.5IQR보다 큰 값을 이상치 후보로 본다.
OX 8. z-score는 평균과 표준편차를 이용해 값이 얼마나 떨어져 있는지 나타낸다.
정답: O
상세풀이: z-score가 매우 크거나 작으면 이상치 후보가 될 수 있다.
OX 9. 결측치와 이상치를 처리할 때 원본 데이터를 보존하는 것이 좋다.
정답: O
상세풀이: 처리 기준이 잘못될 수 있으므로 원본 보존과 처리 기록이 중요하다.
OX 10. 결측치와 이상치 처리는 기술적 작업일 뿐 윤리적 판단과는 무관하다.
정답: X
상세풀이: 값을 삭제하거나 대체하는 결정은 결과와 사람에 대한 해석에 영향을 줄 수 있다.

7. 형성평가 5지선다형 10문항

문항 1. 결측치의 설명으로 가장 적절한 것은?
정답: 1번
상세풀이: 결측치는 값이 없거나 기록되지 않은 상태이다.
문항 2. 결측치 처리 방법으로 적절하지 않은 것은?
정답: 1번
상세풀이: 결측 원인과 분석 목적을 확인하지 않고 임의 조작하는 것은 적절하지 않다.
문항 3. 이상치의 설명으로 옳은 것은?
정답: 1번
상세풀이: 이상치는 데이터 분포에서 크게 벗어난 값이다.
문항 4. 평균 대체보다 중앙값 대체가 더 적합할 수 있는 경우는?
정답: 1번
상세풀이: 중앙값은 극단값의 영향을 덜 받아 이상치가 있는 데이터에서 안정적일 수 있다.
문항 5. IQR의 의미로 적절한 것은?
정답: 1번
상세풀이: IQR은 Q3-Q1로 데이터 가운데 50%의 퍼짐 정도를 나타낸다.
문항 6. z-score가 나타내는 것은?
정답: 1번
상세풀이: z-score는 값이 평균에서 얼마나 떨어져 있는지 표준편차 단위로 표현한다.
문항 7. Pandas에서 결측치를 확인하는 코드로 적절한 것은?
정답: 1번
상세풀이: isna().sum()은 열별 결측치 개수를 확인한다.
문항 8. Pandas에서 결측치를 특정 값으로 채울 때 사용하는 대표 함수는?
정답: 1번
상세풀이: fillna는 결측치를 지정한 값으로 채운다.
문항 9. 이상치 처리에서 가장 바람직한 태도는?
정답: 1번
상세풀이: 이상치가 오류인지 중요한 신호인지 판단해야 한다.
문항 10. 결측치와 이상치 처리 기록이 필요한 이유는?
정답: 1번
상세풀이: 처리 기준과 과정을 기록해야 결과를 검토하고 재현할 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 결측치와 이상치를 단순한 오류가 아니라 데이터가 가진 침묵과 예외로 바라보았습니다. 컴퓨터과학은 이를 탐지하고 처리하는 도구를 제공하고, 수학은 평균·중앙값·IQR·z-score로 판단 기준을 세우게 하며, 과학은 측정 과정과 오류 가능성을 점검하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “우리가 지운 예외는 정말 오류였는가, 아니면 중요한 목소리였는가?” 좋은 데이터 과학자는 값을 지우기 전에 이유를 묻고, 처리 기준을 설명할 수 있는 사람입니다.
