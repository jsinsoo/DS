2. 수업을 여는 멘트

학생들이 좋아하는 급식 메뉴를 조사했다고 해 봅시다. “어떤 메뉴가 가장 인기 있는가?”를 알고 싶다면 막대그래프가 좋습니다. 하지만 “전체 선택 중 카레가 차지하는 비율은 얼마인가?”를 알고 싶다면 원그래프가 더 어울릴 수 있습니다. 인문 철학적으로 그래프 선택은 “무엇을 중심으로 세상을 볼 것인가”의 문제입니다. 오늘 우리는 같은 데이터도 질문에 따라 다르게 보일 수 있음을 배우고, 목적에 맞는 그래프를 선택하는 힘을 기릅니다.

3. 각각의 개념에 대한 상세 설명

① 막대그래프

막대그래프는 범주별 값의 크기를 막대의 길이로 나타내는 그래프이다. 학급별 평균 점수, 메뉴별 선호도, 지역별 이용자 수처럼 서로 다른 범주를 비교할 때 적합하다.

② 원그래프

원그래프는 전체를 하나의 원으로 보고, 각 항목이 차지하는 비율을 부채꼴 조각으로 나타내는 그래프이다. 전체 예산 중 항목별 비중, 설문 응답 비율, 관심 분야 구성비 등을 표현할 때 사용할 수 있다.

③ 범주형 데이터

범주형 데이터는 값을 몇 개의 종류나 분류로 나눈 데이터이다. 예를 들어 메뉴, 지역, 학급, 성별, 동아리 이름 등이 범주형 데이터이다.

④ 빈도

빈도는 어떤 범주가 몇 번 나타났는지를 뜻한다. 설문에서 카레를 선택한 학생 수, 특정 지역의 방문자 수처럼 개수를 세는 데 사용된다.

⑤ 비율과 구성비

비율은 전체 중 특정 항목이 차지하는 정도이다. 원그래프는 각 범주의 비율을 직관적으로 보여 주지만, 정확한 값 비교에는 막대그래프가 더 나은 경우가 많다.

⑥ 막대그래프가 적합한 경우

범주별 값을 정확히 비교하고 싶을 때 막대그래프가 좋다. 항목이 많거나 값 차이를 자세히 비교해야 할 때 원그래프보다 막대그래프가 더 읽기 쉽다.

⑦ 원그래프가 적합한 경우

전체 중 몇 개 항목의 비율을 간단히 보여 줄 때 원그래프가 적합하다. 그러나 항목이 많거나 비율이 비슷한 경우에는 비교가 어렵다.

⑧ 축과 레이블

막대그래프에서는 축 이름과 단위가 중요하다. 원그래프에서는 조각의 이름과 비율 표시가 중요하다. 제목, 축, 레이블이 없으면 그래프 의미를 오해할 수 있다.

⑨ 그래프 선택의 윤리

그래프는 사람의 판단에 영향을 준다. 일부 항목을 숨기거나, 축을 왜곡하거나, 전체 비율을 잘못 표시하면 사실을 다르게 보이게 할 수 있다. 그래프는 정직하고 투명하게 만들어야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 기본 막대그래프

import matplotlib.pyplot as plt

menus = ["Rice", "Curry", "Pasta", "Soup"]
votes = [35, 50, 42, 28]

plt.bar(menus, votes)
plt.title("Menu Preference")
plt.xlabel("Menu")
plt.ylabel("Votes")
plt.show()

메뉴별 투표 수를 막대그래프로 비교한다.

② 가로 막대그래프

import matplotlib.pyplot as plt

clubs = ["AI", "Robot", "Bio", "Math"]
members = [30, 25, 20, 15]

plt.barh(clubs, members)
plt.title("Club Members")
plt.xlabel("Members")
plt.ylabel("Club")
plt.show()

항목 이름이 길거나 항목 수가 많을 때 가로 막대그래프를 사용할 수 있다.

③ 기본 원그래프

import matplotlib.pyplot as plt

labels = ["AI", "Robot", "Bio", "Math"]
values = [30, 25, 20, 25]

plt.pie(values, labels=labels, autopct="%1.1f%%")
plt.title("Club Interest Ratio")
plt.show()

전체 동아리 관심 중 각 항목의 비율을 원그래프로 표현한다.

④ Pandas value_counts로 빈도 계산

import pandas as pd

df = pd.DataFrame({
    "menu": ["Rice", "Curry", "Rice", "Pasta", "Curry", "Curry"]
})

counts = df["menu"].value_counts()
print(counts)

범주형 데이터에서 각 범주의 빈도를 계산한다.

⑤ 빈도 계산 후 막대그래프

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "menu": ["Rice", "Curry", "Rice", "Pasta", "Curry", "Curry"]
})

counts = df["menu"].value_counts()
counts.plot(kind="bar")

plt.title("Menu Counts")
plt.xlabel("Menu")
plt.ylabel("Count")
plt.show()

설문 응답에서 메뉴별 선택 빈도를 계산하고 막대그래프로 나타낸다.

상세 설명: 지역별 이용자 수를 비교한다. 지역 간 크기 차이가 막대 길이로 드러난다.

예제 4. 예산 구성비 원그래프

상세 설명: 전체 예산 중 각 항목이 차지하는 비중을 보여 준다.

예제 5. 원그래프보다 막대그래프가 나은 경우

plt.title("Average Score by Subject")

plt.ylim(0, 100)

9. 수업을 마무리 하는 멘트

오늘 우리는 막대그래프와 원그래프가 서로 다른 질문에 답한다는 것을 배웠습니다. 컴퓨터과학은 데이터를 그래프로 바꾸는 도구를 제공하고, 수학은 빈도와 비율을 정확히 계산하게 하며, 과학은 그래프가 관찰 사실을 왜곡하지 않는지 확인하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “우리는 비교를 보여 주고 싶은가, 아니면 전체 속 비중을 보여 주고 싶은가?” 좋은 데이터 과학자는 그래프를 많이 그리는 사람이 아니라, 질문에 맞는 그래프를 정직하게 선택하는 사람입니다.
