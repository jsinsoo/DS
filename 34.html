2. 수업을 여는 멘트

데이터 과학자는 반짝이는 그래프를 만들기 전에 먼저 지저분한 데이터를 만납니다. 이름 앞뒤에 공백이 있고, 어떤 값은 빠져 있으며, 같은 사람이 두 번 입력되어 있고, 숫자처럼 보이는 값이 사실은 문자열일 때도 있습니다. 인문 철학적으로 데이터 정리는 “현실의 흔적을 어떤 기준으로 해석할 것인가”의 문제입니다. 오늘 우리는 데이터를 깨끗하게 만드는 기술뿐 아니라, 무엇을 고치고 무엇을 남겨야 하는지 판단하는 책임도 함께 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 데이터 정리

데이터 정리는 분석 전에 데이터의 오류, 불일치, 불필요한 값을 확인하고 정돈하는 과정이다. 같은 의미의 값이 서로 다르게 입력되어 있으면 하나의 기준으로 통일해야 한다.

② 전처리

전처리는 데이터 분석이나 머신러닝에 적합하도록 데이터를 변환하는 넓은 과정이다. 정리, 변환, 통합, 축소, 스케일 조정 등이 포함될 수 있다.

③ 결측값

결측값은 비어 있거나 누락된 값이다. 설문 미응답, 센서 오류, 파일 변환 문제 등으로 생긴다. 삭제, 대체, 별도 범주 처리 등 목적에 맞게 다룬다.

④ 중복값

중복값은 같은 정보가 여러 번 들어간 경우이다. 단순 입력 오류일 수도 있고, 실제 반복된 사건일 수도 있으므로 맥락을 확인해야 한다.

⑤ 이상값

이상값은 일반적인 범위에서 크게 벗어난 값이다. 예를 들어 하루 걸음수가 999999라면 입력 오류일 가능성이 있다. 그러나 지진 관측값처럼 중요한 사건일 수도 있다.

⑥ 자료형 변환

자료형 변환은 문자열, 정수, 실수, 날짜 등 값의 종류를 분석 목적에 맞게 바꾸는 과정이다. 숫자가 문자열로 저장되면 평균 계산이 어려울 수 있다.

⑦ 문자열 정리

문자열 정리는 공백 제거, 대소문자 통일, 단위 제거, 오탈자 수정 등을 포함한다. 예를 들어 “ 전주 ”와 “전주”는 사람에게는 같아 보여도 컴퓨터는 다르게 인식한다.

⑧ 정규화와 표준화

정규화는 값을 일정한 범위로 조정하고, 표준화는 평균과 표준편차를 기준으로 스케일을 맞추는 방법이다. 서로 다른 단위의 데이터를 비교하거나 모델에 넣을 때 유용하다.

⑨ 원본 보존과 기록

전처리는 분석 결과를 바꿀 수 있으므로 원본 데이터를 보존하고 어떤 기준으로 처리했는지 기록해야 한다. 이는 재현성과 신뢰성을 높인다.

4. 각각의 개념과 관련된 파이썬 코드

① 결측값 확인

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "점수": [90, None, 85]
})

print(df.isna().sum())

각 열에 결측값이 몇 개 있는지 확인한다.

② 결측값 대체

df["점수"] = df["점수"].fillna(df["점수"].mean())
print(df)

비어 있는 점수를 평균값으로 대체한다. 단, 평균 대체가 항상 옳은 것은 아니므로 목적을 고려해야 한다.

③ 중복 제거

df = pd.DataFrame({
    "학번": [101, 101, 102],
    "이름": ["가은", "가은", "나래"]
})

clean = df.drop_duplicates()
print(clean)

완전히 같은 행이 반복될 때 중복 행을 제거한다.

④ 문자열 공백 제거

df = pd.DataFrame({"지역": [" 전주", "익산 ", " 군산 "]})
df["지역"] = df["지역"].str.strip()
print(df)

문자열 앞뒤 공백을 제거하여 같은 값을 일관되게 만든다.

⑤ 자료형 변환

df = pd.DataFrame({"가격": ["1200", "900", "1500"]})
df["가격"] = df["가격"].astype(int)
print(df["가격"].mean())

문자열로 저장된 가격을 정수형으로 바꿔 평균을 계산한다.

5. 실생활 관련 코드 예제 5개

예제 1. 설문 만족도 결측값 처리

import pandas as pd

df = pd.DataFrame({
    "학생": ["A", "B", "C", "D"],
    "만족도": [5, None, 4, 3]
})

df["만족도_대체"] = df["만족도"].fillna(df["만족도"].mean())
print(df)

상세 설명: 응답하지 않은 만족도를 평균으로 대체한다. 실제 분석에서는 결측 원인을 먼저 확인해야 한다.

예제 2. 회원 명단 중복 제거

import pandas as pd

df = pd.DataFrame({
    "이메일": ["a@school.kr", "b@school.kr", "a@school.kr"],
    "이름": ["가은", "나래", "가은"]
})

print(df.drop_duplicates(subset=["이메일"]))

상세 설명: 이메일을 기준으로 같은 회원이 두 번 입력된 경우 하나만 남긴다.

예제 3. 가격 문자열 정리

import pandas as pd

df = pd.DataFrame({"가격": ["1,200원", "900원", "2,500원"]})
df["가격"] = df["가격"].str.replace(",", "").str.replace("원", "").astype(int)

print(df)
print("평균 가격:", df["가격"].mean())

상세 설명: 쉼표와 단위를 제거한 뒤 정수형으로 바꾸어 계산 가능하게 만든다.

예제 4. 키 데이터 이상값 확인

import pandas as pd

df = pd.DataFrame({"이름": ["A", "B", "C", "D"], "키": [165, 172, 999, 158]})
outlier = df[df["키"] > 230]

print(outlier)

상세 설명: 사람의 키로 보기 어려운 999를 이상값 후보로 찾는다. 삭제 전에 입력 오류인지 확인해야 한다.

예제 5. 시험 점수 표준화

import pandas as pd

df = pd.DataFrame({"점수": [70, 80, 90, 100]})
df["표준화점수"] = (df["점수"] - df["점수"].mean()) / df["점수"].std()

print(df)

상세 설명: 평균과 표준편차를 이용해 점수의 상대적 위치를 나타낸다.
