2. 수업을 여는 멘트

데이터 과학은 단순히 코드를 실행하는 과목이 아닙니다. “우리 학교 학생들은 언제 가장 많이 도서관을 이용할까?”, “운동 시간과 집중도는 관련이 있을까?” 같은 질문을 데이터로 탐구하는 과정입니다. 인문 철학적으로 데이터 분석 프로젝트는 세상을 숫자로 줄이는 일이 아니라, 숫자 속에서 삶의 맥락을 다시 읽는 일입니다. 오늘 우리는 문제를 정의하고, 데이터를 다루고, 그래프로 표현하고, 책임 있게 해석하는 하나의 작은 데이터 과학 프로젝트를 구현해 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 문제 정의

데이터 분석 프로젝트는 “무엇을 알고 싶은가?”라는 질문에서 시작한다. 문제 정의가 분명해야 데이터 수집, 분석 방법, 시각화 방향이 정해진다.

② 데이터 수집

데이터 수집은 분석에 필요한 자료를 모으는 단계이다. 설문, 공공데이터, 센서, 웹, CSV 파일 등 다양한 출처를 활용할 수 있다.

③ 데이터 이해

수집한 데이터의 열 이름, 자료형, 단위, 결측값, 표본 수, 수집 기간을 확인한다. 데이터의 구조를 모르면 잘못된 분석을 할 수 있다.

④ 데이터 전처리

결측값, 이상값, 중복값, 자료형 오류를 정리하는 단계이다. 전처리는 분석 결과의 신뢰도를 높이는 핵심 과정이다.

⑤ 탐색적 데이터 분석

평균, 중앙값, 최댓값, 최솟값, 분포, 상관관계 등을 살펴보며 데이터의 특징을 파악한다.

⑥ 데이터 시각화

그래프를 이용해 변화, 비교, 관계, 분포를 한눈에 볼 수 있게 표현한다. 그래프 선택은 질문과 데이터 형태에 맞아야 한다.

⑦ 결과 해석

분석 결과가 무엇을 의미하는지 설명하는 단계이다. 수치와 그래프를 근거로 결론을 제시하되, 인과관계를 성급히 단정하지 않는다.

⑧ 한계와 윤리

데이터 출처, 표본 수, 수집 방식, 개인정보, 편향 가능성 등 분석의 한계를 함께 제시해야 한다.

⑨ 보고서 작성

프로젝트 보고서는 문제 정의, 데이터 설명, 분석 방법, 결과, 시각화, 해석, 한계, 개선 방향을 포함하면 좋다.

⑩ 재현 가능성

다른 사람이 같은 데이터와 코드로 같은 결과를 얻을 수 있도록 코드와 과정을 명확히 정리하는 것이 중요하다.

4. 각각의 개념과 관련된 파이썬 코드

① 프로젝트용 데이터 만들기

import pandas as pd

df = pd.DataFrame({
    "month": ["Mar", "Apr", "May", "Jun"],
    "reading": [12, 18, 15, 22],
    "study_hour": [30, 35, 32, 40]
})

print(df)

월별 독서량과 공부 시간을 표 데이터로 만든다.

② 데이터 구조 확인

print(df.head())
print(df.info())
print(df.describe())

데이터의 앞부분, 자료형, 요약 통계를 확인한다.

③ 결측값 확인

print(df.isna().sum())

열별 결측값 개수를 확인한다.

④ 기본 분석

print("reading average:", df["reading"].mean())
print("study max:", df["study_hour"].max())

독서량 평균과 공부 시간 최댓값을 계산한다.

⑤ 시각화

import matplotlib.pyplot as plt

plt.plot(df["month"], df["reading"], marker="o", label="Reading")
plt.plot(df["month"], df["study_hour"], marker="o", label="Study Hour")
plt.title("Monthly Reading and Study")
plt.xlabel("Month")
plt.ylabel("Value")
plt.legend()
plt.show()

월별 독서량과 공부 시간의 변화를 선그래프로 비교한다.

⑥ 해석문 출력

max_month = df.loc[df["reading"].idxmax(), "month"]
print("Reading was highest in", max_month)
print("More data is needed to explain the reason.")

가장 독서량이 많은 달을 찾고, 원인 해석에는 추가 데이터가 필요하다는 한계를 함께 출력한다.

5. 실생활 관련 코드 예제 5개

예제 1. 학교 독서량 프로젝트

import pandas as pd

df = pd.DataFrame({
    "class": ["A", "B", "C"],
    "books": [120, 95, 140]
})

print(df.sort_values("books", ascending=False))

상세 설명: 학급별 독서량을 비교하고 가장 많은 학급을 찾는다.

예제 2. 월별 전기 사용량 분석

import pandas as pd

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar", "Apr"],
    "electricity": [320, 280, 250, 230]
})

print("average:", df["electricity"].mean())

상세 설명: 월별 전기 사용량의 평균을 계산하여 에너지 사용 패턴을 분석한다.

예제 3. 만족도 설문 분석

import pandas as pd

df = pd.DataFrame({
    "satisfaction": [5, 4, 3, 5, 4, None]
})

df["satisfaction"] = df["satisfaction"].fillna(df["satisfaction"].mean())
print(df["satisfaction"].mean())

상세 설명: 결측값을 평균으로 채운 뒤 만족도 평균을 계산한다.

예제 4. 운동 시간과 집중도 관계

import pandas as pd

df = pd.DataFrame({
    "exercise": [1, 2, 3, 4, 5],
    "focus": [60, 65, 72, 80, 82]
})

print(df.corr(numeric_only=True))

상세 설명: 운동 시간과 집중도 사이의 상관관계를 확인하되 인과관계로 단정하지 않는다.

예제 5. 분석 결과 그래프 만들기

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "month": ["Mar", "Apr", "May", "Jun"],
    "visitors": [100, 130, 120, 160]
})

plt.bar(df["month"], df["visitors"])
plt.title("Monthly Visitors")
plt.xlabel("Month")
plt.ylabel("Visitors")
plt.show()

상세 설명: 월별 방문자 수를 막대그래프로 표현해 비교한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 데이터 분석 프로젝트가 문제 정의에서 시작하여 수집, 전처리, 분석, 시각화, 해석, 보고서 작성으로 이어지는 탐구 과정임을 배웠습니다. 컴퓨터과학은 데이터를 처리하고 자동화하는 도구를 제공하고, 수학은 평균·비율·상관관계의 의미를 설명하며, 과학은 결과가 실제 세계에서 타당한지 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “데이터로 말할 때, 우리는 누구의 목소리를 담고 누구의 맥락을 놓치고 있는가?” 좋은 데이터 과학자는 코드를 잘 쓰는 사람을 넘어, 데이터로 근거 있게 질문하고 책임 있게 답하는 사람입니다.
