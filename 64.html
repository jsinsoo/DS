2. 수업을 여는 멘트

학생이 공부할 때도 먼저 자료를 모으고, 중요한 내용을 정리하고, 문제를 풀어 보며, 틀린 부분을 확인하고 다시 공부합니다. AI의 데이터 학습 과정도 이와 비슷합니다. 데이터를 모으고, 정리하고, 학습하고, 평가하고, 개선합니다. 인문 철학적으로 학습은 단순한 암기가 아니라 경험을 해석하고 다음 행동을 바꾸는 과정입니다. 오늘 우리는 AI가 데이터를 어떻게 경험으로 바꾸는지, 그리고 그 배움이 정말 믿을 만한지 확인하는 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 데이터 수집

데이터 수집은 모델이 학습할 자료를 모으는 단계이다. 설문, 센서, 웹, 공공데이터, 로그 등 다양한 출처가 있으며, 수집 단계에서부터 편향과 개인정보 문제가 생길 수 있다.

② 데이터 전처리

전처리는 결측값, 이상값, 중복값, 자료형 오류, 불필요한 열을 정리하는 과정이다. 좋은 전처리는 모델이 의미 있는 패턴을 학습하도록 돕는다.

③ 특징 구성

특징은 모델이 입력으로 사용하는 변수이다. 예측에 필요한 정보를 잘 담은 특징을 선택하거나 새로 만드는 과정은 모델 성능에 큰 영향을 준다.

④ 레이블 구성

레이블은 지도학습에서 모델이 맞히려는 정답이다. 레이블이 잘못되거나 편향되어 있으면 모델도 잘못된 기준을 학습한다.

⑤ 데이터 분리

데이터는 보통 훈련, 검증, 테스트 데이터로 나눈다. 훈련 데이터는 학습, 검증 데이터는 조정, 테스트 데이터는 최종 평가에 사용한다.

⑥ 모델 학습

모델 학습은 입력 특징과 레이블 사이의 관계를 찾는 과정이다. 모델은 예측값과 실제값의 차이를 줄이는 방향으로 내부 기준을 조정한다.

⑦ 모델 평가

모델 평가는 예측 결과가 실제 정답과 얼마나 잘 맞는지 확인하는 과정이다. 분류에서는 정확도, 회귀에서는 오차를 사용할 수 있다.

⑧ 모델 개선

모델 개선은 평가 결과를 바탕으로 데이터 추가, 전처리 수정, 특징 개선, 모델 변경 등을 수행하는 과정이다. 학습 과정은 한 번으로 끝나지 않고 반복된다.

⑨ 윤리와 책임

학습 데이터에 개인정보가 포함되거나 특정 집단이 과소대표되면 AI 결과가 사람에게 부당한 영향을 줄 수 있다. 데이터 학습 과정 전체에서 공정성과 책임성을 점검해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 데이터 준비

import pandas as pd

df = pd.DataFrame({
    "study_hour": [1, 2, 3, 4, 5],
    "sleep_hour": [5, 6, 7, 7, 8],
    "score": [50, 60, 70, 82, 90]
})

print(df)

학습에 사용할 표 형태 데이터를 준비한다.

② 특징과 레이블 나누기

X = df[["study_hour", "sleep_hour"]]
y = df["score"]

print("Features")
print(X)
print("Label")
print(y)

모델이 사용할 입력 특징과 맞혀야 할 정답 레이블을 분리한다.

③ 훈련 데이터와 테스트 데이터 나누기

train = df.iloc[:3]
test = df.iloc[3:]

print("Train data")
print(train)
print("Test data")
print(test)

앞부분은 학습용, 뒷부분은 평가용으로 나눈다. 실제 수업에서는 무작위 분리도 사용할 수 있다.

④ 단순 예측 모델 만들기

def predict_score(study_hour):
    return 45 + study_hour * 9

prediction = predict_score(4)
print("Predicted score:", prediction)

공부 시간을 입력하면 점수를 예측하는 매우 단순한 모델이다.

⑤ 평가와 개선 판단

real = [82, 90]
pred = [81, 88]

errors = [abs(r - p) for r, p in zip(real, pred)]
mean_error = sum(errors) / len(errors)

print("Errors:", errors)
print("Mean error:", mean_error)

예측값과 실제값의 차이를 계산해 모델을 평가한다.

5. 실생활 관련 코드 예제 5개

예제 1. 성적 예측 학습 데이터 구성

import pandas as pd

df = pd.DataFrame({
    "study_hour": [1, 2, 3, 4],
    "homework": [2, 3, 4, 5],
    "score": [55, 65, 75, 88]
})

X = df[["study_hour", "homework"]]
y = df["score"]

print(X)
print(y)

상세 설명: 공부 시간과 과제 횟수는 특징, 실제 점수는 레이블이다.

예제 2. 스팸 분류 학습 과정 단순화

messages = ["free prize", "hello friend", "win money", "class notice"]
labels = ["spam", "normal", "spam", "normal"]

for msg, label in zip(messages, labels):
    print(msg, "->", label)

상세 설명: 메시지와 정답 레이블을 함께 준비하면 지도학습 데이터가 된다.

예제 3. 테스트 데이터로 평가하기

real = ["spam", "normal", "spam"]
pred = ["spam", "normal", "normal"]

accuracy = sum(r == p for r, p in zip(real, pred)) / len(real)
print("Accuracy:", accuracy)

상세 설명: 실제 정답과 예측 결과를 비교하여 정확도를 계산한다.

예제 4. 데이터 편향 확인

from collections import Counter

labels = ["A", "A", "A", "A", "B"]
print(Counter(labels))

상세 설명: A가 지나치게 많고 B가 적으면 모델이 A에 치우친 판단을 할 수 있다.

예제 5. 개선 반복 판단

old_accuracy = 0.70
new_accuracy = 0.82

if new_accuracy > old_accuracy:
    print("Model improved")
else:
    print("Need more improvement")

상세 설명: 개선 전후 성능을 비교하여 모델이 나아졌는지 판단한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 AI가 데이터를 통해 배우는 과정을 단계별로 살펴보았습니다. 컴퓨터과학은 데이터를 모델로 학습시키는 알고리즘을 제공하고, 수학은 오차와 평가 지표로 성능을 설명하며, 과학은 학습 결과가 새로운 상황에서도 타당한지 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “기계가 배운 데이터는 누구의 경험을 대표하고, 누구의 경험을 빠뜨리고 있는가?” 좋은 데이터 과학자는 모델을 학습시키는 사람을 넘어, 데이터가 지식이 되는 전 과정을 책임 있게 점검하는 사람입니다.
