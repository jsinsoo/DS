2. 수업을 여는 멘트

AI 모델이 90%를 맞혔다고 하면 좋아 보입니다. 그러나 나머지 10%가 중요한 질병을 놓친 경우라면 어떨까요? 추천 모델이 정확해 보여도 특정 집단에게 불리하게 작동한다면 사용할 수 있을까요? 인문 철학적으로 모델 평가는 “맞고 틀림”을 넘어 “그 판단을 사회가 받아들여도 되는가”라는 질문과 연결됩니다. 오늘 우리는 모델의 성능을 숫자로 평가하는 방법과, 그 숫자를 실제 삶에 적용할 때 필요한 책임을 함께 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 모델 평가

모델 평가는 모델이 예측한 결과와 실제 정답을 비교하여 성능을 확인하는 과정이다. 학습 데이터가 아니라 새로운 데이터에서도 잘 작동하는지 확인하는 것이 중요하다.

② 테스트 데이터

테스트 데이터는 모델 학습에 사용하지 않고 평가에만 사용하는 데이터이다. 모델이 훈련 데이터를 외운 것인지, 실제로 일반화한 것인지 확인하는 데 필요하다.

③ 정확도

정확도는 전체 예측 중 맞힌 예측의 비율이다. 간단하고 직관적이지만, 데이터가 불균형할 때는 성능을 과대평가할 수 있다.

④ 오차

오차는 예측값과 실제값의 차이이다. 회귀 모델에서는 평균절대오차처럼 예측 수치가 실제 수치와 얼마나 차이 나는지를 평가한다.

⑤ 혼동행렬

혼동행렬은 분류 모델에서 실제값과 예측값의 조합을 표로 정리한 것이다. 어떤 종류의 오답이 많이 발생하는지 확인할 수 있다.

⑥ 정밀도와 재현율

정밀도는 양성이라고 예측한 것 중 실제 양성의 비율이고, 재현율은 실제 양성 중 모델이 양성으로 찾아낸 비율이다. 질병 탐지처럼 놓치면 위험한 문제에서는 재현율이 중요할 수 있다.

⑦ 과적합

과적합은 훈련 데이터에는 매우 잘 맞지만 새로운 데이터에는 잘 맞지 않는 상태이다. 훈련 정확도와 테스트 정확도의 차이가 크면 과적합을 의심할 수 있다.

⑧ 모델 활용

모델 활용은 평가된 모델을 실제 문제 해결에 적용하는 과정이다. 추천, 예측, 분류, 진단 보조, 위험 감지 등 다양한 분야에서 사용될 수 있다.

⑨ 책임 있는 AI 활용

모델을 실제로 활용할 때는 정확도뿐 아니라 공정성, 개인정보 보호, 설명 가능성, 안전성, 책임 소재를 함께 검토해야 한다. 중요한 결정에서는 인간의 검토가 필요하다.

4. 각각의 개념과 관련된 파이썬 코드

① 정확도 계산

real = ["spam", "normal", "spam", "normal"]
pred = ["spam", "normal", "normal", "normal"]

accuracy = sum(r == p for r, p in zip(real, pred)) / len(real)
print("Accuracy:", accuracy)

전체 예측 중 실제 정답과 일치한 비율을 계산한다.

② 회귀 오차 계산

real = [80, 90, 70]
pred = [78, 92, 75]

errors = [abs(r - p) for r, p in zip(real, pred)]
mae = sum(errors) / len(errors)

print("Errors:", errors)
print("Mean Absolute Error:", mae)

예측 점수와 실제 점수의 차이를 절댓값으로 계산하고 평균을 구한다.

③ 혼동행렬 직접 만들기

real = ["positive", "negative", "positive", "negative"]
pred = ["positive", "positive", "negative", "negative"]

tp = sum(r == "positive" and p == "positive" for r, p in zip(real, pred))
tn = sum(r == "negative" and p == "negative" for r, p in zip(real, pred))
fp = sum(r == "negative" and p == "positive" for r, p in zip(real, pred))
fn = sum(r == "positive" and p == "negative" for r, p in zip(real, pred))

print("TP:", tp, "TN:", tn, "FP:", fp, "FN:", fn)

분류 결과를 참양성, 참음성, 거짓양성, 거짓음성으로 나누어 확인한다.

④ 과적합 판단

train_accuracy = 0.98
test_accuracy = 0.65

if train_accuracy - test_accuracy > 0.2:
    print("Possible overfitting")
else:
    print("Generalization looks acceptable")

훈련 성능과 테스트 성능의 차이가 크면 과적합을 의심할 수 있다.

⑤ 활용 가능성 체크

accuracy = 0.92
has_bias_check = True
has_privacy_check = True

if accuracy >= 0.9 and has_bias_check and has_privacy_check:
    print("Ready for careful use")
else:
    print("Need more evaluation")

성능뿐 아니라 편향 점검과 개인정보 점검이 함께 필요함을 보여 준다.

5. 실생활 관련 코드 예제 5개

예제 1. 스팸 필터 정확도 평가

real = ["spam", "normal", "normal", "spam", "spam"]
pred = ["spam", "normal", "spam", "spam", "normal"]

accuracy = sum(r == p for r, p in zip(real, pred)) / len(real)
print("Spam filter accuracy:", accuracy)

상세 설명: 스팸 필터가 실제 정답과 얼마나 일치하는지 정확도로 평가한다.

예제 2. 시험 점수 예측 모델 평가

real_scores = [88, 76, 92, 65]
pred_scores = [85, 80, 90, 70]

mae = sum(abs(r - p) for r, p in zip(real_scores, pred_scores)) / len(real_scores)
print("Mean Absolute Error:", mae)

상세 설명: 예측 점수와 실제 점수의 평균적인 차이를 계산한다.

예제 3. 질병 탐지 오답 유형 확인

real = ["disease", "normal", "disease", "normal", "disease"]
pred = ["disease", "normal", "normal", "normal", "disease"]

missed = sum(r == "disease" and p == "normal" for r, p in zip(real, pred))
print("Missed disease cases:", missed)

상세 설명: 질병이 있는데 정상으로 예측한 경우는 위험할 수 있으므로 따로 확인해야 한다.

예제 4. 추천 모델 활용 점검

groups = ["A", "A", "A", "B"]
recommendations = ["science", "science", "science", "music"]

from collections import Counter

print(Counter(zip(groups, recommendations)))

상세 설명: 특정 집단에 특정 추천만 몰리는지 확인해 편향 가능성을 점검한다.

예제 5. 모델 배포 전 체크리스트

checks = {
    "accuracy_ok": True,
    "bias_checked": True,
    "privacy_checked": True,
    "human_review": True
}

if all(checks.values()):
    print("Deploy with monitoring")
else:
    print("Do not deploy yet")

상세 설명: 모델을 실제로 활용하기 전 성능, 편향, 개인정보, 인간 검토 조건을 확인한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 모델을 평가하고 활용한다는 것이 단순히 높은 정확도를 확인하는 일이 아님을 배웠습니다. 컴퓨터과학은 성능 지표와 평가 절차를 제공하고, 수학은 오차와 비율을 통해 모델의 판단을 수치화하며, 과학은 그 결과가 실제 상황에서도 타당한지 검증하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “AI가 틀렸을 때 피해는 누구에게 가며, 책임은 누가 져야 하는가?” 좋은 데이터 과학자는 모델을 만드는 사람을 넘어, 모델을 언제 어떻게 써야 하는지 책임 있게 판단하는 사람입니다.
