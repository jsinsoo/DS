수업을 여는 멘트

우리가 사용하는 검색어, 위치 기록, 사진, 구매 내역은 단순한 숫자의 조각이 아닙니다. 그것은 한 사람의 취향, 관계, 습관, 삶의 방향을 비추는 흔적입니다. 데이터 과학은 세상을 더 편리하게 만들 수 있지만, 동시에 사람을 수단으로만 바라보는 위험도 가집니다. 오늘 수업은 “데이터를 얼마나 잘 분석할 것인가?”를 넘어 “데이터를 어떻게 인간답게 사용할 것인가?”를 묻는 시간입니다.

개념기반 목표지향 수업지도안

핵심 개념

데이터 윤리개인정보익명화동의책임성

핵심 질문

데이터를 활용해 사회적 가치를 만들면서도 개인의 권리와 자유를 어떻게 보호할 수 있을까?

지식 목표

개인정보, 민감정보, 가명정보, 익명정보, 데이터 윤리 원칙을 설명한다.

기능 목표

간단한 개인정보 탐지, 마스킹, 가명처리 코드를 작성하고 결과를 해석한다.

태도 목표

데이터 분석 과정에서 편리함보다 인간의 존엄, 공정성, 책임성을 우선 고려한다.

평가 방법

진단 OX, 형성 5지선다, 코드 실행 결과 해석, 윤리적 판단 근거 제시를 종합 평가한다.

수업 흐름

  1. 도입: 앱 권한과 개인정보 사례 토의
  2. 전개1: 개인정보와 데이터 윤리 개념 설명
  3. 전개2: 파이썬으로 마스킹·가명처리 실습
  4. 정리: 데이터 활용과 권리 보호의 균형 토론
  5. 평가: 자동 채점 후 TXT 결과 저장

각각의 개념에 대한 상세 설명

1. 개인정보

살아 있는 개인을 알아볼 수 있는 정보이다. 이름, 전화번호, 주소처럼 직접 식별되는 정보뿐 아니라 여러 정보를 결합했을 때 특정 개인을 알아볼 수 있는 정보도 포함된다.

2. 민감정보

건강, 생체, 사상, 신념, 정치적 견해 등 개인의 권리 침해 위험이 큰 정보이다. 일반 개인정보보다 더 엄격한 보호가 필요하다.

3. 데이터 윤리

데이터를 수집, 저장, 분석, 공유, 폐기하는 과정에서 인간의 권리와 사회적 책임을 고려하는 원칙이다.

4. 동의와 목적 제한

데이터는 명확한 목적을 밝히고 필요한 범위에서 수집해야 한다. 수집 목적과 다른 용도로 사용하려면 추가적인 정당성이 필요하다.

5. 최소 수집

분석에 꼭 필요한 데이터만 수집하는 원칙이다. 데이터가 많을수록 항상 좋은 것이 아니라, 위험도 함께 커진다.

6. 익명화와 가명처리

익명화는 개인을 다시 알아보기 어렵게 만드는 처리이고, 가명처리는 이름 등 식별자를 다른 값으로 바꾸어 직접 식별을 줄이는 방법이다.

7. 공정성과 편향

데이터가 특정 집단을 과소대표하거나 과거의 차별을 담고 있으면 분석 결과도 불공정해질 수 있다.

8. 책임성과 투명성

데이터 기반 의사결정의 이유와 과정이 설명 가능해야 하며, 피해가 발생했을 때 책임 주체와 수정 절차가 있어야 한다.

각각의 개념과 관련된 파이썬 코드

개인정보 마스킹 예제

import re

text = "김민수의 전화번호는 010-1234-5678이고 이메일은 minsu@example.com입니다."

masked_phone = re.sub(r"010-\d{4}-\d{4}", "010-****-****", text)
masked_email = re.sub(r"[\w.-]+@[\w.-]+", "***@***", masked_phone)

print(masked_email)

이 코드는 정규표현식으로 전화번호와 이메일 패턴을 찾아 직접 식별 가능한 부분을 가린다. 데이터 분석 전 개인정보 노출 위험을 줄이는 기본적인 보호 기법이다.

풀이: 개인정보는 살아 있는 개인을 알아볼 수 있는 정보이며 이름과 전화번호는 대표적 예이다.

OX 3. 민감정보는 일반 개인정보보다 더 신중하게 다루어야 한다.
정답: O
풀이: 건강, 생체, 신념 등은 권리 침해 위험이 크므로 엄격한 보호가 필요하다.

OX 7. 최소 수집 원칙은 필요한 정보만 수집하자는 원칙이다.

정답: O
풀이: 편향된 데이터는 불공정한 의사결정으로 이어질 수 있다.
OX 9. 동의를 받으면 어떤 목적으로든 데이터를 자유롭게 사용할 수 있다.

풀이: 동의는 구체적 목적과 범위 안에서 해석되어야 한다.

정답: O
풀이: 설명 가능성과 책임성은 신뢰받는 데이터 활용의 조건이다.

정답: 1번

정답: 2번

정답: 2번

정답: 1번
풀이: 익명화는 재식별 가능성을 낮추는 처리이다.
문항 8. 책임성에 대한 설명으로 알맞은 것은?
정답: 1번

문항 10. 데이터 과학 수업에서 윤리를 함께 배워야 하는 까닭은?

풀이: 데이터 분석은 사람의 삶과 권리에 영향을 줄 수 있다.

실생활 관련 코드예제 5개

예제 1. 학생 명단 이름 마스킹

names = ["김민수", "이서연", "박지훈"]
masked = [name[0] + "*" + name[-1] for name in names]
print(masked)

성만 남기고 가운데 글자를 가려 명단 공개 시 식별 위험을 낮춘다.

예제 2. 전화번호 일부 숨기기

phones = ["010-1234-5678", "010-9876-1111"]
for p in phones:
    print(p[:4] + "****" + p[-5:])

상담 기록이나 신청자 목록을 공유할 때 전화번호 중간 자리를 숨긴다.

예제 3. 최소 수집 원칙 확인

columns = ["이름", "학년", "취미", "주민번호", "점수"]
needed = ["학년", "점수"]
print([c for c in columns if c in needed])

분석 목적에 필요한 열만 선택하여 불필요한 개인정보 수집을 줄인다.

예제 4. 이메일 도메인만 분석

emails = ["a@school.kr", "b@naver.com", "c@school.kr"]
domains = [e.split("@")[1] for e in emails]
print(domains)

개별 이메일 주소 대신 도메인만 사용하면 개인 식별 위험을 낮추면서도 통계 분석이 가능하다.

예제 5. 가명 ID 만들기

import hashlib
students = ["김민수", "이서연", "박지훈"]
for s in students:
    pseudo_id = hashlib.sha256(s.encode()).hexdigest()[:8]
    print(pseudo_id)

해시 함수를 이용해 이름을 직접 노출하지 않는 가명 ID를 만든다. 단, 해시도 완전한 익명화가 아니므로 관리가 필요하다.

학번과 이름을 입력한 뒤 결과 저장 버튼을 누르면 자동으로 TXT 파일이 생성됩니다.

수업을 마무리 하는 멘트

컴퓨터과학은 데이터를 처리하는 방법을 가르쳐 주고, 수학은 데이터 속 패턴을 해석하게 하며, 과학은 증거를 바탕으로 세계를 이해하게 합니다. 그러나 인문 철학은 우리에게 더 근본적인 질문을 던집니다. “이 분석은 누구를 위한 것인가?”, “편리함 때문에 누군가의 자유와 존엄을 침해하고 있지는 않은가?” 데이터 과학의 진정한 힘은 정확한 예측만이 아니라, 사람을 존중하는 지혜로운 활용에서 완성됩니다.
