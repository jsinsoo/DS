2. 수업을 여는 멘트

사람은 경험을 통해 배웁니다. 여러 번 문제를 풀다 보면 어떤 유형이 나오는지 알게 되고, 새로운 문제를 만나도 비슷한 방식으로 해결합니다. 머신러닝도 이와 비슷합니다. 컴퓨터는 과거 데이터에서 패턴을 찾고, 그 패턴을 새로운 데이터에 적용합니다. 하지만 사람도 잘못된 경험에서 편견을 배울 수 있듯이, 기계도 편향된 데이터에서 잘못된 판단을 배울 수 있습니다. 오늘 우리는 머신러닝이 어떻게 배우고, 왜 새로운 데이터에서 잘 작동하는지가 중요한지 살펴보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 머신러닝

머신러닝은 컴퓨터가 데이터에서 패턴을 학습하여 새로운 데이터에 대해 예측이나 분류를 수행하는 인공지능 방법이다. 사람이 모든 규칙을 직접 작성하지 않고 데이터로부터 규칙성을 찾는다는 점이 핵심이다.

② 특징

특징은 모델이 예측에 사용하는 입력 변수이다. 예를 들어 시험 점수 예측에서는 공부 시간, 수면 시간, 이전 점수 등이 특징이 될 수 있다.

③ 레이블

레이블은 지도학습에서 모델이 맞히려는 정답 값이다. 스팸 분류에서는 스팸/정상, 점수 예측에서는 실제 시험 점수가 레이블이 된다.

④ 훈련 데이터

훈련 데이터는 모델이 패턴을 배우는 데 사용하는 데이터이다. 훈련 데이터의 품질이 낮거나 한쪽으로 치우치면 모델도 잘못 배울 수 있다.

⑤ 테스트 데이터

테스트 데이터는 학습에 사용하지 않은 데이터로, 모델이 새로운 상황에서 잘 작동하는지 평가하는 데 사용된다.

⑥ 모델

모델은 입력 특징을 받아 예측값을 출력하는 계산 구조이다. 모델은 학습을 통해 입력과 출력 사이의 관계를 찾아낸다.

⑦ 분류

분류는 데이터를 정해진 범주 중 하나로 나누는 문제이다. 이메일을 스팸/정상으로 나누거나 이미지를 고양이/강아지로 나누는 것이 예이다.

⑧ 회귀

회귀는 연속적인 숫자 값을 예측하는 문제이다. 집값, 점수, 온도, 판매량 등을 예측하는 경우가 회귀이다.

⑨ 과적합과 일반화

과적합은 훈련 데이터에는 매우 잘 맞지만 새로운 데이터에는 잘 맞지 않는 상태이다. 일반화는 모델이 학습하지 않은 새로운 데이터에도 잘 작동하는 능력이다.

4. 각각의 개념과 관련된 파이썬 코드

① 특징과 레이블 만들기

import pandas as pd

df = pd.DataFrame({
    "study_hour": [1, 2, 3, 4],
    "sleep_hour": [6, 7, 7, 8],
    "score": [55, 65, 75, 85]
})

X = df[["study_hour", "sleep_hour"]]
y = df["score"]

print(X)
print(y)

study_hour와 sleep_hour는 특징이고, score는 모델이 맞히려는 레이블이다.

② 단순한 규칙 기반 예측

study_hour = 4

predicted_score = 50 + study_hour * 8
print("Predicted score:", predicted_score)

공부 시간이 늘수록 점수가 올라간다고 가정한 단순 예측식이다.

③ 가장 가까운 값으로 예측하기

data = [(1, 55), (2, 65), (3, 75), (4, 85)]
new_study_hour = 3.2

nearest = min(data, key=lambda x: abs(x[0] - new_study_hour))
print("Nearest data:", nearest)
print("Predicted score:", nearest[1])

새 데이터와 가장 가까운 훈련 데이터를 찾아 그 정답을 예측값으로 사용한다.

④ 정확도 계산

real = ["spam", "normal", "spam", "normal"]
pred = ["spam", "normal", "normal", "normal"]

accuracy = sum(r == p for r, p in zip(real, pred)) / len(real)
print("Accuracy:", accuracy)

분류 모델의 예측이 실제 정답과 얼마나 일치하는지 정확도로 계산한다.

⑤ 훈련 데이터와 테스트 데이터 개념

data = [10, 20, 30, 40, 50]

train = data[:3]
test = data[3:]

print("Train:", train)
print("Test:", test)

일부 데이터는 학습에 사용하고, 나머지는 평가에 사용한다.

5. 실생활 관련 코드 예제 5개

예제 1. 공부 시간으로 점수 예측

study_hour = 5
predicted_score = 45 + study_hour * 9

print("Predicted score:", predicted_score)

상세 설명: 공부 시간이 많을수록 점수가 높아진다는 단순한 관계를 가정한 예측이다. 실제로는 수면, 집중도, 난이도도 영향을 준다.

예제 2. 스팸 분류 정확도

real = ["spam", "spam", "normal", "normal", "spam"]
pred = ["spam", "normal", "normal", "normal", "spam"]

correct = sum(r == p for r, p in zip(real, pred))
accuracy = correct / len(real)

print("Accuracy:", accuracy)

상세 설명: 예측 결과와 실제 정답을 비교해 정확도를 계산한다.

예제 3. 추천 모델의 특징 사용

user = {"likes_science": 1, "likes_music": 0}

if user["likes_science"] == 1:
    print("Recommend: Science Documentary")
else:
    print("Recommend: General Video")

상세 설명: 사용자의 특징을 입력으로 사용해 추천 결과를 결정한다. 실제 추천 시스템은 훨씬 많은 특징을 사용한다.

예제 4. 가장 가까운 키로 그룹 예측

train = [(150, "A"), (160, "A"), (175, "B"), (180, "B")]
new_height = 170

nearest = min(train, key=lambda x: abs(x[0] - new_height))
print("Predicted group:", nearest[1])

상세 설명: 새 값과 가장 가까운 훈련 데이터를 찾아 그룹을 예측한다. 최근접 이웃 분류의 기초 아이디어이다.

예제 5. 과적합의 직관

train_accuracy = 1.00
test_accuracy = 0.55

if train_accuracy > 0.95 and test_accuracy < 0.70:
    print("Possible overfitting")
else:
    print("Check model again")

상세 설명: 훈련 정확도는 매우 높은데 테스트 정확도가 낮다면 과적합을 의심할 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 머신러닝이 데이터를 통해 패턴을 배우고, 새로운 데이터에 예측을 적용하는 원리를 배웠습니다. 컴퓨터과학은 모델을 만들고 학습시키는 구조를 제공하고, 수학은 오차와 함수, 거리, 확률을 통해 학습 과정을 설명하며, 과학은 예측 결과가 실제 세계에서 검증되는지 묻게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “기계가 과거 데이터를 배웠다면, 그 안의 편견까지 함께 배운 것은 아닌가?” 좋은 데이터 과학자는 모델의 정확도만 보는 사람이 아니라, 데이터의 출처와 한계, 과적합과 일반화, 그리고 사회적 책임까지 함께 생각하는 사람입니다.
