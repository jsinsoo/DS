2. 수업을 여는 멘트

두 학급의 평균 점수가 모두 80점이라고 해 봅시다. 한 학급은 모든 학생이 78점에서 82점 사이이고, 다른 학급은 40점과 100점이 섞여 있습니다. 평균은 같지만 두 학급의 모습은 전혀 다릅니다. 인문 철학적으로 분산과 표준편차는 “평균 뒤에 숨은 다양성과 차이”를 보게 해 줍니다. 오늘 우리는 데이터가 얼마나 흩어져 있는지 계산하며, 하나의 평균이 가릴 수 있는 현실을 더 깊이 읽어 보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 산포도

산포도는 데이터가 얼마나 흩어져 있는지를 나타내는 정도이다. 평균이나 중앙값이 데이터의 중심을 보여 준다면, 산포도는 값들이 그 중심에서 얼마나 멀리 퍼져 있는지를 보여 준다.

② 편차

편차는 각 데이터 값에서 평균을 뺀 값이다. 편차가 양수이면 평균보다 크고, 음수이면 평균보다 작다. 편차는 각 값이 평균에서 얼마나 벗어났는지 보여 준다.

③ 분산

분산은 편차를 제곱하여 평균적으로 얼마나 흩어졌는지 나타내는 값이다. 편차를 그냥 더하면 양수와 음수가 상쇄될 수 있으므로 제곱을 사용한다.

모집단 분산: σ2=∑(xi−μ)2N

④ 표준편차

표준편차는 분산의 제곱근이다. 분산은 단위가 제곱 형태가 되기 때문에 해석이 어렵지만, 표준편차는 원래 데이터와 비슷한 단위로 해석하기 쉽다.

모집단 표준편차: σ=∑(xi−μ)2N

⑤ 평균이 같은 두 집단

평균이 같더라도 표준편차가 다르면 데이터의 안정성과 다양성이 다르다. 표준편차가 작은 집단은 값들이 평균 주변에 모여 있고, 표준편차가 큰 집단은 값들이 넓게 퍼져 있다.

⑥ 표본 분산과 모집단 분산

모집단 전체를 대상으로 하면 N으로 나누고, 표본으로 모집단을 추정할 때는 보통 n-1로 나눈다. Pandas의 var()와 std()는 기본적으로 표본 분산과 표본 표준편차를 계산한다.

⑦ 이상값의 영향

분산과 표준편차는 편차를 제곱하므로 이상값의 영향을 크게 받을 수 있다. 매우 큰 값 하나가 전체 표준편차를 크게 만들 수 있다.

⑧ 변동성

변동성은 값이 얼마나 자주, 크게 변하는지를 의미한다. 주식 가격, 날씨 변화, 시험 점수, 센서 데이터의 안정성 등을 해석할 때 표준편차를 활용할 수 있다.

⑨ 해석의 윤리

표준편차가 크다는 것은 단순히 나쁘다는 뜻이 아니다. 다양성이 크다는 뜻일 수도 있고, 불평등이나 위험이 크다는 뜻일 수도 있다. 데이터가 만들어진 맥락을 함께 보아야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 평균과 편차 구하기

scores = [70, 80, 90]

mean_score = sum(scores) / len(scores)
deviations = [x - mean_score for x in scores]

print("평균:", mean_score)
print("편차:", deviations)

각 점수가 평균에서 얼마나 떨어져 있는지 편차를 계산한다.

② 직접 분산과 표준편차 구하기

scores = [70, 80, 90]

mean_score = sum(scores) / len(scores)
variance = sum((x - mean_score) ** 2 for x in scores) / len(scores)
std_dev = variance ** 0.5

print("분산:", variance)
print("표준편차:", std_dev)

편차 제곱의 평균으로 분산을 구하고, 제곱근을 취해 표준편차를 구한다.

③ Pandas로 분산과 표준편차 구하기

import pandas as pd

df = pd.DataFrame({"점수": [70, 80, 90]})

print("분산:", df["점수"].var())
print("표준편차:", df["점수"].std())

Pandas의 var()와 std()는 기본적으로 표본 분산과 표본 표준편차를 계산한다.

④ 평균은 같지만 흩어짐이 다른 두 집단

import pandas as pd

class_a = pd.Series([78, 79, 80, 81, 82])
class_b = pd.Series([40, 60, 80, 100, 120])

print("A반 평균:", class_a.mean(), "표준편차:", class_a.std())
print("B반 평균:", class_b.mean(), "표준편차:", class_b.std())

두 반의 평균은 같아도 B반의 표준편차가 더 크므로 점수가 더 넓게 퍼져 있다.

⑤ describe로 한 번에 확인하기

import pandas as pd

df = pd.DataFrame({"키": [160, 162, 165, 170, 180]})

print(df["키"].describe())

개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값을 한 번에 확인한다.

5. 실생활 관련 코드 예제 5개

예제 1. 두 학급의 성적 안정성 비교

import pandas as pd

a = pd.Series([78, 79, 80, 81, 82])
b = pd.Series([60, 70, 80, 90, 100])

print("A mean:", a.mean(), "A std:", a.std())
print("B mean:", b.mean(), "B std:", b.std())

상세 설명: 평균은 같지만 B반 표준편차가 더 크다. B반은 점수가 더 다양하게 흩어져 있다.

예제 2. 하루 기온 변동성 분석

import pandas as pd

temp = pd.Series([20, 21, 23, 24, 22, 21])

print("mean temperature:", temp.mean())
print("standard deviation:", temp.std())

상세 설명: 표준편차가 작으면 하루 기온 변화가 비교적 안정적이라고 볼 수 있다.

예제 3. 운동 기록의 꾸준함 비교

import pandas as pd

week1 = pd.Series([30, 31, 29, 30, 30])
week2 = pd.Series([10, 50, 20, 60, 10])

print("week1 std:", week1.std())
print("week2 std:", week2.std())

상세 설명: week1은 운동 시간이 꾸준하고, week2는 날마다 변동이 크다.

예제 4. 상품 가격의 흩어짐

import pandas as pd

prices = pd.Series([1000, 1100, 1200, 1300, 5000])

print("mean:", prices.mean())
print("std:", prices.std())

상세 설명: 5000원 상품 하나가 표준편차를 크게 만들 수 있다. 이상값 여부를 확인해야 한다.

예제 5. 센서 데이터 이상 변동 감지

import pandas as pd

noise = pd.Series([52, 53, 54, 80, 52, 53])

mean_value = noise.mean()
std_value = noise.std()

print("mean:", mean_value)
print("std:", std_value)
print("check values:", noise[noise > mean_value + 2 * std_value].tolist())

상세 설명: 평균보다 표준편차 2배 이상 큰 값을 확인하여 갑작스러운 소음 증가를 탐지한다.

6. 진단평가 OX 예제 10개

OX 1. 분산은 데이터가 평균으로부터 얼마나 흩어져 있는지를 나타내는 값이다.
정답: O
상세풀이: 분산은 각 값이 평균에서 얼마나 떨어져 있는지 제곱하여 평균적으로 나타낸 값이다.
OX 2. 표준편차는 분산의 제곱근이다.
정답: O
상세풀이: 표준편차는 분산에 제곱근을 취해 원래 데이터 단위와 비슷하게 해석할 수 있다.
OX 3. 모든 값이 같으면 분산과 표준편차는 0이다.
정답: O
상세풀이: 모든 값이 평균과 같으므로 흩어짐이 없다.
OX 4. 표준편차가 클수록 데이터가 평균 주변에 더 촘촘히 모여 있다.
정답: X
상세풀이: 표준편차가 클수록 평균에서 멀리 퍼져 있는 정도가 크다.
OX 5. 분산은 편차를 그대로 더해서 구한다.
정답: X
상세풀이: 편차를 그대로 더하면 0이 되기 쉬우므로 편차의 제곱을 사용한다.
OX 6. 편차는 각 데이터 값에서 평균을 뺀 값이다.
정답: O
상세풀이: 편차는 값이 평균보다 얼마나 크거나 작은지를 나타낸다.
OX 7. 분산은 단위가 원래 데이터 단위의 제곱 형태가 된다.
정답: O
상세풀이: 예를 들어 점수의 분산은 점수 제곱 단위처럼 해석되어 직관성이 낮을 수 있다.
OX 8. 표준편차는 원래 데이터와 같은 단위로 해석하기 쉬운 장점이 있다.
정답: O
상세풀이: 표준편차는 분산의 제곱근이므로 원래 단위와 맞아 해석이 쉽다.
OX 9. 평균이 같은 두 집단이라도 표준편차는 다를 수 있다.
정답: O
상세풀이: 평균이 같아도 한 집단은 고르게 모여 있고 다른 집단은 크게 흩어져 있을 수 있다.
OX 10. Pandas의 std()는 표준편차를 구하는 데 사용할 수 있다.
정답: O
상세풀이: Series.std()는 표준편차를 계산한다.

문항 1. 분산이 나타내는 의미로 가장 적절한 것은?

정답: 1번
상세풀이: 편차는 데이터 값과 평균의 차이이다.

상세풀이: 편차를 그대로 더하면 양수와 음수가 상쇄되므로 제곱을 사용한다.

9. 수업을 마무리 하는 멘트

오늘 우리는 평균만으로는 볼 수 없었던 데이터의 흩어짐을 분산과 표준편차로 살펴보았습니다. 컴퓨터과학은 많은 데이터를 빠르게 계산하게 해 주고, 수학은 편차와 제곱, 제곱근을 통해 흩어짐을 정량화하며, 과학은 변동성과 오차를 해석하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “평균 뒤에 숨은 차이와 다양성을 우리는 충분히 보고 있는가?” 좋은 데이터 과학자는 평균을 말할 때 표준편차도 함께 말하며, 숫자 속에 담긴 다양성과 불균형을 놓치지 않는 사람입니다.
