2. 수업을 여는 멘트

여러분이 사진을 저장하고, 메모를 남기고, 게임 기록을 불러오고, 학교 생활기록부가 관리되는 모든 순간에 데이터 저장이 일어납니다. 저장은 단순히 “어딘가에 넣어 두는 일”이 아닙니다. 인문 철학적으로 저장은 기억의 방식입니다. 어떤 기억은 종이에 적고, 어떤 기억은 파일에 남기며, 어떤 사회적 기록은 데이터베이스에 구조화됩니다. 오늘 우리는 데이터가 어떻게 기억되고, 왜 잘 관리되어야 하는지 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 파일

파일은 데이터를 하나의 단위로 저장하는 기본 방식이다. 텍스트 파일, CSV 파일, JSON 파일, 이미지 파일, 엑셀 파일 등이 모두 파일이다. 파일은 만들고 복사하기 쉽지만, 여러 사람이 동시에 수정하거나 복잡한 검색을 수행하기에는 한계가 있다.

② TXT 파일

TXT 파일은 단순한 문자열을 저장하는 파일이다. 로그, 메모, 간단한 결과 저장에 적합하다. 구조가 단순하므로 사람이 읽기 쉽지만, 열과 행이 명확한 데이터 분석에는 추가 처리가 필요하다.

③ CSV 파일

CSV 파일은 쉼표와 줄바꿈을 이용해 표 형태 데이터를 저장한다. Pandas와 엑셀에서 쉽게 읽을 수 있어 데이터 분석에서 자주 사용된다. 다만 자료형, 관계, 제약 조건을 엄격히 관리하기 어렵다.

④ JSON 파일

JSON은 key-value 구조로 데이터를 저장하는 형식이다. 웹 API 응답, 설정 파일, 중첩 구조 데이터 저장에 자주 사용된다. 리스트와 딕셔너리 구조를 표현하기 쉽다.

⑤ 데이터베이스

데이터베이스는 여러 데이터를 체계적으로 저장하고 관리하는 시스템이다. 단순 저장뿐 아니라 검색, 수정, 삭제, 권한 관리, 동시 접근, 무결성 유지 기능을 제공한다.

⑥ 관계형 데이터베이스

관계형 데이터베이스는 데이터를 표, 즉 테이블 형태로 저장한다. 행은 하나의 레코드, 열은 속성을 의미한다. 학생 테이블, 성적 테이블, 수강 테이블처럼 여러 테이블을 연결하여 중복을 줄이고 의미 있는 관계를 표현할 수 있다.

⑦ 기본키

기본키는 각 행을 고유하게 구별하는 값이다. 학생 데이터에서는 학번이 기본키가 될 수 있다. 기본키를 사용하면 같은 이름의 학생이 있어도 정확히 구별할 수 있다.

⑧ SQL

SQL은 관계형 데이터베이스에서 데이터를 생성, 조회, 수정, 삭제하기 위한 언어이다. SELECT는 조회, INSERT는 삽입, UPDATE는 수정, DELETE는 삭제에 사용된다.

⑨ 데이터 무결성과 백업

데이터 무결성은 데이터가 정확하고 일관성 있게 유지되는 상태를 뜻한다. 백업은 데이터 손실에 대비해 복사본을 저장하는 것이다. 중요한 데이터는 저장 구조뿐 아니라 복구 가능성도 고려해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① TXT 파일 저장

text = "데이터 과학 수업 기록입니다."

with open("note.txt", "w", encoding="utf-8") as f:
    f.write(text)

print("TXT 저장 완료")

문자열을 텍스트 파일로 저장한다. with 구문은 파일을 안전하게 열고 닫아 준다.

② CSV 파일 저장

import pandas as pd

df = pd.DataFrame({
    "학번": [101, 102, 103],
    "이름": ["김데이터", "이분석", "박저장"],
    "점수": [90, 85, 95]
})

df.to_csv("score.csv", index=False, encoding="utf-8-sig")
print("CSV 저장 완료")

표 형태 데이터를 CSV 파일로 저장한다. utf-8-sig는 엑셀에서 한글이 깨지는 문제를 줄인다.

③ JSON 파일 저장

import json

student = {
    "학번": 101,
    "이름": "김데이터",
    "관심분야": ["인공지능", "데이터 분석"]
}

with open("student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, ensure_ascii=False, indent=2)

print("JSON 저장 완료")

딕셔너리와 리스트 구조를 JSON 파일로 저장한다. ensure_ascii=False는 한글을 그대로 저장하게 한다.

④ SQLite 데이터베이스 만들기

import sqlite3

conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("""
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    score INTEGER
)
""")

conn.commit()
conn.close()
print("테이블 생성 완료")

SQLite는 파이썬 기본 라이브러리로 사용할 수 있는 가벼운 데이터베이스이다. students 테이블을 만든다.

⑤ 데이터 삽입과 조회

import sqlite3

conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("INSERT INTO students VALUES (?, ?, ?)", (101, "김데이터", 90))
cur.execute("SELECT * FROM students")

rows = cur.fetchall()
print(rows)

conn.commit()
conn.close()

데이터베이스에 학생 정보를 삽입하고 전체 데이터를 조회한다. 물음표는 안전한 값 전달 방식이다.

5. 실생활 관련 코드 예제 5개

예제 1. 출석 기록 CSV 저장

import pandas as pd

df = pd.DataFrame({
    "날짜": ["2026-05-01", "2026-05-02", "2026-05-03"],
    "이름": ["김데이터", "김데이터", "김데이터"],
    "출석": ["출석", "지각", "출석"]

df.to_csv("attendance.csv", index=False, encoding="utf-8-sig")
print(df)

상세 설명: 출석 기록은 표 형식이므로 CSV 저장에 적합하다. 날짜, 이름, 출석 상태를 열로 구성한다.

예제 2. 개인 설정 JSON 저장

import json

settings = {
    "theme": "light",
    "font_size": 16,
    "notifications": True
}

with open("settings.json", "w", encoding="utf-8") as f:
    json.dump(settings, f, ensure_ascii=False, indent=2)

print("설정 저장 완료")

상세 설명: 앱의 설정처럼 key-value 구조가 분명한 데이터는 JSON으로 저장하기 좋다.

예제 3. 독서 목록 데이터베이스 저장

import sqlite3

conn = sqlite3.connect("library.db")
cur = conn.cursor()

cur.execute("CREATE TABLE IF NOT EXISTS books (id INTEGER PRIMARY KEY, title TEXT, author TEXT)")
cur.execute("INSERT INTO books VALUES (?, ?, ?)", (1, "데이터 과학 입문", "홍길동"))
cur.execute("SELECT title, author FROM books")

print(cur.fetchall())

conn.commit()
conn.close()

상세 설명: 도서 목록처럼 계속 추가·검색해야 하는 데이터는 데이터베이스에 저장하면 편리하다.

예제 4. 성적 데이터 조회 조건 적용

import sqlite3

conn = sqlite3.connect(":memory:")
cur = conn.cursor()

cur.execute("CREATE TABLE scores (name TEXT, score INTEGER)")
cur.executemany("INSERT INTO scores VALUES (?, ?)", [
    ("가은", 95), ("나래", 82), ("다온", 76)
])

cur.execute("SELECT name, score FROM scores WHERE score >= 80")
print(cur.fetchall())

conn.close()

상세 설명: SQL의 WHERE 조건을 이용해 80점 이상 학생만 조회한다. 데이터베이스의 검색 기능을 보여 준다.

예제 5. CSV 파일과 데이터베이스 선택 기준

data_size = "large"
many_users = True

if data_size == "small" and not many_users:
    print("CSV 파일 저장이 적합합니다.")
else:
    print("데이터베이스 저장이 적합합니다.")

상세 설명: 데이터 양이 적고 단순하면 CSV가 편리하지만, 데이터가 많거나 여러 사용자가 함께 다루면 데이터베이스가 더 적합하다.

6. 진단평가 OX 예제 10개

OX 1. 파일은 데이터를 저장하는 기본적인 단위이다.
정답: O
상세풀이: 텍스트, CSV, JSON, 이미지 등 다양한 데이터가 파일 형태로 저장될 수 있다.
OX 2. CSV 파일은 표 형태 데이터를 저장하는 데 자주 사용된다.
정답: O
상세풀이: CSV는 행과 열 구조의 데이터를 쉼표 등 구분자로 저장한다.
OX 3. JSON은 key-value 구조의 데이터를 표현하기 어렵다.
정답: X
상세풀이: JSON은 key-value 구조와 리스트, 중첩 구조를 표현하는 데 적합하다.
OX 4. 데이터베이스는 데이터의 검색, 수정, 삭제, 권한 관리에 활용될 수 있다.
정답: O
상세풀이: DBMS는 단순 저장뿐 아니라 다양한 관리 기능을 제공한다.
OX 5. 관계형 데이터베이스는 데이터를 표 형태의 테이블로 저장한다.
정답: O
상세풀이: 관계형 데이터베이스는 행과 열로 이루어진 테이블을 기본 구조로 사용한다.
OX 6. 기본키는 각 행을 고유하게 구별하는 값이다.
정답: O
상세풀이: 기본키는 같은 이름이나 비슷한 데이터가 있어도 각 레코드를 구분하게 해 준다.
OX 7. SQL은 데이터베이스를 조회하고 조작하는 언어이다.
정답: O
상세풀이: SQL은 SELECT, INSERT, UPDATE, DELETE 등으로 데이터를 다룬다.
OX 8. 데이터베이스를 사용하면 백업이 전혀 필요 없다.
정답: X
상세풀이: 데이터베이스도 장애나 실수에 대비해 백업이 필요하다.
OX 9. 데이터 무결성은 데이터가 정확하고 일관성 있게 유지되는 상태를 뜻한다.
정답: O
상세풀이: 무결성은 데이터 관리에서 신뢰성을 유지하는 핵심 조건이다.
OX 10. 여러 사용자가 동시에 데이터를 수정하는 상황에서는 단순 파일보다 데이터베이스가 유리한 경우가 많다.
정답: O
상세풀이: 데이터베이스는 동시 접근, 무결성, 권한 관리를 지원하므로 협업 상황에 적합하다.

7. 형성평가 5지선다형 10문항

문항 1. 파일의 설명으로 가장 적절한 것은?
정답: 1번
상세풀이: 파일은 데이터를 저장하는 기본 단위이며 다양한 형식을 가질 수 있다.
문항 2. CSV 파일의 특징은?
정답: 1번
상세풀이: CSV는 행과 열 형태 데이터를 텍스트로 저장하는 간단한 형식이다.
문항 3. JSON 파일이 적합한 경우는?
정답: 1번
상세풀이: JSON은 딕셔너리, 리스트와 같은 구조화된 데이터를 표현하기 좋다.
문항 4. 데이터베이스의 장점으로 적절한 것은?
정답: 1번
상세풀이: 데이터베이스는 대량 데이터 관리, 검색, 수정, 권한 관리, 무결성 유지에 유리하다.
문항 5. 관계형 데이터베이스의 기본 저장 구조는?
정답: 1번
상세풀이: 관계형 데이터베이스는 행과 열로 구성된 테이블을 사용한다.
문항 6. 기본키의 역할은?
정답: 1번
상세풀이: 기본키는 레코드를 고유하게 식별하기 위한 속성이다.
문항 7. SQL의 SELECT 문은 주로 무엇을 하는가?
정답: 1번
상세풀이: SELECT는 테이블에서 조건에 맞는 데이터를 조회하는 명령이다.
문항 8. 다음 중 CRUD에 해당하지 않는 것은?
정답: 1번
상세풀이: CRUD는 생성, 읽기, 수정, 삭제를 의미한다. Color는 해당하지 않는다.
문항 9. 데이터 무결성이 중요한 이유는?
정답: 1번
상세풀이: 무결성이 유지되어야 데이터 분석과 의사결정의 신뢰성이 높아진다.
문항 10. 단순 파일보다 데이터베이스가 더 적합한 상황은?
정답: 1번
상세풀이: 여러 사용자와 많은 데이터, 복잡한 검색·수정이 필요한 경우 데이터베이스가 유리하다.

8. 학번_이름_데이터31_점수_응시시각.txt 생성

9. 수업을 마무리 하는 멘트

오늘 우리는 데이터가 파일과 데이터베이스에 어떻게 저장되는지 배웠습니다. 컴퓨터과학은 저장 구조와 SQL, 파일 입출력의 방법을 제공하고, 수학은 표와 관계 속에서 데이터의 구조를 논리적으로 바라보게 하며, 과학은 기록의 정확성과 재현 가능성을 중요하게 여깁니다. 그리고 인문 철학은 우리에게 묻습니다. “우리는 무엇을 기억하고, 무엇을 잊게 할 것인가?” 좋은 데이터 과학자는 데이터를 많이 저장하는 사람이 아니라, 필요한 데이터를 정확하고 안전하며 의미 있게 관리하는 사람입니다.
