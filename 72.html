2. 수업을 여는 멘트

데이터 과학자는 거대한 표 속에서 의미 있는 질문을 찾아내는 사람입니다. 하지만 표를 제대로 읽고 정리하지 못하면 좋은 분석도 시작할 수 없습니다. Pandas는 복잡한 데이터를 정돈된 표로 보고, 필요한 행과 열을 선택하고, 그룹별로 요약하게 해 주는 도구입니다. 인문 철학적으로 Pandas 활용은 혼란스러운 현실을 해석 가능한 질서로 정리하는 과정과 닮았습니다. 오늘 우리는 데이터 표를 읽는 눈과 다루는 손을 함께 기르겠습니다.

3. 각각의 개념에 대한 상세 설명

① Pandas

Pandas는 파이썬에서 표 형태 데이터를 다루는 대표적인 라이브러리이다. 데이터 수집, 정리, 분석, 시각화 전 단계에서 자주 사용된다.

② Series

Series는 Pandas의 1차원 자료구조이다. 하나의 열처럼 인덱스와 값으로 구성된다.

③ DataFrame

DataFrame은 행과 열로 이루어진 2차원 표 형태 자료구조이다. 엑셀 표나 CSV 파일과 비슷한 구조로 이해할 수 있다.

④ 데이터 확인

데이터 분석 전에는 head(), tail(), info(), describe()를 이용해 데이터의 구조와 특징을 먼저 살펴본다.

⑤ 열 선택과 행 선택

특정 열은 df["열이름"]으로 선택할 수 있고, 조건을 이용하면 특정 행만 필터링할 수 있다.

⑥ 조건 필터링

조건 필터링은 특정 조건을 만족하는 행만 선택하는 방법이다. 예를 들어 점수가 80점 이상인 학생만 고를 수 있다.

⑦ 정렬

sort_values()는 특정 열을 기준으로 데이터를 오름차순 또는 내림차순으로 정렬한다.

⑧ 그룹화

groupby()는 범주별 평균, 합계, 개수 등을 구할 때 사용한다. 반별 평균 점수, 지역별 판매량 같은 분석에 유용하다.

⑨ 결측값 처리

결측값은 비어 있는 값이다. isna(), fillna(), dropna()를 이용해 확인하거나 채우거나 제거할 수 있다.

⑩ CSV 입출력

read_csv()로 CSV 파일을 읽고, to_csv()로 분석 결과를 파일로 저장할 수 있다.

4. 각각의 개념과 관련된 파이썬 코드

① DataFrame 만들기

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "점수": [85, 92, 78]
})

print(df)

딕셔너리를 이용해 표 형태 DataFrame을 만든다.

② 데이터 구조 확인

print(df.head())
print(df.info())
print(df.describe())

데이터 앞부분, 자료형, 요약 통계를 확인한다.

③ 열 선택

scores = df["점수"]
print(scores)

점수 열만 선택하여 Series로 확인한다.

④ 조건 필터링

high = df[df["점수"] >= 80]
print(high)

점수가 80점 이상인 행만 선택한다.

⑤ 정렬

sorted_df = df.sort_values("점수", ascending=False)
print(sorted_df)

점수를 기준으로 내림차순 정렬한다.

⑥ 그룹별 평균

df = pd.DataFrame({
    "반": ["A", "A", "B", "B"],
    "점수": [80, 90, 70, 85]
})

print(df.groupby("반")["점수"].mean())

반별 평균 점수를 구한다.

⑦ 결측값 처리

df = pd.DataFrame({"점수": [80, None, 90]})

print(df.isna().sum())
df["점수"] = df["점수"].fillna(df["점수"].mean())
print(df)

결측값을 평균으로 채운다.

5. 실생활 관련 코드 예제 5개

예제 1. 학생 성적표 분석

import pandas as pd

df = pd.DataFrame({
    "name": ["A", "B", "C"],
    "score": [85, 92, 78]
})

print("average:", df["score"].mean())
print("max:", df["score"].max())

상세 설명: 학생 점수의 평균과 최고점을 계산한다.

예제 2. 80점 이상 학생 찾기

import pandas as pd

df = pd.DataFrame({
    "name": ["A", "B", "C", "D"],
    "score": [75, 88, 91, 60]
})

result = df[df["score"] >= 80]
print(result)

상세 설명: 조건 필터링으로 80점 이상 학생만 추출한다.

예제 3. 상품 판매량 정렬

import pandas as pd

df = pd.DataFrame({
    "product": ["apple", "banana", "melon"],
    "sales": [120, 90, 150]
})

print(df.sort_values("sales", ascending=False))

상세 설명: 판매량이 많은 상품부터 정렬한다.

예제 4. 지역별 평균 미세먼지

import pandas as pd

df = pd.DataFrame({
    "region": ["Jeonju", "Jeonju", "Iksan", "Iksan"],
    "pm10": [35, 45, 50, 40]
})

print(df.groupby("region")["pm10"].mean())

상세 설명: 지역별 미세먼지 평균을 groupby로 계산한다.

예제 5. 결측값 있는 설문 데이터 처리

import pandas as pd

df = pd.DataFrame({
    "satisfaction": [5, 4, None, 3, 5]
})

df["satisfaction"] = df["satisfaction"].fillna(df["satisfaction"].mean())
print(df)

상세 설명: 비어 있는 만족도 값을 평균으로 채워 분석 가능한 형태로 만든다.
