2. 수업을 여는 멘트

“우리 학교 독서량이 10권 늘었습니다.” 이 말은 좋아 보입니다. 하지만 전체 학생이 10명인지 1000명인지, 작년에는 몇 권이었는지, 평균인지 총합인지에 따라 의미는 완전히 달라집니다. 인문 철학적으로 데이터 비교는 “무엇을 기준으로 공정하게 판단할 것인가”라는 질문과 연결됩니다. 오늘 우리는 숫자를 단순히 크고 작게 보는 것을 넘어, 기준·단위·맥락을 따져 더 정직하게 해석하는 방법을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 데이터 비교

데이터 비교는 둘 이상의 자료를 같은 기준으로 살펴보며 차이와 공통점을 찾는 과정이다. 집단 간 비교, 시점 간 비교, 지역 간 비교, 항목 간 비교 등이 있다.

② 비교 기준

비교 기준은 어떤 관점에서 데이터를 비교할 것인지를 정하는 것이다. 같은 자료라도 총합, 평균, 비율, 변화율 중 무엇을 기준으로 하느냐에 따라 결론이 달라질 수 있다.

③ 절대 비교

절대 비교는 값 자체의 차이를 비교하는 방식이다. 예를 들어 A반 평균이 85점, B반 평균이 80점이면 A반이 5점 높다고 말할 수 있다.

④ 상대 비교와 비율

상대 비교는 기준값에 대한 비율로 비교하는 방식이다. 규모가 다른 두 집단을 비교할 때는 단순 개수보다 비율이 더 공정할 수 있다.

⑤ 변화율

변화율은 처음 값에 비해 얼마나 증가하거나 감소했는지를 비율로 나타낸 값이다.

변화율 = 나중 값−처음 값처음 값×100%

⑥ 표본 수

표본 수는 비교의 신뢰도에 영향을 준다. 표본이 너무 작으면 우연한 차이가 크게 보일 수 있다. 두 집단을 비교할 때는 값뿐 아니라 참여자 수나 관측 수를 함께 확인해야 한다.

⑦ 그래프 해석

그래프는 데이터의 차이를 직관적으로 보여 주지만, 축 범위나 눈금 간격에 따라 차이가 과장되거나 축소될 수 있다. 그래프를 볼 때는 제목, 축, 단위, 출처를 확인해야 한다.

⑧ 맥락 기반 해석

데이터 해석은 계산 결과를 현실의 상황과 연결하는 과정이다. 같은 증가율이라도 정책 변화, 계절, 표본 구성, 측정 방식에 따라 의미가 달라질 수 있다.

⑨ 해석의 한계

좋은 해석은 결론만 말하지 않는다. 데이터 수집 방식, 표본 크기, 결측값, 이상값, 측정 기준의 한계를 함께 제시해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 두 집단 평균 비교

import pandas as pd

df = pd.DataFrame({
    "반": ["A", "A", "B", "B"],
    "점수": [90, 80, 85, 75]
})

print(df.groupby("반")["점수"].mean())

반별 평균 점수를 비교한다. groupby는 집단별 분석에 유용하다.

② 절댓값 차이 계산

a = 90
b = 75

diff = a - b
print("차이:", diff)

두 값의 실제 차이를 계산한다.

③ 비율 계산

success = 45
total = 60

rate = success / total * 100
print("성공률:", rate, "%")

전체 중 성공한 비율을 계산한다. 집단 규모가 다를 때 유용하다.

④ 변화율 계산

last_year = 120
this_year = 150

growth_rate = (this_year - last_year) / last_year * 100
print("증가율:", growth_rate, "%")

작년 대비 올해 값이 몇 퍼센트 증가했는지 계산한다.

⑤ 집단별 합계와 개수 함께 보기

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "전주", "익산", "익산", "익산"],
    "이용자수": [100, 120, 80, 90, 70]
})

result = df.groupby("지역")["이용자수"].agg(["sum", "mean", "count"])
print(result)

합계, 평균, 개수를 함께 보면 집단 규모와 대표값을 동시에 해석할 수 있다.

5. 실생활 관련 코드 예제 5개

예제 1. 두 동아리 참여율 비교

clubs = {
    "AI동아리": {"참여": 18, "전체": 30},
    "로봇동아리": {"참여": 20, "전체": 50}
}

for name, data in clubs.items():
    rate = data["참여"] / data["전체"] * 100
    print(name, "참여율:", rate)

상세 설명: 참여 인원만 보면 로봇동아리가 많지만, 참여율로 보면 다른 결론이 나올 수 있다.

예제 2. 월별 독서량 변화율

last_month = 80
this_month = 100

growth = (this_month - last_month) / last_month * 100
print("독서량 증가율:", growth, "%")

상세 설명: 단순히 20권 증가했다는 사실뿐 아니라, 기준 대비 25% 증가했다는 상대적 의미를 확인한다.

예제 3. 지역별 평균 이용자 수 비교

import pandas as pd

df = pd.DataFrame({
    "지역": ["전주", "전주", "군산", "군산"],
    "이용자수": [120, 140, 80, 100]
})

print(df.groupby("지역")["이용자수"].mean())

상세 설명: 지역별 평균 이용자 수를 계산해 지역 간 차이를 비교한다.

예제 4. 평균과 표본 수 함께 비교

import pandas as pd

df = pd.DataFrame({
    "반": ["A", "A", "A", "B"],
    "점수": [80, 85, 90, 100]
})

print(df.groupby("반")["점수"].agg(["mean", "count"]))

상세 설명: B반 평균은 높지만 표본 수가 1명이다. 평균만 보고 일반화하면 위험하다.

예제 5. 그래프 축 범위 주의

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "year": [2024, 2025, 2026],
    "score": [80, 82, 83]
})

plt.plot(df["year"], df["score"], marker="o")
plt.title("Score Change")
plt.xlabel("Year")
plt.ylabel("Score")
plt.ylim(0, 100)
plt.show()

상세 설명: y축을 0부터 100까지 표시하면 실제 변화 크기를 더 균형 있게 볼 수 있다. 축 범위는 그래프 해석에 영향을 준다.

9. 수업을 마무리 하는 멘트

오늘 우리는 데이터를 비교하고 해석하는 방법을 배웠습니다. 컴퓨터과학은 데이터를 집단별로 계산하고 시각화하게 해 주며, 수학은 차이·비율·변화율을 통해 비교의 기준을 정교하게 만들어 줍니다. 과학은 측정 조건과 표본의 신뢰성을 묻게 하고, 인문 철학은 우리에게 묻습니다. “우리는 어떤 기준으로 공정하게 비교하고 있는가?” 좋은 데이터 과학자는 숫자의 크기만 보는 사람이 아니라, 기준과 맥락과 한계를 함께 설명하는 사람입니다.
