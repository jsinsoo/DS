핵심 개념

일반화된 이해
좋은 데이터 수집은 좋은 질문에서 시작되며, 질문 설계·표본·응답 편향·개인정보 보호가 분석 결과의 신뢰성을 결정한다.

2. 수업을 여는 멘트

여러분은 하루에도 여러 번 질문을 받습니다. “만족하셨나요?”, “추천하시겠습니까?”, “어떤 메뉴가 좋았나요?” 설문 조사는 단순히 체크 표시를 모으는 일이 아닙니다. 사람의 경험과 생각을 데이터라는 언어로 바꾸는 일입니다. 인문 철학적으로 보면 설문은 “타인의 목소리를 어떻게 공정하게 들을 것인가”라는 질문과 연결됩니다. 오늘 우리는 좋은 질문이 좋은 데이터를 만들고, 좋은 데이터가 더 나은 판단으로 이어지는 과정을 배웁니다.

3. 각각의 개념에 대한 상세 설명

① 설문 조사

설문 조사는 정해진 질문을 통해 사람들의 의견, 행동, 경험, 선호를 수집하는 방법이다. 학교 만족도 조사, 급식 선호도 조사, 스마트폰 사용 시간 조사, 진로 희망 조사 등이 설문 조사에 해당한다.

② 모집단과 표본

모집단은 알고 싶은 전체 대상이고, 표본은 실제로 조사한 일부 대상이다. 예를 들어 “전교생의 스마트폰 사용 습관”을 알고 싶다면 전교생이 모집단이고, 실제 응답한 100명이 표본이다. 표본이 모집단을 잘 대표하지 못하면 결과가 왜곡될 수 있다.

③ 문항 설계

문항 설계는 설문에서 가장 중요한 단계이다. 질문은 명확하고 중립적이어야 한다. “우리 학교 급식이 매우 훌륭하다고 생각하지 않나요?”처럼 응답을 유도하는 질문은 좋은 문항이 아니다.

④ 응답 척도

척도는 응답을 측정하는 기준이다. 예를 들어 1점부터 5점까지 만족도를 표시하는 리커트 척도, 예/아니오, 객관식 선택, 순위 선택 등이 있다. 척도는 분석 방법과 직접 연결된다.

⑤ 정량 응답과 정성 응답

정량 응답은 숫자로 분석하기 쉬운 응답이다. 예를 들어 만족도 1~5점, 사용 시간, 선택 빈도 등이 있다. 정성 응답은 서술형 의견처럼 문장으로 표현된 응답이다. 정성 응답은 키워드 추출이나 범주화가 필요하다.

⑥ 응답 편향

응답 편향은 실제 생각과 다르게 응답이 치우치는 현상이다. 질문이 유도적이거나, 표본이 특정 집단에 몰리거나, 응답자가 사회적으로 바람직한 답을 하려 할 때 편향이 발생할 수 있다.

⑦ 결측 응답

결측 응답은 응답자가 문항에 답하지 않아 값이 비어 있는 경우이다. 결측값이 많은 문항은 분석 신뢰도를 떨어뜨릴 수 있으므로 원인을 확인하고 제외, 대체, 별도 표시 등의 처리가 필요하다.

⑧ 온라인 설문과 웹 데이터 수집

온라인 설문은 웹 폼을 통해 응답을 수집하고 CSV 또는 스프레드시트로 저장할 수 있다. 웹 데이터 수집 기초와 연결하면, 온라인 응답 데이터도 웹을 통해 생성되는 구조화된 데이터로 볼 수 있다.

⑨ 개인정보 보호와 동의

설문에는 이름, 연락처, 학번, 위치 정보처럼 개인을 식별할 수 있는 정보가 포함될 수 있다. 반드시 수집 목적을 설명하고 필요한 정보만 최소한으로 수집해야 하며, 가능하면 익명화해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 설문 응답 DataFrame 만들기

import pandas as pd

df = pd.DataFrame({
    "학년": [1, 1, 2, 2, 3],
    "만족도": [5, 4, 3, 4, 2],
    "희망활동": ["코딩", "실험", "코딩", "독서", "실험"]
})

print(df)

설문 응답을 표 형태의 DataFrame으로 만든다. 각 행은 한 명의 응답, 각 열은 하나의 문항이다.

② 선택형 문항 빈도 계산

counts = df["희망활동"].value_counts()
print(counts)

선택형 문항에서 각 선택지가 몇 번 선택되었는지 계산한다.

③ 만족도 평균 계산

mean_score = df["만족도"].mean()
print("평균 만족도:", mean_score)

리커트 척도처럼 숫자로 입력된 응답의 평균을 구한다.

④ 학년별 평균 만족도

group_mean = df.groupby("학년")["만족도"].mean()
print(group_mean)

학년별로 만족도 평균을 비교하여 집단 간 차이를 살펴본다.

⑤ 결측 응답 확인

missing = df.isna().sum()
print(missing)

응답하지 않은 문항이 있는지 확인한다. 결측값은 분석 전에 반드시 점검해야 한다.

5. 실생활 관련 코드 예제 5개

예제 1. 급식 만족도 설문 분석

import pandas as pd

df = pd.DataFrame({
    "학생": ["A", "B", "C", "D", "E"],
    "만족도": [5, 3, 4, 2, 5]
})

print("평균 만족도:", df["만족도"].mean())
print("최고점:", df["만족도"].max())
print("최저점:", df["만족도"].min())

상세 설명: 급식 만족도를 숫자형 척도로 수집하면 평균, 최고점, 최저점 등을 쉽게 계산할 수 있다.

예제 2. 진로 희망 분야 빈도표

import pandas as pd

df = pd.DataFrame({
    "진로": ["의학", "공학", "공학", "생명과학", "의학", "인공지능"]
})

print(df["진로"].value_counts())

상세 설명: 학생들이 선택한 진로 분야를 빈도표로 정리한다. 가장 많이 선택된 분야를 빠르게 확인할 수 있다.

예제 3. 스마트폰 사용 시간 구간 분류

import pandas as pd

df = pd.DataFrame({
    "이름": ["가", "나", "다", "라"],
    "사용시간": [1.5, 3.2, 5.1, 2.0]
})

def level(h):
    if h < 2:
        return "낮음"
    elif h < 4:
        return "보통"
    return "높음"

df["사용수준"] = df["사용시간"].apply(level)
print(df)

상세 설명: 숫자로 수집한 사용 시간을 낮음·보통·높음 범주로 바꾼다. 데이터를 해석하기 쉬운 정보로 변환하는 예이다.

예제 4. 학년과 선호 활동 교차표

import pandas as pd

df = pd.DataFrame({
    "학년": [1, 1, 2, 2, 3, 3],
    "활동": ["코딩", "실험", "코딩", "독서", "실험", "코딩"]
})

table = pd.crosstab(df["학년"], df["활동"])
print(table)

상세 설명: 학년별로 어떤 활동을 선호하는지 교차표로 확인한다. 두 범주형 문항의 관계를 분석할 때 유용하다.

예제 5. 서술형 응답 키워드 간단 분석

answers = [
    "급식이 맛있고 메뉴가 다양하면 좋겠습니다",
    "메뉴가 다양하지만 채소가 더 많으면 좋겠습니다",
    "맛있고 따뜻한 급식이 좋습니다"
]

keywords = ["맛있", "다양", "채소", "따뜻"]
for key in keywords:
    count = sum(key in answer for answer in answers)
    print(key, count)

상세 설명: 서술형 응답에서 특정 키워드가 몇 번 등장하는지 간단히 확인한다. 정성 응답을 정량적으로 요약하는 기초 활동이다.

7. 형성평가 5지선다형 10문항

문항 1. 설문 조사의 목적에 대한 설명으로 가장 적절한 것은?
정답: 1번
상세풀이: 설문 조사는 응답자의 의견, 행동, 경험, 선호 등을 데이터로 수집하는 방법이다.
문항 2. 모집단의 의미로 가장 적절한 것은?
정답: 1번
상세풀이: 모집단은 연구자가 알고자 하는 전체 대상이다.
문항 3. 표본에 대한 설명으로 옳은 것은?
정답: 1번
상세풀이: 표본은 전체 모집단을 대신해 실제 조사에 참여한 일부 대상이다.
문항 4. 좋은 설문 문항의 조건으로 적절한 것은?
정답: 1번
상세풀이: 좋은 문항은 이해하기 쉽고 한 가지 내용만 묻고 중립적이어야 한다.
문항 5. 응답 편향이 발생할 가능성이 큰 문항은?
정답: 1번
상세풀이: 칭찬 표현과 부정 의문이 섞인 유도 질문은 응답을 한쪽으로 치우치게 할 수 있다.
문항 6. 리커트 척도의 예로 가장 적절한 것은?
정답: 1번
상세풀이: 만족도나 동의 정도를 단계별 숫자로 표시하는 방식이 리커트 척도이다.
문항 7. 결측 응답 처리와 관련된 설명으로 옳은 것은?
정답: 1번
상세풀이: 결측값은 평균, 비율, 빈도 분석에 영향을 줄 수 있으므로 먼저 확인해야 한다.
문항 8. 온라인 설문과 웹 데이터 수집의 연결로 적절한 것은?
정답: 1번
상세풀이: 온라인 설문 응답은 스프레드시트나 CSV로 저장되어 분석할 수 있다.
문항 9. 설문에서 개인정보 보호를 위한 태도로 가장 적절한 것은?
정답: 1번
상세풀이: 개인정보는 목적에 필요한 최소 범위로 수집하고 동의와 보호 조치를 고려해야 한다.
