2. 수업을 여는 멘트

우리는 생활 속에서 수많은 표를 만납니다. 출석부, 성적표, 시간표, 급식표, 경기 기록표, 병원 검사 결과표가 모두 표 형태 데이터입니다. 표는 단순히 네모 칸을 나열한 것이 아니라, 세상을 비교하고 기억하기 위해 만든 질서입니다. 인문 철학적으로 보면 표는 복잡한 현실을 일정한 기준으로 나누어 이해하려는 인간의 사고 방식입니다. 오늘 우리는 표의 행과 열을 읽는 법을 배우며, 숫자와 글자 뒤에 숨어 있는 의미를 정확히 해석하는 힘을 기릅니다.

3. 각각의 개념에 대한 상세 설명

① 표 형태 데이터

표 형태 데이터는 행과 열로 구성된 데이터이다. 일반적으로 한 행은 하나의 관찰 대상이나 사건을 나타내고, 한 열은 그 대상의 속성을 나타낸다. 예를 들어 학생 성적표에서 한 행은 한 학생, 열은 이름·학번·국어·수학·과학 점수이다.

② 행과 레코드

행은 표에서 가로 방향의 한 줄이며, 데이터베이스에서는 레코드라고도 한다. 한 행은 하나의 대상에 대한 여러 속성 값을 묶어 표현한다. 행을 잘못 해석하면 한 사람의 정보와 여러 사람의 정보를 혼동할 수 있다.

③ 열과 필드

열은 표에서 세로 방향의 한 줄이며, 데이터베이스에서는 필드 또는 속성이라고도 한다. 열 이름은 데이터의 의미를 알려 주므로 분석 전에 반드시 확인해야 한다.

④ 셀

셀은 행과 열이 만나는 한 칸이다. 셀 하나에는 특정 대상의 특정 속성 값이 들어 있다. 예를 들어 “김데이터 학생의 수학 점수 95점”은 하나의 셀 값이다.

⑤ 인덱스

인덱스는 행을 구별하기 위한 이름이나 번호이다. Pandas에서는 기본적으로 0부터 시작하는 인덱스가 붙는다. 데이터베이스의 기본키와 비슷하게 행을 구분하는 데 도움을 줄 수 있지만, 항상 고유한 식별자라고 단정해서는 안 된다.

⑥ 자료형

자료형은 값의 종류를 뜻한다. 숫자형은 계산할 수 있고, 문자열은 글자로 처리되며, 날짜형은 시간 순서 분석에 적합하다. 숫자처럼 보여도 문자열로 저장되어 있으면 평균 계산이 되지 않을 수 있다.

⑦ 결측값

결측값은 비어 있는 값이다. 설문에 응답하지 않았거나, 센서가 측정하지 못했거나, 파일 변환 과정에서 값이 누락될 때 발생한다. 결측값은 평균, 합계, 비율 분석에 영향을 줄 수 있다.

⑧ 정렬과 필터링

정렬은 데이터를 특정 기준에 따라 순서대로 배열하는 것이고, 필터링은 조건에 맞는 행만 선택하는 것이다. 예를 들어 점수가 높은 순서로 정렬하거나, 80점 이상 학생만 골라낼 수 있다.

⑨ 요약 통계

요약 통계는 평균, 합계, 최댓값, 최솟값, 개수처럼 데이터를 간단히 설명하는 값이다. 표가 클수록 요약 통계는 전체 경향을 파악하는 데 유용하다.

4. 각각의 개념과 관련된 파이썬 코드

① DataFrame 만들기

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "수학": [95, 82, 76],
    "과학": [90, 88, 92]
})

print(df)

딕셔너리를 이용해 표 형태 데이터인 DataFrame을 만든다. 열 이름은 이름, 수학, 과학이다.

② 열 선택

print(df["수학"])

수학 열만 선택한다. 하나의 열은 같은 속성에 대한 값들의 모음이다.

③ 행 선택

print(df.loc[0])

인덱스가 0인 첫 번째 행을 선택한다. 한 행은 한 학생의 전체 정보를 나타낸다.

④ 조건 필터링

high = df[df["수학"] >= 80]
print(high)

수학 점수가 80점 이상인 행만 선택한다. 조건에 맞는 데이터를 골라내는 필터링이다.

⑤ 정렬과 평균

sorted_df = df.sort_values("과학", ascending=False)
print(sorted_df)

print("수학 평균:", df["수학"].mean())

과학 점수를 기준으로 내림차순 정렬하고, 수학 점수의 평균을 계산한다.

5. 실생활 관련 코드 예제 5개

예제 1. 급식 선호도 표 데이터

import pandas as pd

df = pd.DataFrame({
    "메뉴": ["비빔밥", "카레", "김치찌개", "스파게티"],
    "선호도": [4.5, 4.2, 3.8, 4.7]
})

print(df.sort_values("선호도", ascending=False))

상세 설명: 메뉴별 선호도를 표로 만들고 선호도가 높은 순서로 정렬한다. 급식 개선 의견을 데이터로 확인할 수 있다.

예제 2. 출석 데이터 필터링

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온", "라온"],
    "상태": ["출석", "지각", "출석", "결석"]
})

late_or_absent = df[df["상태"] != "출석"]
print(late_or_absent)

상세 설명: 출석이 아닌 학생만 필터링한다. 조건 필터링은 필요한 행만 빠르게 찾을 때 유용하다.

예제 3. 운동 기록 요약

import pandas as pd

df = pd.DataFrame({
    "요일": ["월", "화", "수", "목", "금"],
    "걸음수": [8200, 7600, 9100, 6500, 10000]
})

print("평균 걸음수:", df["걸음수"].mean())
print("최대 걸음수:", df["걸음수"].max())

상세 설명: 요일별 걸음수 표에서 평균과 최댓값을 계산한다. 표 데이터의 요약 통계 예이다.

예제 4. 결측값 있는 설문 데이터

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "만족도": [5, None, 4]
})

print(df.isna().sum())

상세 설명: 응답하지 않은 값이 있는지 확인한다. 결측값은 분석 전에 반드시 점검해야 한다.

예제 5. 열 추가로 총점 계산

import pandas as pd

df = pd.DataFrame({
    "이름": ["가은", "나래", "다온"],
    "국어": [90, 85, 78],
    "수학": [95, 80, 88]
})

df["총점"] = df["국어"] + df["수학"]
print(df)

상세 설명: 기존 열을 이용해 새로운 열을 만든다. 표 데이터는 여러 속성을 조합해 새로운 정보를 만들 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 표 형태 데이터가 행과 열이라는 질서 속에서 현실을 표현한다는 것을 배웠습니다. 컴퓨터과학은 DataFrame과 데이터베이스를 통해 표를 저장하고 처리하게 해 주고, 수학은 평균, 합계, 비교, 비율을 통해 표의 의미를 해석하게 하며, 과학은 데이터가 어떤 조건에서 수집되었는지 묻도록 합니다. 그리고 인문 철학은 우리에게 말합니다. “표는 현실을 보여 주지만, 현실 전체를 다 담지는 못한다.” 좋은 데이터 과학자는 표를 빠르게 계산하는 사람일 뿐 아니라, 표가 말하는 것과 말하지 못하는 것을 함께 읽는 사람입니다.
