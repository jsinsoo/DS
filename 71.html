핵심 개념
파이썬 기초는 데이터를 표현하고 처리하며 분석과 시각화로 확장하기 위한 프로그래밍의 기본 언어이다.

데이터 과학에서 프로그래밍은 문제를 논리적으로 분해하고 재현 가능한 절차로 표현하는 과정이다.

2. 수업을 여는 멘트

데이터 과학자는 숫자를 많이 아는 사람일 뿐 아니라, 반복되는 생각을 컴퓨터가 실행할 수 있는 절차로 바꾸는 사람입니다. 우리가 매일 하는 “평균을 구하자”, “조건에 맞는 학생을 찾자”, “여러 값을 하나씩 확인하자”라는 생각은 파이썬 코드가 될 수 있습니다. 인문 철학적으로 프로그래밍은 인간의 사고를 명확한 언어로 번역하는 일입니다. 오늘 우리는 데이터 과학의 언어인 파이썬을 통해 생각을 코드로 바꾸는 첫걸음을 시작합니다.

3. 각각의 개념에 대한 상세 설명

① 파이썬

파이썬은 문법이 비교적 간단하고 읽기 쉬워 데이터 분석, 인공지능, 웹 개발, 자동화 등 다양한 분야에서 사용되는 프로그래밍 언어이다.

② 변수

변수는 값에 이름을 붙여 저장하는 방법이다. 예를 들어 score = 90은 90이라는 값을 score라는 이름으로 저장한다.

③ 자료형

자료형은 데이터의 종류이다. 정수, 실수, 문자열, 참/거짓, 리스트 등이 있으며 자료형을 이해하면 계산 오류를 줄일 수 있다.

④ 입력과 출력

input()은 사용자에게 값을 입력받고, print()는 값을 화면에 출력한다.

⑤ 형 변환

형 변환은 자료형을 바꾸는 것이다. int("10")은 문자열 "10"을 정수 10으로 바꾼다.

⑥ 조건문

조건문은 조건의 참과 거짓에 따라 실행할 코드를 선택한다. if, elif, else를 사용한다.

⑦ 반복문

반복문은 같은 작업을 여러 번 실행하는 문법이다. 데이터 목록을 하나씩 처리할 때 매우 유용하다.

⑧ 리스트

리스트는 여러 값을 순서대로 저장하는 자료형이다. 점수 목록, 이름 목록, 측정값 목록처럼 여러 데이터를 묶어 처리할 수 있다.

⑨ 함수

함수는 특정 작업을 수행하는 코드를 묶어 이름을 붙인 것이다. 같은 코드를 반복하지 않고 재사용할 수 있다.

4. 각각의 개념과 관련된 파이썬 코드

① 변수와 출력

score = 90
name = "Data"

print(name)
print(score)

문자열과 숫자를 변수에 저장하고 출력한다.

② 자료형 확인

a = 10
b = 3.14
c = "python"
d = True

print(type(a))
print(type(b))
print(type(c))
print(type(d))

type()을 이용해 값의 자료형을 확인한다.

③ 입력과 형 변환

age_text = input("Age: ")
age = int(age_text)

print(age + 1)

입력값을 정수로 변환하여 계산한다.

④ 조건문

score = 85

if score >= 80:
    print("Good")
else:
    print("Try again")

조건에 따라 다른 결과를 출력한다.

⑤ 반복문과 리스트

scores = [70, 80, 90]

for score in scores:
    print(score)

리스트의 값을 하나씩 꺼내 출력한다.

⑥ 함수

def average(values):
    return sum(values) / len(values)

scores = [70, 80, 90]
print(average(scores))

평균 계산 함수를 정의하고 재사용한다.

5. 실생활 관련 코드 예제 5개

예제 1. 시험 점수 평균 구하기

scores = [85, 90, 78, 92]
avg = sum(scores) / len(scores)
print("Average:", avg)

상세 설명: 여러 점수를 리스트에 저장하고 합계와 개수를 이용해 평균을 계산한다.

예제 2. 온도에 따른 옷차림 추천

temperature = 12

if temperature < 10:
    print("Wear a coat")
elif temperature < 25:
    print("Wear a jacket")
else:
    print("Wear light clothes")

상세 설명: 조건문을 이용해 온도에 따라 다른 추천을 출력한다.

예제 3. 지출 합계 계산

expenses = [3000, 4500, 2500, 6000]
total = 0

for money in expenses:
    total += money

print("Total expense:", total)

상세 설명: 반복문으로 지출 목록을 하나씩 더해 총액을 계산한다.

예제 4. 합격 여부 판정 함수

def pass_check(score):
    if score >= 60:
        return "Pass"
    return "Fail"

print(pass_check(75))
print(pass_check(45))

상세 설명: 함수로 합격 판정 규칙을 묶어 여러 점수에 재사용한다.

예제 5. 데이터에서 조건에 맞는 값 찾기

steps = [3500, 8000, 12000, 6000]
high_steps = []

for s in steps:
    if s >= 8000:
        high_steps.append(s)

print(high_steps)

상세 설명: 반복문과 조건문을 함께 사용해 8000보 이상 걸은 날만 리스트에 모은다.
