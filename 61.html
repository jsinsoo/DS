2. 수업을 여는 멘트

우리는 이미 인공지능과 함께 살고 있습니다. 스마트폰은 얼굴을 인식하고, 영상 플랫폼은 다음에 볼 콘텐츠를 추천하며, 챗봇은 우리의 질문에 답합니다. 하지만 인공지능이 답을 준다고 해서 항상 옳은 것은 아닙니다. 인문 철학적으로 인공지능은 “생각한다는 것은 무엇인가?”, “판단의 책임은 누구에게 있는가?”라는 오래된 질문을 새롭게 던집니다. 오늘 우리는 AI를 마법처럼 받아들이지 않고, 데이터와 규칙과 모델이 어떻게 지능적인 행동처럼 보이는 결과를 만드는지 차근차근 살펴보겠습니다.

3. 각각의 개념에 대한 상세 설명

① 인공지능

인공지능은 컴퓨터가 인간의 지능적 활동과 비슷한 기능을 수행하도록 만드는 기술과 학문 분야이다. 여기에는 언어 이해, 이미지 인식, 음성 인식, 추론, 예측, 의사결정 등이 포함된다.

② 약한 인공지능

약한 인공지능은 특정 과제를 잘 수행하도록 설계된 AI이다. 현재 우리가 사용하는 대부분의 AI는 번역, 추천, 분류, 검색처럼 특정 목적을 수행하는 약한 인공지능이다.

③ 규칙 기반 인공지능

규칙 기반 인공지능은 사람이 미리 정한 조건과 규칙에 따라 판단하는 방식이다. 예를 들어 “온도가 30도 이상이면 더움”처럼 명시적인 규칙을 사용한다.

④ 머신러닝

머신러닝은 데이터를 통해 패턴을 학습하고, 새로운 데이터에 대해 예측이나 판단을 수행하는 인공지능 방법이다. 사람이 모든 규칙을 직접 쓰지 않고 데이터로부터 규칙성을 찾는다.

⑤ 모델

모델은 입력 데이터를 바탕으로 출력이나 판단을 만드는 계산 구조이다. 머신러닝 모델은 학습 데이터를 이용해 내부 기준이나 가중치를 조정한다.

⑥ 지능 에이전트

지능 에이전트는 환경을 인식하고 목표에 맞게 행동하는 시스템이다. 센서나 입력으로 환경을 파악하고, 판단 과정을 거쳐 행동을 선택한다.

⑦ 데이터와 학습

AI가 좋은 판단을 하려면 적절한 데이터가 필요하다. 데이터가 부족하거나 편향되어 있으면 AI의 결과도 부정확하거나 불공정할 수 있다.

⑧ AI 활용 사례

챗봇, 음성 비서, 추천 시스템, 자율주행, 의료 영상 분석, 번역기, 스팸 필터, 얼굴 인식 등이 인공지능 활용 사례이다.

⑨ AI 윤리

인공지능은 사람의 삶에 영향을 주므로 공정성, 개인정보 보호, 설명 가능성, 책임성, 안전성 문제가 중요하다. AI가 내린 판단이라도 최종 책임과 검토는 인간 사회의 몫이다.

4. 각각의 개념과 관련된 파이썬 코드

① 규칙 기반 AI

temperature = 32

if temperature >= 30:
    result = "Hot"
else:
    result = "Normal"

print(result)

온도 조건에 따라 더움 또는 보통을 판단하는 간단한 규칙 기반 AI 예제이다.

② 간단한 챗봇 규칙

message = "hello"

if message == "hello":
    reply = "Hi, nice to meet you!"
else:
    reply = "I do not understand."

print(reply)

입력 문장에 따라 정해진 답을 출력한다. 실제 챗봇은 훨씬 복잡한 언어 처리 과정을 사용한다.

③ 추천 시스템 기초

liked_genre = "science"

if liked_genre == "science":
    recommendation = "Data Science Documentary"
else:
    recommendation = "General Movie"

print(recommendation)

사용자의 선호에 따라 콘텐츠를 추천하는 기본 아이디어를 보여 준다.

④ 거리 기반 간단 분류

new_height = 170

if new_height >= 165:
    label = "Group A"
else:
    label = "Group B"

print(label)

하나의 기준값을 이용해 데이터를 두 집단으로 분류한다. 실제 머신러닝은 여러 특징을 함께 사용할 수 있다.

⑤ 데이터 기반 평균 예측

scores = [70, 80, 90]
prediction = sum(scores) / len(scores)

print("Predicted score:", prediction)

과거 점수의 평균을 이용해 단순 예측을 수행한다. 데이터 기반 예측의 가장 기초적인 형태이다.

5. 실생활 관련 코드 예제 5개

예제 1. 스팸 메시지 규칙 분류

message = "free money now"

spam_words = ["free", "money", "win"]

if any(word in message for word in spam_words):
    print("Spam")
else:
    print("Normal")

상세 설명: 특정 단어가 포함되어 있으면 스팸으로 분류한다. 규칙 기반 분류의 예이다.

예제 2. 날씨 추천 AI

temperature = 8

if temperature < 10:
    print("Wear a coat")
elif temperature < 25:
    print("Light jacket is enough")
else:
    print("Wear cool clothes")

상세 설명: 온도에 따라 옷차림을 추천한다. 센서 데이터나 날씨 데이터와 연결할 수 있다.

예제 3. 간단한 음악 추천

mood = "happy"

recommend = {
    "happy": "dance music",
    "sad": "calm piano",
    "focus": "lofi music"
}

print(recommend.get(mood, "popular music"))

상세 설명: 사용자의 기분 입력에 따라 음악을 추천한다. 실제 추천 시스템은 많은 사용자 행동 데이터를 활용한다.

예제 4. 공부 시간 기반 점수 예측

study_hour = 4

predicted_score = 50 + study_hour * 8

print("Predicted score:", predicted_score)

상세 설명: 공부 시간이 늘수록 점수가 증가한다고 가정한 단순 예측식이다. 실제 예측은 여러 요인과 데이터를 검토해야 한다.

예제 5. AI 편향 체험

training_data = ["soccer", "soccer", "soccer", "piano"]

from collections import Counter

most_common = Counter(training_data).most_common(1)[0][0]
print("AI recommends:", most_common)

상세 설명: 학습 데이터에 soccer가 지나치게 많으면 추천도 soccer로 치우친다. 데이터 편향이 결과 편향으로 이어질 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 인공지능이 마법이 아니라 데이터, 규칙, 모델, 판단 구조로 이루어진 기술임을 배웠습니다. 컴퓨터과학은 AI를 구현하는 알고리즘과 시스템을 제공하고, 수학은 패턴과 예측의 논리를 설명하며, 과학은 결과를 검증하고 오류를 점검하게 합니다. 그리고 인문 철학은 우리에게 묻습니다. “기계가 판단할 때, 그 판단의 책임은 누구에게 있는가?” 좋은 데이터 과학자는 AI를 잘 사용하는 사람을 넘어, AI의 한계와 사회적 영향을 함께 설명할 수 있는 사람입니다.
