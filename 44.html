3. 각각의 개념에 대한 상세 설명

① 상관관계

상관관계는 두 변수가 함께 변하는 경향을 의미한다. 예를 들어 공부 시간이 늘수록 점수가 높아지는 경향이 있다면 두 변수 사이에 상관관계가 있다고 말할 수 있다.

② 양의 상관관계

양의 상관관계는 한 변수가 증가할 때 다른 변수도 증가하는 경향이다. 산점도에서는 점들이 왼쪽 아래에서 오른쪽 위로 향하는 패턴을 보인다.

③ 음의 상관관계

음의 상관관계는 한 변수가 증가할 때 다른 변수는 감소하는 경향이다. 산점도에서는 점들이 왼쪽 위에서 오른쪽 아래로 향하는 패턴을 보인다.

④ 무상관

무상관은 두 변수 사이에 뚜렷한 선형 관계가 보이지 않는 경우이다. 점들이 특별한 방향 없이 흩어져 있을 수 있다. 단, 선형 상관이 약하다고 해서 모든 관계가 없다는 뜻은 아니다.

⑤ 상관계수

상관계수는 두 변수 사이의 선형 관계 방향과 강도를 수치로 나타낸 값이다. 피어슨 상관계수는 -1에서 1 사이의 값을 가지며, 1에 가까우면 강한 양의 상관, -1에 가까우면 강한 음의 상관, 0에 가까우면 약한 선형 관계를 뜻한다.

피어슨 상관계수: r=∑(xi−x¯)(yi−y¯)∑(xi−x¯)2∑(yi−y¯)2

⑥ 산점도

산점도는 두 수치형 변수를 x축과 y축에 놓고 각 관측값을 점으로 표시한 그래프이다. 상관계수 숫자만 보는 것보다 산점도를 함께 보면 이상값, 군집, 비선형 패턴을 더 잘 알 수 있다.

⑦ 상관관계와 인과관계

상관관계는 함께 변한다는 뜻이고, 인과관계는 한 변수가 다른 변수의 원인이 된다는 뜻이다. 상관관계만으로는 인과관계를 증명할 수 없다.

⑧ 제3의 변수

제3의 변수는 두 변수 모두에 영향을 주어 상관관계가 있는 것처럼 보이게 만드는 숨은 변수이다. 예를 들어 더운 날씨는 아이스크림 판매량과 물놀이 사고 모두에 영향을 줄 수 있다.

⑨ 해석의 책임

상관관계는 정책, 광고, 뉴스, 연구 해석에서 자주 사용된다. 하지만 관계를 원인으로 오해하면 잘못된 판단을 내릴 수 있으므로 근거, 실험, 이론, 맥락을 함께 확인해야 한다.

4. 각각의 개념과 관련된 파이썬 코드

① 양의 상관 데이터 만들기

import pandas as pd

df = pd.DataFrame({
    "공부시간": [1, 2, 3, 4, 5],
    "점수": [55, 60, 72, 80, 90]
})

print(df.corr(numeric_only=True))

공부시간과 점수가 함께 증가하는 경향을 상관계수로 확인한다.

import matplotlib.pyplot as plt

plt.scatter(df["공부시간"], df["점수"])
plt.title("Study Time and Score")
plt.xlabel("Study Time")
plt.ylabel("Score")
plt.show()

두 변수의 관계를 점의 패턴으로 시각화한다.

③ 음의 상관 데이터

import pandas as pd

운동시간이 늘수록 스트레스 점수가 낮아지는 경향을 확인한다.

⑤ 상관관계가 약한 데이터

import pandas as pd

두 변수 사이에 뚜렷한 선형 관계가 없는 경우 상관계수가 0에 가까울 수 있다.

9. 수업을 마무리 하는 멘트

오늘 우리는 두 변수가 함께 움직이는 정도를 상관관계로 살펴보았습니다. 컴퓨터과학은 상관계수를 빠르게 계산하고 산점도로 시각화하게 해 주며, 수학은 -1에서 1 사이의 수로 관계의 방향과 강도를 표현하게 합니다. 과학은 관계를 발견한 뒤 원인인지 검증하라고 요구하고, 인문 철학은 우리에게 묻습니다. “함께 나타난다는 이유만으로 원인이라고 믿고 있지는 않은가?” 좋은 데이터 과학자는 관계를 발견하는 사람일 뿐 아니라, 그 관계를 겸손하고 비판적으로 해석하는 사람입니다.
