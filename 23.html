3. 각각의 개념에 대한 상세 설명

① 웹 데이터

웹 데이터는 웹 페이지, 뉴스, 게시글, 표, 이미지 설명, 상품 정보, 날씨 정보처럼 인터넷을 통해 제공되는 다양한 정보이다. 웹 데이터는 실시간성이 높고 양이 많다는 장점이 있지만, 형식이 일정하지 않거나 저작권·개인정보 문제가 포함될 수 있다.

② URL

URL은 웹 자원의 주소이다. 예를 들어 https는 통신 방식, example.com은 도메인, /news는 경로, ?q=data는 요청 조건을 나타낼 수 있다. URL을 이해하면 어떤 데이터를 어디에 요청하는지 파악할 수 있다.

③ HTML과 태그

HTML은 웹 페이지의 구조를 표현하는 언어이다. 제목은 h1, 문단은 p, 링크는 a, 표는 table 태그로 표현된다. 웹 스크래핑은 이러한 태그 구조를 분석하여 필요한 정보만 추출하는 과정이다.

④ HTTP 요청과 응답

브라우저나 파이썬 프로그램이 서버에 웹 페이지를 요청하면, 서버는 상태 코드와 함께 HTML, JSON 같은 데이터를 응답한다. 200은 성공, 404는 찾을 수 없음, 403은 접근 금지, 500은 서버 오류를 의미한다.

⑤ 크롤링과 스크래핑

크롤링은 여러 웹 페이지를 따라가며 데이터를 수집하는 과정이고, 스크래핑은 특정 웹 페이지에서 필요한 데이터를 추출하는 과정이다. 수업 초급 단계에서는 많은 페이지를 자동 방문하기보다, 허용된 예제 페이지나 저장된 HTML을 대상으로 구조를 이해하는 것이 좋다.

⑥ 파싱

파싱은 HTML이나 JSON 같은 데이터의 구조를 해석하여 필요한 요소를 꺼내는 과정이다. BeautifulSoup은 HTML 파싱에 자주 사용되는 파이썬 라이브러리이다.

⑦ robots.txt

robots.txt는 웹 사이트가 자동 수집 프로그램에게 접근 가능 범위를 알려 주는 파일이다. 법적 허용 여부를 완전히 대신하지는 않지만, 웹 데이터 수집을 시작하기 전에 반드시 확인해야 할 중요한 신호이다.

⑧ 웹 데이터 수집 윤리

웹에 보인다고 해서 모두 자유롭게 수집·복제·재배포할 수 있는 것은 아니다. 개인정보, 저작권, 이용 약관, 서버 부담, 출처 표기, 수집 목적의 정당성을 고려해야 한다. 교육용 실습에서는 공개 예제, 직접 만든 HTML, 공공데이터, 공식 API를 우선 활용하는 것이 안전하다.

4. 각각의 개념과 관련된 파이썬 코드

① URL 문자열 이해

from urllib.parse import urlparse

url = "https://example.com/search?q=data"
parsed = urlparse(url)

print(parsed.scheme)
print(parsed.netloc)
print(parsed.path)
print(parsed.query)

URL을 통신 방식, 도메인, 경로, 쿼리 문자열로 나누어 확인한다.

② 웹 페이지 요청 기초

import requests

url = "https://example.com"
response = requests.get(url, timeout=5)

print(response.status_code)
print(response.text[:100])

웹 서버에 요청을 보내고 응답 상태 코드와 HTML 앞부분을 확인한다. 실제 수업에서는 접속 가능한 안전한 예제 사이트를 사용한다.

③ HTML 태그 파싱

from bs4 import BeautifulSoup

html = "<html><body><h1>데이터 과학</h1><p>웹 데이터 수집</p></body></html>"
soup = BeautifulSoup(html, "html.parser")

print(soup.find("h1").text)
print(soup.find("p").text)

문자열로 저장된 HTML에서 h1 태그와 p 태그의 텍스트를 추출한다.

④ 표 데이터 읽기

import pandas as pd

html = """
<table>
<tr><th>지역</th><th>기온</th></tr>
<tr><td>전주</td><td>23</td></tr>
<tr><td>군산</td><td>21</td></tr>
</table>
"""

tables = pd.read_html(html)
print(tables[0])

HTML 안의 table 태그를 Pandas DataFrame으로 읽어 표 형태로 분석한다.

⑤ 수집한 데이터 CSV 저장

import pandas as pd

df = pd.DataFrame({
    "제목": ["날씨", "교통", "미세먼지"],
    "분류": ["환경", "교통", "환경"]

df.to_csv("web_data.csv", index=False, encoding="utf-8-sig")

수집·정리한 데이터를 CSV 파일로 저장한다. utf-8-sig는 엑셀에서 한글이 깨지는 현상을 줄이는 데 도움이 된다.

5. 실생활 관련 코드 예제 5개

예제 1. 뉴스 제목 HTML에서 제목 추출

from bs4 import BeautifulSoup

html = """
<div class='news'>
  <h2>전주 지역 청소년 데이터 캠프 개최</h2>
  <h2>미세먼지 예보 서비스 개선</h2>
</div>
"""

soup = BeautifulSoup(html, "html.parser")
titles = [tag.text for tag in soup.find_all("h2")]

print(titles)

상세 설명: 뉴스 페이지 구조를 단순화한 HTML에서 h2 태그만 찾아 제목 목록을 만든다. 실제 사이트를 무단 수집하지 않고도 구조 이해 실습이 가능하다.

예제 2. 상품 가격 문자열 정리

prices = ["12,000원", "8,500원", "23,300원"]

numbers = [int(p.replace(",", "").replace("원", "")) for p in prices]

print(numbers)
print("평균 가격:", sum(numbers) / len(numbers))

상세 설명: 웹에서 가져온 가격 문자열에는 쉼표와 단위가 포함될 수 있다. 분석을 위해 숫자형으로 변환한다.

예제 3. 학교 급식 예시 데이터 추출

from bs4 import BeautifulSoup

html = """
<ul>
  <li class='menu'>현미밥</li>
  <li class='menu'>된장국</li>
  <li class='menu'>닭갈비</li>
</ul>
"""

soup = BeautifulSoup(html, "html.parser")
menus = [m.text for m in soup.select(".menu")]

print("오늘의 급식:", menus)

상세 설명: class 이름이 menu인 요소를 선택하여 급식 목록을 추출한다. CSS 선택자의 기초를 이해할 수 있다.

import pandas as pd

예제 5. 수집 윤리 체크리스트 만들기

checks = {
    "robots.txt 확인": True,

9. 수업을 마무리 하는 멘트

오늘 우리는 웹을 사람이 보는 화면이 아니라 컴퓨터가 해석할 수 있는 구조로 바라보았습니다. 컴퓨터과학은 요청과 응답, 파싱과 저장의 방법을 알려 주고, 수학은 수집된 데이터 속 패턴을 정량적으로 해석하게 하며, 과학은 관찰과 검증의 태도를 요구합니다. 그러나 인문 철학은 한 가지 질문을 던집니다. “수집할 수 있다는 것이 곧 수집해도 된다는 뜻인가?” 좋은 데이터 과학자는 많이 모으는 사람이 아니라, 필요한 데이터를 정당하고 책임 있게 다루는 사람입니다.
